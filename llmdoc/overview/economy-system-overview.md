# 经济系统概览

## 1. 身份标识

- **定义**: 一个包含货币体系、交易市场、跑商系统、气运投资的经济生态系统
- **目的**: 提供玩家间资源流动、财富积累和游戏内经济循环的完整框架

## 2. 高层描述

经济系统是游戏的核心支撑系统,通过双轨制货币(金币、积分)、13个跑商市集、P2P交易市场和投资系统,形成资源获取、流通和消耗的完整闭环。系统采用动态定价机制、阶梯税收和多重防护措施,在保证交易自由的同时控制通胀、防范作弊。主要特点包括:

- **货币双轨制**: 金币用于日常交易,积分用于高端装备兑换
- **多元收入渠道**: 跑商(差价交易)、打工(稳定收入)、投资(高风险高收益)、P2P交易(玩家间买卖)
- **智能价格调控**: 财富指数联动、供需因子动态调整、底价自动吸附
- **完善的安全机制**: 时间窗口限制、原子性事务、装备冻结、消息守卫

核心业务逻辑分布在 `plugins/xiuxian_game/economy/` 目录下,数据模型使用 SQLAlchemy ORM 实现。
