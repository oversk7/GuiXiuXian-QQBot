# 战斗系统概述

## 1. Identity

- **What it is:** 一个基于回合制的完整战斗引擎,集成了属性系统、效果系统和装备系统。
- **Purpose:** 提供玩家vs怪物(PvE)、玩家vs玩家(PvP)的战斗能力,支持多样化的战斗效果、触发机制和装备驱动特性。

## 2. High-Level Description

战斗系统是《GuiXiuXian2》的核心系统之一,负责处理所有战斗相关的逻辑。它采用回合制机制,支持完整的战斗流程(初始化→回合执行→胜负判定)。系统设计高度模块化,分为战斗引擎层、效果管理层、属性计算层和接口桥接层。

**核心特性:**
- **装备驱动效果系统:** 装备提供特殊效果,按升阶等级解锁(+2阶解锁第1个效果,VIP装备0阶全解锁)
- **丰富的战斗属性:** 支持暴击、连击、反击、闪避、命中、穿透等10+种战斗属性,各有独立上限
- **灵活的触发机制:** 20+种效果类型,10+种触发类型,支持持续性效果、效果叠加、条件触发
- **复杂伤害计算:** 多阶段伤害公式,支持真伤、穿透、防御减伤、斩龙闪20%必中拆分
- **PvP切磋系统:** 无损战斗,不影响实际状态,支持随机种子实现可重现战斗

**系统集成:**
战斗系统通过桥接模式(BattleEffectBridge)与效果系统的IEffect接口集成,同时保留现有的BattleEffectManager的优秀设计。装备配置通过YAML定义,系统启动时自动解析并注册到效果注册中心(EffectRegistry)。
