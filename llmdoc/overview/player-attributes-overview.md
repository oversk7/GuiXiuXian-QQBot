# 玩家与属性系统概述

## 1. Identity

- **What it is**: 诡修仙2核心玩家数据管理和属性计算系统
- **Purpose**: 管理玩家角色生命周期、属性成长、境界晋升和转生机制

## 2. High-Level Description

玩家与属性系统是诡修仙2的核心模块,采用分层架构设计,包含数据模型层、仓储层、服务层和命令处理层。系统实现了完整的玩家生命周期管理,从角色创建、修炼成长、境界突破到冥返转生的完整循环。

**核心职责**:
- **数据管理**: 维护玩家基础信息、属性、坐标、社交关系等30+字段
- **属性计算**: 统一的属性计算框架,支持装备、丹药、VIP、buff等多来源加成
- **境界系统**: 35个预设境界+动态扩展境界,支持转数前缀显示
- **转生机制**: 冥返系统保留永久加成,转数提供属性点和效率加成
- **服务接口**: Repository+UnitOfWork+DI架构,提供高性能数据访问

**关键特性**:
- **双轨架构**: Legacy静态方法服务与DI架构服务平滑共存
- **缓存优化**: 60秒TTL缓存减少90%临时buff查询
- **属性持久化**: 装备加成预计算并持久化到player表
- **自动迁移**: 启动时自动升级数据库结构,零停机部署
