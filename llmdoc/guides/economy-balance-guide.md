# 如何维护经济系统平衡

经济系统平衡需要综合运用货币政策、税收工具和监控手段,在保持玩家活跃度的同时控制通胀、防范作弊。以下是维护经济平衡的实用指南。

1. **监控财富指数**: 财富指数(_get_wealth_scale)基于全服前100名玩家金币中位数计算,范围1.0-3.0,影响所有物品底价。
   - 计算公式: `scale = 1.0 + (median_wealth / 5_000_000_000)^0.3 * 0.3`
   - 指数>2.5: 高玩财富过度集中,考虑增加金币消耗渠道
   - 指数<1.2: 全服财富不足,可考虑增加跑商奖励或降低税率
   - 使用EMA平滑(0.15系数)降低敏感度,避免短期波动

2. **调整税收参数**: 阶梯税收(calculate_transaction_tax)是控制通胀的主要工具,通过`plugins/xiuxian_game/economy/market.py:57-75`修改税率。
   - 当前设置: [5000, 20000, 50000, 100000] -> [0%, 5%, 10%, 15%, 20%]
   - 提高税收: 增加>100000交易的税率至25%,抑制大额交易
   - 降低税收: 降低门槛或税率,鼓励交易活跃度
   - 免税门槛: 提高至10000可鼓励新手交易

3. **分析价格倍率**: 经济倍率(ECONOMY_MULT_BY_TYPE/RARITY)在`plugins/xiuxian_game/economy/market.py:86-100`配置,影响物品底价计算。
   - 当前设置: MATERIAL=0.7, GEM=2.0, EQUIPMENT=4.0
   - 降低宝石倍率: 从2.0降至1.5,降低宝石交易门槛
   - 提高材料倍率: 从0.7升至1.0,增加材料价值
   - 稀有度倍率: white=1.0, orange=1.3,考虑扩大差异至1.5

4. **检查供需因子**: 供需因子(MarketState.demand_factor/supply_factor)在`plugins/xiuxian_game/models/market_state.py:104-152`中更新,影响跑商价格。
   - 购买操作: demand_factor += quantity * 0.01 (最高1.6)
   - 出售操作: supply_factor += effective_qty * 0.005 (最高1.6)
   - 每日回归: 20%回归至1.0,避免价格长期偏离
   - 异常检测: factor>1.5表示该商品在当前市场过热/过冷

5. **监控金币总量**: 定期查询数据库统计全服金币总量和分布,识别异常增长。
   - 统计前10名玩家持有比例,>50%表示财富集中度过高
   - 统计月度金币增长率,>30%表示通胀压力大
   - 统计日均税收回收额,评估税收政策效果

6. **防范刷钱行为**: 通过交易记录(TradeRecord)和时间窗口限制检测异常交易模式。
   - 4小时同地点限制(`plugins/xiuxian_game/economy/merchants.py:633`): 防止原地快速买卖套利
   - 8小时挂牌限制(`plugins/xiuxian_game/economy/market.py:302`): 防止通过挂牌给小号转移商品
   - 异常检测: 单日单玩家交易>100万金币、频繁大额转账、IP关联多账号

7. **调整财富基线**: 财富基线(WEALTH_BASELINE=5_000_000_000)在`plugins/xiuxian_game/economy/market.py:104`设置,影响财富指数敏感度。
   - 提高基线至100亿: 降低财富指数对高玩的敏感度,抑制底价上涨
   - 降低基线至30亿: 提高敏感度,更快响应通胀
   - 调整指数: WEALTH_GAMMA=0.3,提高至0.5使底价更快响应

8. **优化消耗渠道**: 增加金币消耗渠道,平衡货币创造速度。
   - 装备强化/修复: 主要消耗,确保成本与玩家收益匹配
   - 护航费用: 高级玩法消耗,调整费用结构
   - 公会捐献: 金币转积分,比例1:0.7可调整
   - 考虑新增消耗: 奢侈品、特殊服务、金币回收活动

9. **分析市场流动性**: 通过MarketOrder和TradeRecord数据评估市场健康度。
   - 订单成交率: 成交订单/总订单,<30%表示流动性不足
   - 平均成交时间: 挂牌到成交的时间,<1小时表示流动性好
   - 价格差异率: (最高价-最低价)/平均价,>100%表示定价混乱

10. **应急调控措施**: 出现严重通胀或经济危机时采取临时措施。
    - 暂停税收: 降低税率至0%,刺激交易(短期)
    - 提高底价: 临时调高WEALTH_SMIN至1.5,快速拉高物价
    - 金币回收活动: 推出限时高价商品,回收过剩金币
    - 财富重分配: 通过特殊机制向低收入玩家发放金币

**定期监控指标**:
- 每日: 金币总量、交易量、税收回收额、财富指数
- 每周: 通胀率(物价指数)、玩家平均金币持有、市场活跃度
- 每月: 财富集中度(Gini系数)、新增玩家留存率、异常交易数量

**告警阈值建议**:
- 财富指数>2.8: 严重通胀预警
- 前10名持有>60%金币: 财富集中预警
- 单日交易>100万/玩家: 刷钱预警
- 月金币增长>40%: 通胀失控预警
