# 除夕叩门 -- 新年限时活动策划案

> **版本**: v4.2
> **状态**: 策划完成，待实现
> **创建日期**: 2026-02-12

---

## 1. 活动概要

| 项目 | 内容 |
|------|------|
| 活动名 | 除夕叩门 |
| 活动时长 | 48小时（可配置，测试时可缩短） |
| 核心玩法 | 大都会地图刷新诡事点 → 玩家前往坐标击杀鬼怪 → 获得碎片兑换奖励 |
| 辅助机制 | 限时命令【鬼域瞬移 x y】解决新手移动慢的问题 |
| 奖励定位 | 丰厚节日福利（经验/金币/限定称号/限定纪念品） |

### 活动背景

> *除夕夜，阴阳界薄如蝉翼。缉邪司总部紧急通报：大都会多处出现异常诡象——有居民听到敲门声后再未开门，有路灯下出现无人认领的愿望贴纸，有修士在通讯中提到某个字后便失去联系。经查实，至少三类高危厉鬼同时活跃，疑似受除夕夜阴气催动集体苏醒。缉邪司即刻发布全城甲级缉邪令，所有修士即刻响应。*

## 2. 诡事类型

基于三只原著厉鬼设计五类诡事：

### 2.1 敲门鬼系列

**原著设定**: 死寂沉闷的敲门声，门内听到声音的人会腐化死掉，死后变成敲门鬼的鬼仆在其鬼域游荡。任何听到敲门声的人都被诅咒，迟早会被找上门。曾有人将敲门声录音放到网上大量传播。

#### (1) 叩门诅咒（基础）

- **NPC名**: `鬼仆·{名字}`
- **说明**: 被敲门鬼诅咒死后沦为仆从的亡者残骸
- **强度**: 基础
- **叙事池**:

```
1. "{地名}老宅区，住户连续三夜听到沉闷敲门声。第一夜后指甲发黑，第二夜后左臂皮肤大面积溃烂。敲门声仍在继续。"
2. "{地名}出租屋内发现一具尸体，面部完全腐烂，但死者手机通话记录显示，死前最后一句话是：'有人在敲门，我去开——'"
3. "{地名}街道监控拍到异常画面：凌晨三点，一个没有面孔的人形站在某户门前，缓缓抬手，叩了三下。门内随即传出惨叫。"
```

#### (2) 鬼域渗透（中等）

- **NPC名**: `渗界仆从·{名字}`
- **说明**: 从敲门鬼鬼域裂隙中爬出的亡者
- **强度**: 中等
- **叙事池**:

```
1. "{地名}地面出现一道细长裂缝，透过裂缝能看到灰色的另一个世界——和这里一模一样的街道，但所有窗户都是黑的，街上游荡着面目模糊的人影。有东西正在往外爬。"
2. "{地名}居民报告：家中镜子映出的不再是自己的房间，而是一条灰暗的走廊，走廊尽头有无数人影在排队——排队走向一扇门。镜面开始往外渗水。"
```

#### (3) 录音扩散（中等）

- **NPC名**: `咒音残响·{名字}`
- **说明**: 录音中凝聚成形的敲门声实体
- **强度**: 中等
- **叙事池**:

```
1. "紧急！修士通讯频道被投放了一段音频，内容为三声沉闷的敲门声。已有数十人收听。所有听过的人反馈：耳鸣不止，且每到深夜就能听到自家门外有东西在敲。"
2. "{地名}发现一台循环播放敲门声的老式收音机，无法关闭，无法断电，砸碎后碎片仍在发出声响。周围三条街的住户均已出现腐化症状。"
```

### 2.2 路灯鬼系列

**原著设定**: 路灯闪烁，路灯下站着一个低垂着头背对你的黑影，以愿望贴纸为媒介，可以以扭曲的方式实现任何愿望，但会死掉一个亲人。可以重启自身状态到40分钟前，几乎不败。

#### (4) 愿望贴纸（精英）

- **NPC名**: `灯下黑影·{名字}`
- **说明**: 路灯鬼留下的分身/投影
- **强度**: 精英
- **特殊机制**: 被攻击后有概率"重启"恢复30%HP（模拟原著40分钟重启能力），最多触发1次
- **重启战斗文案**: *"黑影的轮廓模糊了一瞬——仿佛时间倒退，它的伤口正在愈合。路灯闪了一下。"*
- **叙事池**:

```
1. "{地名}路灯下发现散落的愿望贴纸。一张写着'希望父亲的手术顺利'，背面用血写着'已达成——代价：母亲'。路灯下那个低头的黑影仍然站在那里。"
2. "{地名}路口，路灯以不规律频率闪烁。有修士报告：灯灭的瞬间，能看到一个背对自己的黑色人影；灯亮时人影消失，但地上多了一张空白贴纸和一支笔。"
```

### 2.3 "静悄悄"系列

**原著设定**: 诡异小女孩，穿脏污连衣裙，浑身淤青，两个漆黑空洞的眼眶，没有鼻子嘴巴，仅余一双耳朵。唯心类厉鬼，只要世界上有人提及"鬼"这个概念，就会生成一具分身瞬间出现进行攻击，无限分身，不论时间空间，无解。

#### (5) 禁字之祸（Boss级）

- **NPC名**: `禁字之祸·{名字}`
- **说明**: "静悄悄"的物质化分身
- **强度**: Boss级
- **特殊机制**: 战斗中附加"禁声"debuff——玩家本次战斗暴击率和连击率各降低10%（你不敢出声）
- **叙事池**:

```
1. "{地名}出现甲级诡象。一名修士在通讯中说了那个字，话音未落，身边凭空出现一个脏兮兮的小女孩——没有鼻子和嘴巴，只有两个漆黑的眼洞和一双耳朵。修士当场重伤。它在听。"
2. "{地名}学堂内，一名教书先生在课上讲到某个字时，教室角落里多了一个人。所有孩子都看到了她——穿着脏污连衣裙，浑身淤青，空洞的眼眶对着先生的方向。现在整间学堂被封锁。"
```

| 奖励 | 公式 | 说明 |
|------|------|------|

### 4.3 活动商店（碎片兑换）

设计原则：
1. **分层定价** — 低碎片日耗品保证每日参与体验，高碎片限定物品作为48小时总目标
2. **不卖已有物品原物** — 活动专属丹药/物品，避免冲击现有经济（升阶石等除外，因为本身就是硬通货）
3. **限定收藏 > 数值膨胀** — 最贵的东西是称号和纪念品，不是数值碾压道具

#### 碎片消耗验算（活跃玩家约100碎片为例）

```
方案A「实用派」:
  升灵丹 x8/天x2天 = 80碎片(5x16)   → 剩20
  回生丹 x5 = 30碎片(6x5)            → 超支，需降低
  → 实际：升灵丹x6/天(60) + 回生丹x3/天(36) = 96碎片 ✓

方案B「成长派」:
  血心丹 x3/天x2天 = 72碎片(12x6)
  中级升阶石 x1 = 25碎片
  → 合计97碎片 ✓

方案C「收藏派」:
  封门人称号 = 150碎片 → 需要肝帝级别参与
  或：叩门者残骸(80) + 敲门鬼的指骨(30) = 110碎片 → 活跃玩家刚好够

方案D「PVP派」:
  三级暴击佛珠x2(70) + 三级穿透水晶x1(35) = 105碎片 ✓

方案E「餐厅老板」:
  绿色食谱全5个(40) + 蓝色食谱x3(56) + 紫色食谱x1(40) = 136碎片 → 需肝帝级别
  或：绿色全5个(40) + 蓝色x2(36) = 76碎片 ✓ 活跃玩家可达
  或：绿色全5个(40) + 升灵丹x6/天(60) = 100碎片 ✓ 食谱+经验两不误
```

结论：100碎片左右的玩家必须做出取舍（不可能全买），形成有意义的选择；称号需要肝帝级别投入（150碎片），具有稀缺性。食谱全买需136碎片，与称号(150碎片)同属肝帝级目标，但活跃玩家可以通过取舍获得大部分绿色+部分蓝色食谱。

## 5. 鬼域瞬移（限时命令）

### 设计目的

现有导航速度 = `敏捷 / 2500` 格/秒，新手（敏捷~15）约0.006格/秒，走100格需要约4.6小时。活动期间提供限距瞬移解决这个问题。

### 命令规格

```
【鬼域瞬移 x y】
```

| 参数 | 值 |
|------|------|
| 瞬移范围 | 当前位置曼哈顿距离 <= 100格 |
| 冷却时间 | 3分钟 |
| 限制条件 | 仅限大都会区域 + 活动期间 + HP>0 |
| 坐标范围 | -500 ~ 500 |

### 文案

> *空间扭曲——你踏入一道短暂的裂隙，眨眼间已身处({x},{y})。裂隙在身后无声合拢。*

## 8. 技术实现

### 8.1 文件结构

```
plugins/xiuxian_game/event/
├── __init__.py           # 命令注册(除夕活动/鬼域瞬移/叩门排行/活动商店)
├── knocker_event.py      # 核心: 诡事刷新/击杀回调/进度/排行
└── knocker_config.py     # 配置: 诡事类型/叙事文本池/奖励参数
```

追加修改:
- `data/items.yaml` — 新增 knocker_shard, knocker_relic
- `player/help.py` — 新增活动命令帮助

### 8.2 复用的现有系统

| 功能 | 复用模块 |
|------|---------|
| 鬼怪NPC生成 | `DailyTaskService.create_ghost_npc_for_task()` 模式 |
| 坐标范围校验 | `navigation.py` 的 MAX_COORD 常量 |
| PvE战斗 | `BattleIntegrationHelper.enhanced_player_vs_monster_battle_v2()` |
| 物品/背包管理 | `ItemInstance.add_item()` |
| 属性计算公式 | `DailyTaskService._calculate_enemy_stats()` |

### 8.3 新建核心逻辑

- 定时刷新诡事点（APScheduler 或简单时间检查）
- 鬼域瞬移命令（坐标校验 + 距离限制 + 冷却）
- 活动商店（碎片兑换）
- 击杀回调（活动NPC被杀时发放奖励 + 碎片）

### 8.4 数据存储

使用 `player.extra_attrs` JSON字段存储活动数据，无需数据库迁移：

```python
player.extra_attrs = {
    "knocker_event": {
        "shards": 0,           # 碎片数量
        "kills": 0,            # 击杀总数
        "last_teleport": 0,    # 上次瞬移时间戳
        "purchased": {}        # 已兑换记录
    }
}
```

## 9. 经济影响预估（50人参与）

### 直接金币流入

| 来源 | 计算 | 预估总量 |
|------|------|---------|
| 击杀金币产出 | 50人 x 平均20次击杀 x 平均800金币 | ~800,000 |
| Boss击杀金币 | 约10次Boss被杀 x 1925金币 | ~19,250 |
| **净金币流入** | | **~820,000（人均约16,400）** |

### 碎片兑换物品价值（非直接金币）

| 物品类别 | 估算 | 等价金币价值 |
|---------|------|------------|
| 经验丹(升灵丹+血心丹) | 50人 x 平均6个升灵+2个血心 | ~2,400,000（参考底价） |
| 升阶石(初级+中级) | 50人 x 平均2初级+0.5中级 | ~500,000（参考积分换算） |
| 永久属性丹 x3种 | 约30人各买1~2个 | ~难以金币化，约+2~4属性点/人 |
| 宝石(暴击佛珠+穿透水晶) | 约15人买1~2个 | ~900,000（参考底价） |
| 稳定水晶 | 约10人各买1个 | ~等价10000积分/人 |
| 食谱(绿/蓝/紫) | 约20人买食谱，平均5~8个/人 | ~无直接金币价值，但解锁后菜肴售价320~3500金/份，长期餐厅收入提升 |

### 总结

| 指标 | 值 | 对比 |
|------|-----|------|
| 净金币流入 | ~82万 | 人均1.6万，约2.5天打工收入 |
| 经验产出(击杀+丹药) | ~500万 | 人均10万exp，约2天修炼量 |
| 永久属性影响 | 每人最多+6/+6/+6 | 远小于一次转生加成(数十点) |
| 稀有材料流出 | 约10个稳定水晶+宝石若干 | 可控，等价约10万积分 |
| 食谱解锁 | 约20人解锁5~9个食谱 | 首次开放高级食谱获取渠道，激活餐厅系统中高端内容，长期利好但不直接注入金币 |

结论：金币流入比v4.0估算更低（因为商店消耗碎片而非金币），主要价值在**限定物品**、**成长加速**和**餐厅食谱解锁**，对经济平衡的冲击极小。食谱作为永久解锁内容提供了长线价值，鼓励玩家发展餐厅经营这一经济子系统。
