# FA012符箓气运重命名实施报告

**实施日期**: 2025-01-05
**问题**: FA012"符箓气运"价格1741金币,被玩家质疑过高
**解决方案**: 重命名为"天工符箓",避免与TECH03"符箓制作"混淆

---

## 📊 问题分析

### 玩家疑问
> "符隶的价格怎么这么高，合理吗"

### 价格对比
| 气运代码 | 名称 | 基础价格 | 当前价格 | 类型 |
|---------|------|---------|---------|------|
| FA012 | **符箓气运** | 1500金币 | 1741金币 | 💎高端 |
| TECH03 | 符箓制作 | 80金币 | 62金币 | 📊普通 |
| TECH01 | 法宝工坊 | 100金币 | 88金币 | 📊普通 |
| TECH02 | 阵法研究 | 150金币 | 133金币 | 📊普通 |

### 异常原因
**名称混淆**:
- TECH03"符箓制作"(80金币) - **普通气运**
- FA012"符箓气运"(1500金币) - **高端气运**

玩家看到两个都带"符箓"的气运,价格相差**21.8倍**,产生困惑。

### 实际情况分析
经过深入分析,发现**价格其实合理**:

1. **两套气运体系**:
   - **初始12个气运** (stock_commands.py): 60-200金币,新手友好
   - **重新上市气运** (stock_relist_service.py): 700-1500金币,老玩家高端

2. **FA012涨幅正常**:
   - 基础1500金币 → 当前1741金币
   - 涨幅: (1741-1500)/1500 = **+16%**
   - 在正常波动范围内(±15%)

3. **如果降价到80金币**:
   - 持仓FA012的玩家将亏损**95%**
   - 不符合设计初衷

---

## ✅ 解决方案: 方案2 - 调整名称

### 实施内容

#### 1. 数据库修改
**SQL脚本**: `scripts/rename_fa012_stock.sql`

```sql
-- 更新FA012的名称
UPDATE stocks
SET name = REPLACE(name, '符箓', '天工符箓')
WHERE symbol = 'FA012';
```

**效果**:
- "符箓气运" → "天工符箓气运"
- 突出高端定位,避免混淆

#### 2. 帮助文档更新
**文件**: `player/help.py:154-159`

新增内容:
```
💎 气运价格分层说明：
• 📊 普通气运（TECH01-FIN02等）：基础60-200金币，适合新手
• 💎 高端气运（FA0XX系列）：基础700-1500金币，适合老玩家
• 例：TECH03符箓制作(80金币) vs FA012天工符箓(1500金币)
  - 名称相似但定位不同，请注意区分
```

**效果**:
- 明确告知玩家两套气运体系
- 用具体例子说明区别
- 避免未来混淆
