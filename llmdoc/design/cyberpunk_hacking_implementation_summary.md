## 关键设计决策

### 1. 为什么选择3-5条路径?
**理由**:
- 单条路径匹配概率<0.2%, 不可接受
- 3条路径理论概率×3≈0.6%, 加路径多样性优化≈15-20%
- 4-5条路径进一步提升覆盖，但收益递减
- **平衡点**: 3-5条路径，生成时间<300ms

### 2. 为什么限制重叠<40%?
**理由**:
- 100%多样性(0%重叠): 难以生成足够长的不同路径
- 60%重叠: 路径过于相似，多样性无意义
- **40%重叠**: 平衡多样性与可生成性的最优点

### 3. 为什么使用"安全符文池"?
**理由**:
- 旧问题: 随机填充可能在路径附近放置目标符文，造成干扰
- 新方案: 接近路径(<2格)用不在目标中的符文, 避免混淆玩家
- **效果**: 玩家不会因干扰符文而走错路径

### 4. 为什么排列组合要全部尝试?
**理由**:
- 旧限制: 仅6种排列，6x6的4!=24种只覆盖25%
- 新做法: 全部尝试，确保找到最优组合
- **成本**: 24种排列, <100ms计算, 可接受

### 5. 为什么Fallback要动态化?
**理由**:
- 旧问题: 固定4步，6x6时无法覆盖5个符文的目标
- 新做法: `min(len(optimal_sequence), buffer_size)` 动态调整
- **效果**: 6x6 Fallback能放5-6个符文，100%覆盖目标

## 技术要点

### 多路径生成算法

```
步骤1: 生成最优序列 (包含所有目标, 长度<=6)
步骤2: 根据起点策略生成3-5条路径
  ├─ 路径0: 左侧起点(0 ~ size//2)
  ├─ 路径1: 右侧起点(size//2+1 ~ size-1)
  └─ 路径2+: 随机起点
步骤3: 检查路径多样性 (重叠<40%)
步骤4: 在所有路径上放置相同的最优序列
步骤5: 智能填充剩余格子 (路径附近用安全符文)
```

### 多样性检查逻辑

```python
overlap = set(new_path) & set(existing_path)  # 交集
overlap_ratio = len(overlap) / len(new_path)  # 重叠比例
if overlap_ratio > 0.4:                        # 超过40%则拒绝
    return False
```

### 路径交叉处理

```python
# 多条路径可能经过同一格子
placed_positions = {}
for each (row, col) in path:
    if (row, col) not in placed_positions:
        matrix[row][col] = expected_rune
        placed_positions[(row, col)] = expected_rune
    elif placed_positions[(row, col)] == expected_rune:
        continue  # 符文相同, 无冲突
    else:
        continue  # 符文不同, 跳过
```
