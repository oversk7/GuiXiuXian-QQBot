# 导航随机事件设计

## 1. 目标

在导航过程中加入随机事件，增加趣味性。事件在到达目的地时统一展示。

## 2. 触发机制

### 路程事件
- 每30-80格（随机间隔）触发一次判定
- 短途（<30格）不触发路程事件
- 使用确定性随机种子（`player_id + task创建时间`），同一次导航结果不变

### 到达事件
- 到达目的地时额外一次独立判定（50%概率）

## 3. 事件池

### 好事（60%概率）
| 事件 | 效果 |
|------|------|
| 路边捡到金币 | +100~500金币 |
| 发现材料 | 白/绿品质随机材料1-3个 |
| 偶遇散修切磋 | +少量经验（基于等级） |
| 发现灵泉 | +恢复咒抗10-30 |
| 遇到商旅 | +随机商品1个 |

### 坏事（40%概率）
| 事件 | 效果 |
|------|------|
| 遭遇山贼伏击 | -50~200金币（不低于0） |
| 途中迷雾 | -5~10%最大HP |
| 诡异气息侵蚀 | -咒抗5~15 |
| 遭遇野兽 | 纯文字，无实际惩罚 |

## 4. 影响强度定位

有感知但不痛：中等奖惩，让玩家关注导航过程但不会因此不敢导航。

## 5. 数据存储

不新增数据库表/字段。到达时根据 `initial_distance` 直接计算事件次数。

## 6. 代码改动

1. **新增** `plugins/xiuxian_game/world/navigation_events.py` — 事件池定义 + 结算逻辑
2. **修改** `plugins/xiuxian_game/world/navigation.py` — 到达时调用事件结算，拼接到到达消息

### 改动点详述

`navigation_events.py`:
- `generate_navigation_events(player, distance, seed)` — 根据距离和种子生成事件列表
- `apply_navigation_events(session, player, events)` — 应用事件效果到玩家
- `format_navigation_events(events)` — 格式化事件为展示文本

`navigation.py`:
- 在 `nav_cmd.handle()` 中到达逻辑处调用事件结算
- 在其他调用 `_update_nav_position` 并判断到达的位置（info.py、teleport.py、item_effects.py）也附带事件结算

## 7. 展示格式

```
🎯 已到达目标位置 上京 (120,80)
━━━━━━━━━━━━━
📖 途中见闻：
  🍀 路过荒废道观，捡到 320 金币
  ⚔️ 遭遇山贼伏击，损失 150 金币
  🌿 发现一株灵草，获得【翠灵草】×2
━━━━━━━━━━━━━
📍 当前坐标: (120,80)
✅ 导航任务已完成
```

短途无事件时不显示"途中见闻"区块。
