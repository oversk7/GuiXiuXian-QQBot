## 1. 核心定位

| 维度 | 设计 |
|------|------|
| **本质** | 诡域深处撕裂出的凝固时空，三十年前荔湾镇被诡异吞噬的瞬间被永久定格 |
| **玩家身份** | 修炼者进入后修为被压制为凡人，靠智慧和判断存活 |
| **探索方式** | 场景节点制（完全替代坐标网格），玩家在命名地点间跳转 |
| **核心体验** | 试炼故事 `ghost_town.json` 的开放世界版——自由探索旅馆、公寓、街道中的恐怖场景 |
| **等级要求** | Lv.50 |
| **死亡惩罚** | 本次试炼结束，所有物品金币清零（空手而归） |
| **与诡域关系** | 独立体系，主动传送进入，不占用诡域系统 |

### 首次 vs 重复

| | 首次通关 | 后续刷本 |
|--|---------|---------|
| **场景布局** | 固定（忠实还原试炼故事） | NPC位置随机打乱，新增怪物和宝箱 |
| **叙事文本** | 完整剧情旁白、线索提示 | 简化提示 |
| **目标** | 找到正确路径存活一晚 | 刷材料、挑战更高难度 |
| **结局** | 达成「存活到黎明」解锁后续模式 | 多结局结算不同奖励 |

### 奖励规则

- 里界专属材料 + 金币
- 专属材料**不可被扫荡令刷出**
- 死亡 = 空手而归，存活 = 按探索深度结算奖励
- 线索收集进度**全局保存**（不因死亡重置）

### 首次 vs 后续的节点差异

**首次**：节点顺序固定，按主线推进（旅馆需房卡→必须在楼道搜到房卡→必须先引诱厂服男）。分支可选探索。

**后续**：
- 主线节点保留，NPC随机分配到不同房间
- 新增2-3个随机「诡异事件」节点（从事件池抽取）
- 分支节点掉落物随机化
- 可能出现首次没有的「隐藏房间」（地下室、天台）

## 3. NPC与怪物设计

### 设计原则

修为被压制为凡人，NPC分两类：
- **凡人NPC**：可交谈/威吓/处决，杀人有理智代价
- **诡异/鬼怪**：不可正面战斗（凡人打不过），只能规避、利用或智取

### 凡人NPC

| NPC | 位置 | 性质 | 交谈 | 威吓 | 处决 | 死亡后果 |
|-----|------|------|------|------|------|---------|
| **雨衣男** | 楼道（堵门） | 杀手 | ✗ | ✗ | 2D6+敏捷(11+) | 可搜刮获得四号房卡 |
| **厂服男** | 草丛 | 变态杀手 | ✗ | ✗ | ✗ 无法处决 | 只能被引诱离开 |
| **旅馆老板** | 旅馆大厅/走廊 | 笑面杀手 | ✓ 表面友善 | ✗ 他有猎枪 | 2D6+敏捷(10+) | 猎枪归你，但枪声引来女鬼 |
| **无脸女** | 二号房 | 伪装者 | ✓ 会露出真面目 | ✗ | ✗ 不是凡人 | — |
| **学生** | 三号房 | 弑亲者 | ✓ 讲述虚假家庭故事 | 2D6+攻击(8+) | 2D6+敏捷(7+) | 获得线索，进他房间=死 |
| **老人** | 一号房/宵夜 | 变态 | ✓ 沉默寡言 | 2D6+攻击(9+) | 2D6+敏捷(9+) | 获得钥匙，可直接进一号房 |
| **厨师** | 大厅·宵夜 | 帮凶 | ✓ 介绍「宵夜」 | ✗ 和老板一伙 | 2D6+敏捷(9+) | 搜刮获得厨房钥匙 |

### 诡异/鬼怪（不可正面对抗）

| 怪物 | 出没位置 | 行为模式 | 应对方式 | 遭遇后果 |
|------|---------|---------|---------|---------|
| **提头女鬼** | 旅馆门外→宵夜时可放入 | 追杀一切活物 | 利用她清场 | 被抓=立即死亡 |
| **十字路口死神** | 十字路口 | 站在原地招手 | 保持距离搜刮，靠近=2D6(10+) | 失败理智-30 |
| **诊所幽灵儿童** | 废弃诊所 | 嬉笑跑动，脚不着地 | 可交谈获线索，不要参与捉迷藏 | 参与游戏=死亡 |
| **镜中人** | 卧室 | 镜中另一个自己 | 不看=安全 | 看了=2D6(8+)，失败理智-15 |
| **无头女鬼敲门** | 楼道/旅馆走廊 | 敲门声 | 绝对不能开门 | 开门=死亡 |
| **冰箱怪物** | 厨房密室 | 闭眼等待喂食 | 喂牙齿→苏醒→和提头女鬼互杀 | 不喂=无法通关，喂早了=被老板打死 |
| **笑面狗** | 随机（入夜后） | 床底喘息声 | 2D6+幸运(7+) | 失败理智-10，低理智时出现频率增加 |

### NPC互动增强

**交谈** — 对话树，多次交谈解锁不同信息（非随机选一句）。

**搜刮** — 每场景有固定可搜刮物品列表，2D6+幸运判定：
- 大成功(12+)：全部物品 + 隐藏物品
- 成功(10-11)：主要物品
- 普通(7-9)：部分物品
- 失败(4-6)：无 + 发出声响（可能引来危险）
- 大失败(2-3)：触发陷阱/惊动NPC

**观察** — 场景首次进入只有基本描述，【观察】后发现隐藏细节和「细思极恐」的叙事线索。

| 6 | 老人妻子的日记 | 一号房·搜刮 | 被囚禁、拔牙、饥饿的全过程记录 | 老人把妻子关在密室 |

- 线索通过搜刮、交谈、观察获取（非随机CLUE格子）
- 收集进度**全局保存**，不因死亡重置
- 鼓励多次尝试逐步发现所有线索

| 结局 | 触发条件 | 描述 | 奖励倍率 |

## 7. 补充说明（Spec Review 修复）

### 7.1 宵夜事件的触发机制

`lobby_midnight`（大厅·宵夜）不是自由前往的节点。触发条件：
- 玩家在 `room_4`（四号房）执行【观察】或等待（经过一定操作次数后）
- 系统提示"凌晨十二点，宵夜时间到了"
- 自动触发宵夜事件，玩家进入 `lobby_midnight` 场景

`room_1`（一号房）的到达路径：在宵夜事件中，坐在桌子最外侧 → 趁乱逃入老人房间。不可从走廊直接前往。

### 7.2 黄昏/入夜阶段切换精确规则

- `move_count` 在**到达新场景时**递增（即 `enter_scene` 成功后）
- 第5次移动到达的场景仍属黄昏阶段，玩家可在该场景自由操作
- **第6次移动时**，如果目标是户外节点（`type: "outdoor"`），移动被阻止并触发死亡叙事："天已经完全黑了。你踏出建筑的那一刻，黑暗中伸出无数只手——"
- 场景节点配置中用 `outdoor: true/false` 标记是否为户外
- 入夜后所有 `outdoor: true` 的节点从可前往列表中移除（【前往】命令不显示）

### 7.3 `InnerRealmTile` 表处置

不执行 DROP TABLE。保留表结构但新代码不再使用：
- `x`, `y` 字段同理保留，新代码不再读写
- 场景状态存储在 `session.state` JSON 中，结构如下：

```json
{
  "scene_states": {
    "home": {"searched": true, "npc_alive": true, "items_found": ["needle_thread"]},
    "room_1": {"searched": false, "npc_alive": true}
  },
  "npc_states": {
    "raincoat_man": {"alive": true, "location": "hallway"},
    "hotel_owner": {"alive": true, "location": "hotel_lobby"}
  },
  "events_triggered": ["mirror_event", "phone_event"],
  "phase": "night",
  "boss_defeated": false
}
```

### 7.4 线索全局保存机制

线索存储分两层：
- **会话级** `session.clue_collected`：本次探索发现的线索（死亡时随会话结算）
- **玩家级** `Player.inner_realm_clears` JSON：累积发现的线索，格式：

```json
{
  "liwan_ghost_town": {
    "cleared": true,
    "clues_found": ["clue_1", "clue_2", "clue_5"]
  }
}
```

每次发现新线索时，同时写入会话和玩家全局记录。死亡不影响玩家级记录。
【查看线索】命令显示的是玩家级全局记录（所有历次探索的累积）。

### 7.5 里界内道具 vs 持久化材料

两类物品存储方式不同：

| 类型 | 存储位置 | 死亡时 | 离开时 |
|------|---------|--------|--------|
| **关键道具**（针线、房卡、罐头、牙齿、日记） | `session.inventory` JSON | 随会话清零 | 自动消失 |
| **专属材料**（血迹房卡、无脸人皮等6种） | 正常 `inventory` 表 | **清零**（空手而归） | 保留，按结局倍率结算 |
| **金币** | 正常 player.gold | **清零本次所得** | 保留，按结局倍率结算 |

实现方式：探索过程中材料/金币先记录在 `session.state["pending_rewards"]` 中，只有存活结算时才真正发放到玩家背包。死亡时不发放。

### 7.6 屠镇者结局的精确条件

需要击杀的凡人NPC列表（排除非凡人）：
- `raincoat_man`（雨衣男）
- `hotel_owner`（旅馆老板）
- `student`（学生）
- `old_man`（老人）
- `chef`（厨师）

共5人。厂服男（只能引诱）和无脸女（非凡人）不计入。
条件：`killed_count >= 5 AND 以上5人全部dead`，且玩家存活到达 `town_entrance_dawn`。

### 7.7 `ghost_town.json` 试炼故事共存策略

保留 `ghost_town.json` 不删除。两个系统并存：
- 原版试炼故事：通过故事引擎系统（`story/engine.py`）触发，线性选择分支
- 里界版荔湾：通过里界系统（`inner_realm/`）触发，开放世界探索

两者面向不同玩法需求，不冲突。里界版不依赖 `ghost_town.json` 的代码，只是叙事上参考其世界观。

### 7.8 凡人状态下的属性修正

修为压制后，骰子判定的属性修正按以下公式计算：

```python
# 凡人状态下，属性修正值 = 基于玩家等级的固定加成（非实际属性）
# 保证所有玩家在里界内的判定能力大致相同
modifier = min(3, player.level // 100)  # Lv.50=0, Lv.100=1, Lv.200=2, Lv.300+=3
```

最大修正值为+3，保证鬼镇的难度不会被高等级玩家碾压。

### 7.9 扫荡令排除机制

优先使用现有的标签过滤机制。在 `items.yaml` 中为6种专属材料添加 `tags: ["inner_realm_exclusive"]`，扫荡逻辑中已有对应的过滤代码。硬编码列表 `INNER_REALM_EXCLUSIVE_ITEMS` 作为第二道防线保留。

### 7.10 理智归零的检查时机

理智归零时不立即结算。在**下一次操作**（移动/搜刮/交谈等）时触发结局叙事：

```
你蹲在地上，双手抱头。周围的一切都在旋转——
墙壁在呼吸，地板在蠕动，天花板上的裂缝组成了一张笑脸。
你发出一声大笑，然后什么都不记得了。
━━━━━━━━━━━━━
🧠 理智崩溃 · 试炼失败
```

给玩家一个"最后挣扎"的回合（比如使用过期罐头恢复理智）。

### 7.11 会话生命周期

- 每次进入创建新会话，不复用旧会话
- 存活结算或死亡后，会话标记 `is_settled = True`
- `scheduler.py` 的清理逻辑保持不变（7天后删除已结算会话）
- 玩家同一时间只能有一个活跃会话
