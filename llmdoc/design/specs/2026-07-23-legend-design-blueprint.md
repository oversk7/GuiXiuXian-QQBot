## 一、属性体系

### 1.1 基本属性（9 项 + 2 项扩展职业）

| 属性 | 作用 | 主受益职业 |
|------|------|-----------|
| **攻击** | 影响物理攻击和物理技能伤害 | 战士 |
| **魔法** | 影响魔法攻击和魔法技能伤害 | 法师 |
| **道术** | 影响道术攻击和道术技能伤害 | 道士 |
| **刺术** | 影响刺术攻击和刺术技能伤害 | 刺客 |
| **弓术** | 影响弓术攻击和弓术技能伤害 | 弓手 |
| **防御** | 减少受到的*挥砍（物理）*伤害 | 通用 |
| **魔防** | 减少受到的*魔法/道术*伤害 | 通用 |
| **体力值 HP** | 角色生命，归零则死亡 | 通用 |
| **魔法值 MP** | 施放技能消耗，归零无法释放技能 | 法师/道士 |
| **幸运** | 提高攻击时打出**伤害上限**的概率 | 通用（详见公式节） |

> **核心设计要点：** 传奇的攻击属性显示为"区间"（如攻击 45-120），每次出手在区间内随机取值。幸运值决定取值偏向上限的概率——这是传奇最独特的伤害机制，所有追求都围绕"稳定打出上限"展开。

### 1.2 进阶属性（攻击侧 7 项 + 防御侧 9 项 + 特殊 7 项）

**攻击属性：**

| 属性 | 效果 |
|------|------|
| 破物防 | 忽略对方部分物理防御 |
| 破魔防 | 忽略对方部分魔法防御 |
| 准确度 | 提高挥砍命中率 |
| 暴击率 | 攻击造成更高伤害的概率 |
| 暴击伤害 | 暴击时额外提升的伤害量 |
| 伤害加成 | 百分比增加自身总输出 |
| 攻击速度 | 普通攻击的出手频率 |

**防御属性：**

| 属性 | 效果 |
|------|------|
| 敏捷度 | 闪避挥砍类攻击 |
| 魔法躲避 | 闪避魔法/道术攻击 |
| 减暴击 | 降低被暴击的概率 |
| 减暴伤 | 降低被暴击时受到的伤害 |
| 中毒躲避 | 抵抗中毒效果 |
| 物理抗性 | 百分比减少物理伤害 |
| 魔法抗性 | 百分比减少魔法伤害 |
| 定身抵抗 | 降低被定身的概率 |
| 减速抵抗 | 降低被减速的概率 |

**进阶特殊属性：**

| 属性 | 效果 |
|------|------|
| **神圣伤害** | 无视防御直接追加固定伤害（类似真伤），范围技有衰减，召唤物不受益 |
| 物理击回 | 物理攻击命中时按主属性比例回复 HP（物理吸血） |
| 魔法击回 | 魔法攻击命中时按主属性比例回复 HP（魔法吸血） |
| 减速强化 | 攻击概率使目标移速降低 50%，持续 2 秒 |
| 定身强化 | 攻击概率定身目标 |
| 灼烧强化 | 魔法攻击概率灼烧（持续 3 秒 DoT） |
| 流血强化 | 物理攻击概率流血（持续 3 秒 DoT） |

## 二、伤害公式与幸运机制

### 2.1 基础伤害计算（经典端游）

传奇的伤害计算核心是**减法模型**——攻击减防御，不是 RPG 常见的比例减伤：

```
实际伤害 = 攻击力（区间随机取值）- 对方防御（区间随机取值）
最低保底 = 0（不造成伤害）

攻击力区间：角色面板显示 "攻击 X-Y"
每次出手在 [X, Y] 之间随机取值
幸运值影响此随机取值偏向 Y（上限）的概率

玩家解析示例（端游战士 PK）：
战士攻击 76，对手防御 16
→ (76 / 2.6 - 16) ≈ 13.2 → 取整后 ×系数
中红毒（施毒术）时额外 ×1.2 系数

技能伤害公式（端游 Magic.DB）：
技能伤害 = 主属性值 + 技能常数
示例：小火球 = 魔力 + 11，地狱火 = 魔力 + 21
刺杀剑术二段伤害无视防御（真伤）
```

> **物理 vs 魔法 vs 道术：** 三种伤害类型分别由攻击/魔法/道术属性驱动，分别被防御/魔防减免。物理攻击被"防御"抵消，魔法和道术攻击被"魔防"抵消——这意味着高防低魔防的战士天然被法师克制。

### 2.2 幸运值机制（传奇核心设计）

```
打出攻击上限的概率 = 1 / (10 - 幸运值)

幸运 0 → 1/10 = 10% 概率打出上限
幸运 3 → 1/7 ≈ 14%
幸运 5 → 1/5 = 20%
幸运 7 → 1/3 ≈ 33%
幸运 8 → 1/2 = 50%
幸运 9 → 1/1 = 100%（刀刀上限，俗称"运9"）
```

幸运来源：武器通过喝**祝福油**提升（有失败/降级风险），项链天生自带幸运属性（白色虎齿项链 +2 幸运是经典搭配）。武器幸运 + 项链幸运 = 总幸运值。

**诅咒值**是幸运的反面：增加打出攻击*下限*的概率。武器喝祝福油失败可能获得诅咒。诅咒 10 的武器几乎刀刀下限。

> **设计启示：** "运9"机制创造了传奇最核心的追求循环——所有玩家都在追求稳定输出上限。这比简单的"攻击力+N"有趣得多：它让伤害从"随机"变"稳定"，而非从"低"变"高"。对标到新项目：可以设计类似"从不稳定→稳定"的追求轴，而非永远向上的数值膨胀。

### 2.3 传奇永恒扩展公式

```
最终伤害 = (攻击区间取值 - 防御减免) × (1 + 伤害加成%) × 暴击倍率
           + 神圣伤害（无视防御）

防御减免：被"破物防/破魔防"（穿透）削减后的有效防御
暴击倍率：暴击时额外乘以 (1 + 暴击伤害%)
神圣伤害：直接追加，不受攻方幸运/技能/BUFF 加成，不受守方防御减免
```

## 三、装备部位与套装

### 3.1 装备部位（经典端游 10 个穿戴位）

| # | 部位 | 主要属性方向 | 特殊说明 |
|---|------|-------------|---------|
| 1 | **武器** | 攻击/魔法/道术 | 职业专属；可升级（祝福油加幸运、黑铁矿石升品）；发光特效（+5 起） |
| 2 | **衣服/盔甲** | 防御、HP | 职业专属（战士重甲/法师法袍/道士灵衣）；影响角色外观 |
| 3 | **头盔/斗笠** | 防御、魔防 | 部分通用，部分职业限定 |
| 4 | **项链** | 魔法/道术 + 幸运 | 幸运属性主要来源之一（白色虎齿 +2 幸运） |
| 5-6 | **戒指 ×2** | 攻击/魔法/道术 | 可穿戴两枚，属性叠加 |
| 7-8 | **手镯/护腕 ×2** | 攻击/魔法/防御 | 可穿戴两件，属性叠加 |
| 9 | **腰带** | HP、防御 | 雷霆版本后新增 |
| 10 | **鞋子/靴子** | 敏捷、魔防 | 雷霆版本后新增 |
| 11 | **勋章** | 综合属性 | 铭文系统载体；激活魂链起点 |
| — | 盾牌（战士） | 防御、魔防 | 仅战士可用，部分版本 |

> **铭文系统（传奇永恒）：** 10 件装备形成激活链（勋章→武器→护腕→项链→戒指→衣服→面巾→头盔→鞋子→腰带→勋章），每件装备通过"铸魂"获得一条龙卫魂链 + 一条铭文（飞云/玄天/星罗/寒月/血阳 五种），按顺序依次激活获得属性加成。

## 四、装备强化系统

### 4.1 武器升级（经典核心玩法）

| 要素 | 说明 |
|------|------|
| NPC | 三爷（武器升级） |
| 材料 | 本职业首饰 + 黑铁矿石 + 金币 |
| 上限 | +9（+5 起武器发光） |
| 失败后果 | **武器碎裂消失**，材料不退还 |
| 成功率影响 | 首饰属性总和（攻击上限+下限之和）+ 人物升级武器幸运值（时间段内波动） |
| 黑铁矿石 | 不影响成功率，只影响武器**持久度**（纯度 15-16 最佳，保证不掉持久） |

> **垫刀机制：** 玩家通过先用低级武器+低级首饰试升来"试探"当前时间段的服务器幸运值波动。每 10 分钟取一次，观察成功/失败规律，选择幸运峰值时段升主武器。这是传奇最经典的博弈玩法。

### 4.2 防具/配饰强化（传奇永恒）

- 防具强化成功增加体力值；穿齐 4 件防具且全部强化 +5 以上，额外获得神圣攻击和防御
- 装备**精炼**：消耗精炼石/精炼精华+金币，橙装→精装→魔装逐阶提升
- 精炼属性可在同部位同性别装备间**继承**（转移），避免换装损失

## 六、经济与 PK 系统

### 经济体系

- **金币：** 打怪掉落、卖装备、交易获得；消耗于武器升级、强化、购买药水
- **元宝：** 充值获得；购买祝福油、黑铁矿石、时装、坐骑等
- **交易：** 玩家间自由交易（摆摊/面对面），装备全自由流通
- **主要 sink：** 武器升级碎裂（装备直接消失！）、强化材料消耗、药水消耗（法师喝蓝量极大）
- **最大 sink：** 死亡爆装——红名 PK 死亡有概率掉落身上装备

### PK / PvP 系统

- **自由 PK：** 野外地图随时可攻击其他玩家
- **红名：** 杀人后名字变红，死亡时**装备掉落概率大增**
- **安全区：** 城镇内不可 PK
- **沙巴克攻城战：** 每周定时，公会争夺沙巴克城，获胜公会享受专属地图/商人/称号
- **行会战：** 公会宣战后双方成员可自由互杀不加红名

## 七、现代传奇（页游/手游）衍生系统

经典端游的核心框架之上，页游和手游版本层叠了大量"养成坑位"，形成所谓的"战力值"体系：

| 衍生系统 | 功能 | 设计特点 |
|---------|------|---------|
| **翅膀/羽翼** | 外观 + 大量属性加成 | 升阶消耗材料+金币，纯数值膨胀 |
| **坐骑** | 外观 + 移速 + 属性 | 幻化系统、坐骑装备（马鞍/马铠/缰绳/马镫） |
| **战力值** | 所有属性的单一合成分数 | 一切养成最终汇入战力数字，排行榜核心 |
| **装备强化/追加/祝福/附魔/精炼/魔炼** | 多层叠加的装备数值提升通道 | 每层消耗不同材料，形成多条消费链 |
| **铭文/魂链** | 装备间的链式激活系统 | 5 种铭文循环激活，10 件装备形成激活链 |
| **品质进阶** | 绿→蓝→紫→橙→金→魔→神 | 7 阶品质，每阶开放更多附魔位/强化等级 |
| **神装/圣物** | 顶级装备，全服限量 | 极低爆率或活动专属 |
| **转生/重生** | 满级后重置等级换取永久属性加成 | 多次转生叠加，形成长线追求 |
| **龙卫传承** | 百分比属性加成 | 挑战特定 BOSS 获得升级材料 |

> **页游/手游化的核心变化：** 经典端游的追求是"爆到一件好装备 → 稳定输出（运9）"，追求的是*装备本身*；页游/手游化后变成"所有装备都能无限叠强化层 → 追求的是*数值层数*"。前者有终点（运9就是毕业），后者无上限（永远可以再加一层强化）。

## 八、对新项目的适配建议

### 传奇设计中值得借鉴的精华

1. **攻击区间 + 幸运值** — "从不稳定→稳定"比"从小→大"更有追求深度
2. **减法伤害公式** — 简单直觉：攻击减防御 = 伤害。但穿透（破防）和神圣伤害（真伤）增加策略维度
3. **双防体系（物防/魔防）** — 天然形成职业克制三角，适合有阵容选择的战斗
4. **装备有部位有角色** — 10 个部位各有功能定位，穿装备是在构建一个"面板"，不是塞数值棒
5. **套装系统** — 凑套装是核心追求，创造"差一件"的稀缺感
6. **武器升级的博弈性** — 碎裂风险 + 垫刀策略 + 发光视觉反馈，升武器本身就是一个完整的心流循环
7. **死亡掉装 + 红名** — PK 有真实代价，让装备有"保险价值"而非无限堆叠

### 需要针对 QQ 文字游戏改造的部分

1. **攻击速度** — 文字游戏无实时操作，攻速无表达空间，砍掉或转化为"每回合行动次数"
2. **移速/减速/定身** — 在文字战斗中，物理位移无意义。改为"行动顺序"或"跳过回合"等效果
3. **敏捷度/魔法躲避** — 文字游戏中 MISS 体验差（等了一回合白打），概率控制在极低或改为减伤
4. **死亡掉装** — 对未成年玩家群体过于严苛，改为掉落金币或材料
5. **战力值** — 可以做但要诚实标注局限：它只衡量面板数值，不衡量 build 质量
6. **多层强化系统** — 页游式叠了 7~8 层强化是纯氪金设计，新项目选 2~3 层即可（升级 + 词缀 + 孔位）

### 可直接移植的传奇要素速查

| 要素 | 传奇原版 | 适配新项目的形态 |
