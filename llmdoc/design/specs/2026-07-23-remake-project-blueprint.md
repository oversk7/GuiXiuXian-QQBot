# 诡修仙·重制版 — 项目蓝图

> 2026-07-23 · 全新 QQ bot 文字 RPG，从零设计，不受旧服数据/玩家存量约束
> 参考文档：[传奇系设计蓝图](2026-07-23-legend-design-blueprint.md)

---

## 一、项目定位

**一句话**：传奇的骨（属性/装备部位/减法伤害/幸运/套装/强化博弈/经济循环）+ 诡修仙的皮（邪神/鬼物/诡契/怪谈叙事/镇压封印）+ QQ bot 的形（回合制自动战斗/坐标导航/Markdown 卡片/按钮交互）。

| 维度 | 说明 |
|------|------|
| 平台 | QQ 群 / QQ 频道，NoneBot2 框架 |
| 类型 | 文字 RPG，回合制自动战斗 |
| 玩家画像 | 未成年为主，碎片时间（每次 15~20 分钟），不做解谜/复杂计算 |
| 世界观 | 诡异修仙——邪神/鬼怪/民俗恐怖，不是传统修仙/妖兽体系 |
| 叙事基调 | 《神秘复苏》《我有一座冒险屋》《道诡异仙》；大白话 + 第二人称现在时 |
| 职业 | 无职业分支，单一角色，Build 多样性通过装备/套装机制实现（候选：鬼物/诡契扩展 build 轴，未拍板） |
| 差异化 | 市场上没有同类型的诡异题材 QQ 文字 RPG |
| 与旧服关系 | 独立新 bot，旧服进入维护模式（只修 bug 不加功能） |

## 二、设计宪法（不可违反的红线）

| # | 条款 | 来源 |
|---|------|------|
| 1 | **面板成长只加法，不允许比例(ratio)加成** | 旧游戏死因诊断：ratio 乘法通胀封死天花板 |
| 2 | **一切战力来源硬封顶** | 装备有最高阶、强化有上限、诡契有满级 |
| 3 | **来源绑定：要 X 就必须去 Y 打 Z** | 旧游戏材料不绑产地导致无稀缺感 |
| 4 | **简单直给：一句话看懂、一个按钮上路** | 玩家是未成年 |
| 5 | **稀缺性守恒：新物品上线前查所有出口** | 用户最在意"没有东西稀有" |
| 6 | **叙事驱动进度，不靠经验条磨级** | 主线解锁区域，不靠重复刷怪升级 |
| 7 | **不改已上线的玩家习惯交互** | 旧服教训：挂牌货架化次日被回滚 |
| 8 | **鬼怪结局用镇压/封印/安抚，不用击杀** | 世界观规范 |
| 9 | **面板永远现算：基础值 + Σ装备/鬼物/诡契，派生值不落库为真源** | 旧服属性账本漂移收口的学费；永久基础值修改从第一天走单一入口 |
| 10 | **金币盯现实物价：1 金币 ≈ 1 元；高阶内容不多产金币，产出走预算制** | 旧服金币膨胀到几十亿的教训（详见 §12.0） |

## 三、核心循环

### 主循环（每章 1~2 周推完）

```
接任务 → 上路 → 探索异域 → 挑战 Boss → 收获 → 解锁
  │        │        │          │         │       │
NPC给    导航途中   格子探索    选对配装   装备    下一章
目标+    偶遇事件   遇怪/采集   打明牌Boss 套装    新区域
按钮              触发支线              材料    新系统
```

### 日常循环（每天 15~20 分钟）

```
签到刷新 → 接委托 → 短途出发 → 处理 → 交差领赏
              │                  │
          就近NPC派            讨伐/收集
          不跨大陆            用现有 build
```

### 社交循环（候选——随诡契拍板启用）

```
收徒 → 徒弟升级 → 获得香火 → 缔结诡契 → 变强
                                ↑
                  异域神龛采集(保底)
```

### 单步时长控制

- 每步操作 5~15 分钟可完成
- 放学后 20 分钟能有实质进展
- 长导航途中有偶遇事件填充等待

## 四、属性体系

> 参照：[传奇系设计蓝图 · 一、属性体系](2026-07-23-legend-design-blueprint.md#一属性体系)

### 4.1 设计决策

传奇有 5 种攻击属性（攻击/魔法/道术/刺术/弓术）对应 5 个职业。本游戏无职业，改为**单一攻击属性 + 伤害类型由装备/诡契决定**：

- 角色只有一个"攻击"值（区间制：X-Y）
- **伤害类型由凶器决定**：常规凶器打物理（吃物防），邪术凶器打诡术（吃魔防）——两条凶器线**骨架即有**，不依赖候选系统。这同时保证 PvP 中对手可能是物理流也可能是诡术流，物防/魔防都是有效的配装博弈（2026-07-24 补充：若诡术只从鬼物/诡契出，候选不上线则 PvP 魔防形同虚设）
- 鬼物/诡契（候选）可额外赋予"此伤害视为诡术伤害"（被魔防减免而非物防）
- 怪物/Boss 有物防和魔防分别设定，玩家根据 Boss 弱点选择物理 build 或诡术 build

### 4.2 属性清单

**基础属性（面板可见，可通过升级/装备/强化提升）：**

| 属性 | 传奇对应 | 说明 |
|------|---------|------|
| **攻击 X-Y** | 攻击（区间制） | 每回合在 [X, Y] 间随机取值。装备/强化提升区间 |
| **物防** | 防御 | 减少受到的物理伤害（减法） |
| **魔防** | 魔防 | 减少受到的诡术伤害（减法） |
| **生命 HP** | 体力值 | 归零则倒下 |
| **幸运** | 幸运 | 打出攻击上限的概率。公式 `1/(10-幸运值)`，运9=100%上限 |

> 注：灵力 MP 已移除——战斗全自动，不存在"要不要放技能"的决策点，保留 MP 只是多一个无意义的数字。基础属性精简为 5 项，降低认知负担。
>
> 注：传奇的"敏捷度"（闪避）改为回合制的"格挡"（见战斗属性）。旧游戏的"Agility"绑定了跑商速度，新游戏不做此耦合。

**战斗属性（由装备/诡契/鬼物赋予，不可直接加点）：**

| 属性 | 传奇对应 | 回合制翻译 | 来源 |
|------|---------|-----------|------|
| **暴击率** | 暴击率 | 每回合独立判定 | 装备/诡契 |
| **暴击伤害** | 暴击伤害 | 暴击时的额外倍率 | 装备 |
| **穿透** | 破物防/破魔防 | 削减对方有效防御 | 装备/鬼物 |
| **格挡率** | 敏捷度（闪避） | 触发时伤害减免 30%（非 MISS） | 装备 |
| **行动次数** | 攻击速度 | 达阈值时一回合攻击 2 次 | 稀有装备/诡契 |
| **真伤** | 神圣伤害 | 无视防御直接追加固定伤害 | 鬼物/诡契独占 |
| **吸血** | 物理击回 | 造成伤害后回复 HP | 诡契独占 |
| **流血** | 流血强化 | 攻击概率附加 DoT（N 回合持续伤害） | 鬼物独占 |
| **灼烧** | 灼烧强化 | 诡术攻击概率附加 DoT | 鬼物独占 |
| **定身** | 定身强化 | 攻击概率使目标跳过下回合 | 诡契独占 |
| **反击** | 无（旧服机制沿用） | 被攻击后概率立即回击一次（不受行动次数影响） | 鬼物独占 |
| **减暴** | 减暴击 | 降低被暴击概率 | 装备 |
| **减伤** | 物理/魔法抗性 | 百分比减少受到的伤害（上限封顶） | 装备/诡契 |

> **Build 多样性来源（骨架版）**：真伤/吸血/流血/灼烧/定身/反击等机制属性由**稀有装备与套装效果**提供——传奇特戒模式（麻痹戒指/护身戒指就是挂在首饰上的机制属性），build 差异 = 带哪几件机制装备、凑哪套套装。
>
> 表中来源列的"鬼物/诡契"为**候选归属**：这两个系统未拍板（见 §6/§7）。若拍板上线，再把对应属性迁为其独占来源、装备侧同步收紧；不上线则装备侧就是唯一来源，骨架自洽。

### 4.3 伤害公式

> 参照：[传奇系设计蓝图 · 二、伤害公式](2026-07-23-legend-design-blueprint.md#二伤害公式与幸运机制)

```
每回合伤害计算：

1. 攻击取值 = 在 [攻击下限, 攻击上限] 区间随机，受幸运值影响偏向上限
2. 有效防御 = 对方防御 × (1 - 穿透率)
3. 基础伤害 = max(1, 攻击取值 - 有效防御)
4. 暴击判定 = roll(暴击率)，若暴击：基础伤害 × (1 + 暴击伤害%)
5. 格挡判定 = roll(格挡率)，若格挡：伤害 × 0.7
6. 减伤计算 = 伤害 × (1 - 减伤率%)
7. 真伤追加 = + 固定真伤值（无视上述所有减免）
8. 行动次数 = 若有双击：重复步骤 1~7
9. DoT 结算 = 流血/灼烧持续伤害（每回合固定值）
10. 吸血回复 = 本回合总伤害 × 吸血率%

先手判定：玩家主动进攻时首回合先手；后续每回合各 50% 概率先手
定身判定：被定身的单位跳过本回合
```

> 注意：这是**加法为主**的公式。唯一的乘法是暴击倍率和格挡/减伤的比例减免——这些都是"对局内倍率"，不进面板，不复利，符合宪法第 1 条。

### 4.4 数值锚点（Phase 1 写战斗代码前必须先填）

减法公式对攻防比极端敏感：防御逼近攻击下限则伤害塌缩到保底 1，攻击略超防御后每 +1 都是净伤害；且流血/灼烧/真伤无视防御，对高防目标的相对价值线性放大。数值不能边写代码边拍——先定锚点、跑模拟、再开工。

**锚点规则（抄传奇的攻防比手感——防御偏弱、伤害流畅，Boss 靠 HP 和签名机制难，不靠防御墙）：**

| 规则 | 目标带 |
|------|--------|
| 普通怪防御 ÷ 玩家均值攻击 | 20% ~ 35% |
| 精英/Boss 防御 ÷ 玩家均值攻击 | 35% ~ 50% |
| 普通战斗回合数 | 3 ~ 5 回合 |
| 精英/Boss 战斗回合数 | 6 ~ 10 回合 |
| 保底伤害(=1)出现率 | < 5%（超过说明防御带偏高） |
| DoT+真伤 占对 Boss 总输出比 | 单流派 ≤ 60%（超过说明防御把直伤挤死了） |

**一阶示例锚点（待模拟校准）：** 玩家满配攻击 18-36 / 普通怪防御 6-9、HP 90 / 精英防御 12-16、HP 260。

**校验方式：** 用复用的战斗引擎写模拟脚本（每组配装 × 每个怪 1000 场），检查回合数带与流派伤占比达标后再落 YAML。半天工作量，省掉整个 Phase 1 的反复调数。

## 五、装备系统

> 参照：[传奇系设计蓝图 · 三、装备部位](2026-07-23-legend-design-blueprint.md#三装备部位与套装)

### 5.1 装备部位

传奇 10+ 部位精简为 **6 类基础部位 + 2 个候选槽**，保留部位角色分工，适配文字游戏信息密度：

| # | 部位 | 属性方向 | 传奇对应 | 设计意图 |
|---|------|---------|---------|---------|
| 1 | **凶器**（武器） | 攻击 X-Y | 武器 | 伤害主源；可强化加幸运 |
| 2 | **躯壳**（衣服） | 物防、HP | 盔甲 | 物理生存 |
| 3 | **面具**（头盔） | 魔防、HP | 头盔/斗笠 | 诡术生存 |
| 4 | **锁链**（项链） | 幸运、辅助属性 | 项链 | 幸运的第二来源 |
| 5 | **骨戒 ×2**（戒指） | 暴击/穿透/攻击 | 戒指 ×2 | 输出向首饰 |
| 6 | **缠带 ×2**（手镯） | 物防/魔防/格挡 | 手镯 ×2 | 防御向首饰 |
| 7 | **鬼物**（效果件，**候选未拍板**） | 战斗效果（真伤/流血/灼烧等） | 无（新增） | Build 流派定义；效果带代价 |
| 8 | **诡契**（契约槽，**候选未拍板**） | 战斗效果（吸血/定身等） | 无（新增） | 另一条 Build 轴；香火缔结 |

> 戒指和手镯各可穿 2 件，基础穿戴件数 = 8 件；鬼物/诡契槽若拍板则为 10 件，与传奇一致。骨架层装备槽位用可扩展枚举，为候选槽预留。

### 5.2 装备品质

| 品质 | 颜色 | 入门门槛 | 获取途径 |
|------|------|---------|---------|
| 残破 | ⚪白 | 无 | 新手/低级怪掉落 |
| 凡品 | 🟢绿 | 一阶 | 区域怪/锻造 |
| 诡品 | 🔵蓝 | 二阶 | 异域精英/锻造 |
| 邪品 | 🟣紫 | 三阶 | 异域 Boss/套装件 |
| 神器 | 🟠橙 | 四阶 | 高级异域 Boss 限定 |

### 5.3 套装系统

> 参照：[传奇系设计蓝图 · 套装机制](2026-07-23-legend-design-blueprint.md#32-装备品质与套装)

每个异域区域产出一套专属套装（项链+戒指+手镯，3~4 件凑齐获额外效果）。设计原则：
- 套装效果是**机制性的**（"凑齐 3 件：攻击附带降防 2 回合"），不是纯数值加成
- **同阶横向选择**：同一阶段长期规划 2 个异域（见 §9.2），各产一套同品质但效果方向不同的套装，对不同 Boss 签名机制各有优劣
- 跨阶纵向替换：高阶套装基础属性更高，但低阶套装的机制效果对特定 Boss 仍有用武之地（保留换装理由）
- "差一件"的稀缺感是核心追求驱动

### 5.4 装备强化

> 参照：[传奇系设计蓝图 · 四、装备强化](2026-07-23-legend-design-blueprint.md#四装备强化系统)

| 系统 | 传奇做法 | 本游戏适配 |
|------|---------|-----------|
| **凶器强化** | 祝福油加幸运，失败碎裂 | 献祭材料加幸运，失败**降 1 级**（非碎裂），连续失败 N 次保底 |
| **防具强化** | 黑铁矿石 + 金币升级 | 材料 + 金币升级，增加物防/魔防，上限 +9 |
| **首饰强化** | 精炼石逐阶提升 | 暂不做，首饰靠换件而非强化——保持换装驱动力 |

幸运值上限 = 9（凶器最高 +7，锁链最高 +2）。遵循传奇公式 `1/(10-幸运值)`。

## 六、鬼物系统（候选，未拍板）

> **状态**：候选扩展，骨架不依赖本系统。骨架版的机制属性由稀有装备/套装承担（§4.2）；若拍板上线，本节生效并做属性归属迁移。

### 6.1 概念

鬼物 = 被镇压的诡异实体，封印在器物中充当装备。每件鬼物有名字、来历、战斗效果、**使用代价**。

> 设计灵感：《神秘复苏》的"鬼物"概念——驭鬼要付出代价。

### 6.2 机制

- **专属部位**：占用第 7 个装备槽"鬼物"位
- **效果**：赋予真伤/流血/灼烧/反击等机制属性（独占矩阵见 §4.2；行动次数归稀有装备/诡契，不从鬼物出）
- **代价**：每件鬼物自带负面效果（"每回合损失 3% HP"、"前 2 回合不可暴击"）
- **获取**：异域 Boss 掉落，不可锻造。来源绑定到特定异域
- **不可拆卸效果**：效果和鬼物本体绑定，不能转移到其他装备
- **代码实现**：骑现有 battle_effects.py TriggerConfig 管线（A 级可复用）

### 6.3 设计约束

- 没有"无代价的万能鬼物"——强效果必带强代价，有取舍才有 build
- 鬼物不给基础属性（攻击/防御/HP），只给机制效果——和装备本体的职责分明
- **代价必须被 Boss 设计放大**：全自动战斗中代价本身只是数学减法，需要 Boss 签名机制配合才有体感（例：Boss 有爆发回合，带"每回合损失 3% HP"的鬼物可能导致扛不过爆发）。设计鬼物时同步设计至少一个让该代价特别疼的 Boss
- PvP 中鬼物效果初期可先关闭，跑通 PvE 后再开放

## 七、诡契系统（候选，未拍板）

> **状态**：候选扩展，骨架不依赖本系统。香火货币随本系统拍板才开始产出（无出口不发币，同怨念）；师徒香火加速闭环同此。

### 7.1 概念

诡契 = 与异域邪神缔结的契约，获得战斗中的特殊能力，用香火缔结、用金币和材料加深。

### 7.2 机制

- **专属槽位**：第 8 个装备槽"诡契"位，初始 1 个，硬上限 2~3 个（主线进度解锁扩槽）
- **效果**：赋予吸血/定身/特殊减伤等机制属性（与鬼物错开，不重复）
- **代价**：和鬼物一样，强效果带负面——"与邪神做交易怎么可能不付代价"
- **缔结消耗**：香火（一次性门票）
- **加深消耗**：金币 + 该异域限定材料（长线主力金币 sink；指数定价做长尾，前段价格对齐新服玩家的实际收入曲线——新服没有存量金币可瞄）
- **加深有失败风险**：失败降 1 级但不低于基础级，连续失败 N 次保底（从传奇祝福油机制借鉴+兜底适配未成年）
- **获取**：异域 Boss 首杀必得基础契约。不可交易（或仅低阶可交易）
- **代码实现**：骑铭文管线 inscription_service.py（YAML 配置 → roll → 品阶评定 → TriggerConfig）

### 7.3 香火经济闭环

```
独立路径（任何人可完成）：
  异域神龛采集 + 循环委托香火奖励 + 天梯赛季结算 → 足量香火（慢但够用）

社交加速器：
  带徒弟 → 徒弟升级 → 师父获得香火 → 约等于独立路径 2 倍速度
```

> **设计原则**：独狼玩家通过神龛+委托+天梯能独立获得足够香火完成所有诡契缔结，只是速度较慢。师徒是**加速器**而非必要条件——核心进度不能绑在不可控的社交机制上。带新人仍然有强激励（快一倍），但不带也不会卡死。

### 7.4 货币分工表

| 货币 | 在诡契系统中的角色 | 其他系统用途 |
|------|-----------------|------------|
| **香火** | 缔结（一次性门票） | 师徒专属货币 |
| **金币** | 加深（大头消耗） | 装备强化、跑商、日常 |
| **限定材料** | 加深（绑定异域） | 锻造该区域装备/套装 |
| **怨念** | 不进诡契 | **首发不上线**——献祭类玩法就绪后随玩法一同引入（宪法 5：无出口不发币） |

## 八、战斗系统

### 8.1 回合制自动战斗

战斗全自动结算，玩家的策略输入在**战前配装**阶段：
- 穿哪套装备（堆物防 vs 堆魔防，取决于 Boss 伤害类型）
- 带哪几件机制装备/凑哪套套装（真伤流 vs 流血流 vs 吸血流……）
- （候选系统拍板后）选哪件鬼物、缔哪个诡契——追加的 build 轴

**侦查系统**（借鉴杀戮尖塔意图系统，适配战前决策）：精英/Boss 战前可用"侦查"获取情报，三行解决——把题目明牌给你，你的任务是搞到对的装备来解这道题：

```
【侦查】缚灵者
  类型：滚雪球型 | 伤害：诡术为主 → 堆魔防
  特殊：受到持续伤害时反而变强 ⚠ 避免流血/灼烧
  建议：快攻真伤 build + 高魔防
```

考验的是"有没有备对装"，不是"猜不猜得出机制"。

### 8.2 战报展示（Markdown 卡片）

```
【第 3 回合】你先手
  你的攻击 → 162（上限！）
  ├ 暴击！×1.8 → 291
  ├ 穿透 12%，有效防御 88→77
  ├ 敌方格挡，伤害 -30%
  └ 最终伤害：204 | 吸血回复 20 HP

  敌方攻击 → 95
  ├ 流血持续，本回合额外 -35
  └ 你剩余 HP：623/1200

  【继续】 【逃跑】
```

每个属性的触发都有一行展示——比传奇端游（实时数字刷屏）更清晰的正反馈。

**消息形态（防刷屏、防磨）：**
- 普通战斗：**一张汇总卡**——自动挑 2~3 个关键回合（暴击/机制触发/翻盘点）展开成上面的格式，其余回合折叠为一行结果
- 精英/Boss 战：分阶段 2~3 张卡（【继续】翻页），单次抉择点（§8.3）自然嵌在阶段之间
- 上例即 Boss 战的阶段卡形态；普通怪不逐回合翻页

### 8.3 Boss 战斗（可选：单次抉择点）

普通战斗全自动。Boss 战斗可在关键回合插入一次选择：
- "它要放大招了——【硬扛】还是【闪避】"
- 一个按钮选一下，不复杂但有参与感
- 初版可不做，验证核心循环后再加

### 8.4 敌人设计原则

> 核心理念（借鉴杀戮尖塔，适配全自动战斗）：**敌人不是数值墙，是配装谜题。** 好的敌人谱系是一组不同类型的问题，不是同一个问题的数值放大。

**敌人战斗原型（精英/Boss 必须归入其一）：**

| 原型 | 行为特征 | 考验什么 | 需要的 build 方向 |
|------|---------|---------|-----------------|
| **高爆发型** | 蓄力后释放高额伤害，间歇期较弱 | 生存能力 | HP / 格挡 / 减伤 |
| **持久回复型** | 中等输出 + 每 N 回合回复 HP | 输出压制 | 真伤 / 高 DPS / 定身（跳过回复回合） |
| **滚雪球型** | 每回合自我增强，拖久必死 | 击杀速度 | 爆发 / 暴击 / 连击 |
| **反制型** | 触发条件惩罚特定机制 | build 灵活性 | 至少准备两套装 |
| **多怪协同型** | 2~3 怪各有角色（增益/输出/肉盾） | 综合能力 | 面板够硬或有范围效果 |

**Boss 签名机制**：每个异域终点 Boss 必须有一条签名规则，专门克制某种流派。设计约束：
- 签名机制必须**可侦查**（侦查报告明确写出）
- 必须有**至少两种合理应对**（不允许唯一解）
- 同一异域内的精英和 Boss 签名机制**不克制同一流派**（避免某 build 被整个异域锁死）

签名机制示例：

| Boss | 签名机制 | 被克流派 | 应对方式 |
|------|---------|---------|---------|
| 缚灵者 | 受到 DoT 时每层攻击 +10 | 流血 / 灼烧 | 真伤 / 暴击爆发 |
| 镜面鬼 | 被暴击时反弹 50% 伤害 | 暴击流 | 流血持续 / 稳定输出 |
| 蚀骨母 | 每 3 回合吞噬回复等量 HP | 低 DPS 持久战 | 定身跳过吞噬 / 高爆发 |
| 百目 | 每回合叠"凝视"，5 层秒杀 | 慢速磨血 | 必须 5 回合内击杀 |

**行为脚本（战报叙事层）**：精英/Boss 配置多回合行为循环（YAML 定义），让战报有节奏变化——"蓄力……蓄力……爆发！"——而非每回合千篇一律的"它攻击了你"。行为脚本是**表现层工具**，不是玩家决策信息（决策由侦查在战前提供）。

**自动目标 AI**：多怪战斗中，战斗引擎默认优先攻击增益型/治疗型敌人（威胁最高的后排）。玩家不需要手动设置目标——可通过鬼物/诡契效果间接影响目标策略（如某鬼物自带"优先攻击 HP 最低的敌人"）。

### 8.5 失败与恢复（抄传奇：药水续航 + 回城复活）

**HP 延续：** 异域/巢穴内 HP 跨战斗延续，不自动回满——攻坚是一次资源管理，高爆发型怪和鬼物代价（"每回合损失 3% HP"）因此在整场攻坚里有分量，而不是只在单场内。城镇内自然恢复（分钟级回满）。

**符水（消耗品，对应传奇药水的经济位）：**
- 城镇药铺金币购买——**日常高频金币 sink**，填补强化/加深两大低频 sink 之间的日常出口
- 战斗中 HP 低于阈值自动服用（全自动战斗不需要手动喝），每场上限 2 瓶；异域携带上限随阶提升
- 分阶有品级，低阶符水打高阶异域杯水车薪（来源绑定同样适用）

**倒下（HP 归零）：**
- 回最近城镇，损失携带金币的 5%（有封顶）；**不掉装备、不掉材料**（传奇死亡掉装的未成年温和化）
- 异域内倒下：退回异域入口，已通过的区域门保留（重进不用从头打）
- 无其他惩罚——失败的代价主要是符水消耗和时间

## 九、异域系统（副本）

### 9.1 结构

每个"异域"= 一个**有限的多区域地图**，不是无限层：

- 3~5 个区域串联，每区域复用诡域格子引擎（11×11 格）
- 区域间设门/Boss 关卡
- 有专属怪物谱系（具名怪物，有来历有弱点）
- 有专属材料掉落（来源绑定）
- 有终点 Boss，打穿有结局（镇压/封印）
- 首通即毕业，不靠无限加深度延寿。但打穿后保留**周常回访**理由：每周刷新隐藏精英 / 限定材料掉落 / 高难模式，避免"死内容"
- **材料频控（稀缺性守恒的显式化）**：Boss 首杀必得核心掉落；复访的限定材料/鬼物掉落走周限额（每周 N 次有效掉落），规则写进配置，不留给实现时拍
- **首通可行性校验（防鸡生蛋）**：每个异域的首通必须用"该异域之前可得的资源"配装可过；侦查建议不得推荐玩家当时拿不到的 build；第一个异域的 Boss 以纯装备零鬼物的裸配装为基准设计——异域自身的产出（鬼物/套装）服务于下一阶的挑战，不是本域门票

### 9.2 异域与阶段对齐

| 玩家阶段 | 门槛 | 首发异域 | 掉落品质 |
|---------|------|---------|---------|
| 二阶 窥诡 | 完成第一章 | 异域 ×1 | 绿品 + 套装 + 首件机制装备 |
| 三阶 缔约 | 完成第二章 | 异域 ×1 | 蓝品 + 套装 |
| 四阶 驭邪 | 完成第三章 | 异域 ×1 | 紫品 + 高级机制装备 |
| 五阶 镇世 | 完成第四章 | 异域 ×1 | 橙品 + 顶级机制装备 |

> 鬼物/诡契若拍板，其掉落位嵌入对应阶的异域（鬼物走 Boss 掉落、诡契走首杀契约），部分机制属性从装备侧迁移。

**横向扩展**：每阶长期规划第 2 个异域（同品质、不同套装方向、不同 Boss 签名机制），作为内容更新追加。同阶两个异域提供真正的套装横向选择——基础属性相当但效果方向不同，对不同 Boss 各有优劣。

### 9.3 无限塔（Phase 1 标配 endgame）

无限挑战塔是打穿异域后的**主要 endgame 内容**，防止 max 玩家因内容空窗而流失：
- **不掉关键材料**（核心资源必须去具名异域拿）
- 奖励：排名 + 赛季称号（香火奖励随诡契拍板启用）
- 每周重置排行，保持重复参与动力
- 每 10 层有一个随机签名机制的精英，考验 build 灵活性和装备储备深度
- 层间允许换装/换鬼物/换诡契——考验的就是储备深度，不锁配置

## 十、任务系统

### 10.1 任务引擎

```
quests.yaml → 任务定义（类型/前置/步骤列表）
pois.yaml   → 兴趣点定义（坐标/类型/触发条件）
PlayerQuestProgress 表 → player_id / quest_id / step_index / 计数器

四个钩子（埋在现有流程出口处）：
- 导航到达钩子 → 到达任务
- 战斗胜利钩子 → 讨伐任务
- NPC 交互钩子 → 对话/送信任务
- 物品变动钩子 → 收集/交付任务
```

### 10.2 任务目标类型

| 类型 | 说明 | 按钮 |
|------|------|------|
| **到达** | 走到某坐标/POI | 【前往 x,y】 |
| **讨伐** | 在指定 POI 击杀具名怪 | 【前往】→【探索】→【战斗】 |
| **交付/送信** | 从 A 城 NPC 取物送到 B 城 NPC | 【交互 NPC】→【前往】→【交互 NPC】 |
| **收集** | 收集某异域限定材料 | 在异域内探索获取 |
| **对话** | 找某城某 NPC 对话 | 【交互 NPC名】 |
| **异域** | 进入某异域 / 击败某 Boss | 【前往入口】→【进入】 |

### 10.3 主线 vs 循环委托 vs 偶遇

| 类型 | 定位 | 来源 | 绑坐标 |
|------|------|------|--------|
| **主线** | 叙事骨架，解锁异域/系统 | 手写 yaml + 文案 | 一章锚定一个大区 |
| **循环委托** | 日常任务，金币/材料产出 | 模板化轮换（NPC+怪+地点） | 就近派单，不跨大陆 |
| **偶遇** | 支线剧情，惊喜感 | 导航途中自动触发 | 固定 POI 附近 |

### 10.4 主线结构

- 一章 = 一个大区的怪谈事件
- 章内所有步骤集中在同一集群（城际几分钟级别）
- 跨大陆移动只发生在章节开头那一次"上路"
- 章尾：发现异域入口 → 解锁该区域的异域
- 一章开一界，叙事层和玩法层同一份投入

新人第一章 = 教学：注册 → 序章 → 第一次导航 → 第一个 POI → 第一次 NPC 对话 → 第一次战斗 → 发现异域入口。30 分钟内接触到基础战斗和装备系统；打穿第一章后解锁异域和鬼物，诡契在第二章后自然引入，不在教学中强塞。

**序章初始装备包二选一**（2026-07-24 拍板）：序章剧情里捡装备（如"生锈的柴刀"攻击向 vs "死人的棉袄"防御向，只带得走一样）。作用：给"选方向"的仪式感、教学期体验有差异、第一分钟就教会"装备决定强弱"；初始装备十级前自然淘汰，选"错"无永久影响。**不做成长系数分支/职业**——方向感全部由装备轴承担（§4.1 两条凶器线 + 套装流派）。

## 十一、地图系统

### 11.1 大地图

- **城市数量**：终态 15~20 座（旧游戏 35 座太多且同质化）；**分期开城**——首发只建第一章集群 4~6 座，随章节扩展（"一章开一界"同样适用于城市），Phase 3 跑商上线前扩到 10+ 座保证价差地理
- **坐标制**：复用旧游戏坐标系统，导航+实时旅行
- **导航速度**：基础速度所有人相同，坐骑加定额百分比（不绑属性，避免"敏捷=印钞机"）
- **城市特色**：每座城有唯一 NPC、唯一工匠能力、地理决定附近异域入口

### 11.2 地图内容（POI 系统）

| POI 类型 | 功能 | 生命周期 |
|---------|------|---------|
| **巢穴/异闻点** | 讨伐任务目标，具名怪物盘踞 | 常驻（手写）+ 轮换（系统刷） |
| **神龛** | 采集香火（诡契副水龙头） | 常驻 |
| **异域入口** | 进入异域的地理锚点 | 主线解锁后常驻 |
| **废墟/枯井** | 偶遇触发点 | 常驻（路过自动触发） |

### 11.3 导航偶遇

复用旧游戏的导航随机事件引擎（navigation_events.py，A 级可复用），扩展为：
- 路过未发现 POI 时弹选项："你路过一口枯井，井里传来水声…【停下查看】【继续赶路】"
- 发现即入图鉴
- 偶遇事件文案按《冒险屋》单元剧结构：异常 → 查明执念 → 安抚收尾
- 偶遇的选择结果落 flag（入图鉴、可被后续偶遇/主线引用）——选择不能即选即忘

## 十二、经济系统

> 参照：[传奇系设计蓝图 · 六、经济与 PK](2026-07-23-legend-design-blueprint.md#六经济与-pk-系统)

### 12.0 总锚：现实物价制（1 金币 ≈ 1 元人民币）

旧服金币膨胀到几十亿，数字彻底失真。新服金币量纲**盯住现实物价**——玩家是未成年，对"一块钱能买什么"有天然直觉，每个价格自带体感，不用教。

**物价对照表（所有定价的母表，新物品定价先在这张表里找现实参照）：**

| 现实参照 | 游戏内 | 定价带 |
|---------|--------|--------|
| 新手口袋零花钱 | 开局金币 | 50 金 |
| 一瓶饮料 | 一阶符水一瓶 | 5~8 金 |
| 一顿正餐 | 客栈食宿 / 情报贩子一条情报 | 10~30 金 |
| 打车/短途消费 | 防具强化一次 | 30~300 金（随阶） |
| 一天零工日结 | 30 分钟日活净收入 | 100~200 金 |
| —— | 重度玩家日净收入上限 | ≤ 400 金 |
| —— | 跑商单趟利润（税后） | 50~300 金 |
| 百元日用品 | 凡品（绿）装备一件 | 100~500 金 |
| 一部手机 | 诡品（蓝）装备一件 | 1000~5000 金 |
| 一套家电 | 邪品（紫）装备一件 | 1万~5万 金 |
| 一辆车 | 神器（橙）拍卖行情 | 10万级（由拍卖决定，不设官方售价） |
| —— | 一条诡契加深满级累计（候选系统） | 约 3万~5万 金（长尾 sink） |

**防通胀四阀门（结构性的，不是靠自觉）：**

1. **金币产出不随阶数放大**——高阶内容多产材料和装备（实物财富），不多产金币。旧服几十亿的第一根源就是高阶金币产出一路翻倍；传奇的做法也是金币面额终生稳定、财富形态是装备
2. **产出预算制**——所有金币水龙头集中一张 economy.yaml 预算表，人均日净产出目标带 50~150 金（产出 − 日常消耗）；任何新玩法要发金币，先在表里占预算，零基预算
3. **金币账本**——金币变动走单一入口 + 来源标签（宪法 9 同款思路）；管理员指令一键出周报（分渠道产出/回收），轻量实现，不上监控系统
4. **稳态指标**——全服金币总量周环比增幅 < 2%，长期趋零；超标先查预算表最近的新增项

**显示规则：** 永不出现 K/M/亿 缩写——数字大到需要缩写，本身就是设计事故。

### 12.1 货币

| 货币 | 产出 | 消耗 |
|------|------|------|
| **金币** | 打怪、委托奖励、跑商差价、交易 | 装备强化（大头）、诡契加深、锻造、修理、跑商进货 |
| **香火** | （候选——随诡契拍板才产出；届时：师徒主渠道、神龛副渠道、天梯结算） | 诡契缔结（无出口不发币） |
| **怨念** | （首发不产出） | 随献祭玩法一同上线，产出与出口同日开闸 |

### 12.2 跑商

复用旧游戏地理定价模型（merchant_service.py，A- 级可复用）：
- 城市间价差 = 距离 × 供需
- 导航速度与属性解耦——信息优势（哪条线路利润高）比速度优势重要
- 情报贩子 NPC 卖跑商情报（小金币 sink）

### 12.3 主要 Sink（金币出口）

| Sink | 量级 | 设计意图 |
|------|------|---------|
| 装备强化（幸运/防具） | 中 | 传奇核心博弈 |
| 符水消耗（§8.5） | 小额高频 | **日常出口**——填补大额低频 sink 之间的空窗，防金币只进不出 |
| 拍卖行抽成（§12.4） | 按成交额 | 交易越活跃回收越多 |
| 诡契加深（候选） | 大（指数长尾） | 候选系统拍板后的长线 sink |
| 锻造材料 | 中 | 来源绑定材料的消耗端 |
| ~~修理耐久~~ | ~~小~~ | 已移除——在已有强化+诡契加深+锻造三个大 sink 的情况下，修理是无选择的日常税，对未成年玩家负面体验 > 边际经济价值 |
| 跑商累进税 | 按收入分段 | 防止跑商通胀 |

### 12.4 交易系统（Phase 3）

抄传奇：装备全自由流通是传奇经济的根，稀缺性 × 可交易 = 装备有价。

- **拍卖行 + 面对面交易**：装备、材料、符水自由流通（旧服拍卖代码可参考）
- **绑定不可交易**：鬼物、诡契、香火——build 核心必须自己打，交易只流通"装备与原料"
- **拍卖抽成**：按成交额抽税，作为金币 sink
- §12.1 产出表中的"交易"一项由此闭环

> - **每阶设等级上限**：主线通关才解锁下一段——磨级不能越阶，主线始终是唯一的进度主轴（宪法 6 的保障线）
> - 战力大头始终来自装备/鬼物/诡契的 build 选择，等级是节奏器，不是战力轴

## 十五、技术栈与项目架构

> 2026-07-24 拍板：全新独立仓库 + 同服务器 MySQL 新库。原则：**照搬旧栈，风险预算全部留给玩法内容**——这套栈被 3900+ 角色的生产环境验证过。

### 15.1 技术选型

| 层 | 选型 | 说明 |
|---|------|------|
| Bot 框架 | NoneBot2 + adapter-qq | 与旧服一致；QQ 开放平台新注册一个机器人账号 |
| ORM | SQLAlchemy 2.0 async | aiomysql（生产）/ aiosqlite（本地沙箱） |
| 数据库 | 服务器现有 MySQL 实例**新建独立库**（如 `guixiuxian3`） | 与旧服同实例不同库，数据完全隔离，运维零新增；实例已调优（binlog/perf_schema 已关） |
| 迁移 | auto_migrate.py `REQUIRED_FIELDS` 模式 | 不用 Alembic，沿用项目规矩 |
| 数据访问 | infrastructure（IRepository + UoW + safe_session） | 第一批 A 级复用件 |
| 内容配置 | YAML（items/enemies/quests/zones/contracts…） | 内容即数据；加载器参考 pet/config.py 模式 |
| 消息渲染 | utils_markdown 原生 Markdown + 按钮 | 有按钮处不共存蓝字 |
| 定时任务 | nonebot-plugin-apscheduler | 周重置 / 委托刷新 / 神龛 |
| 依赖管理 | uv + Python 3.12 | 与服务器环境一致 |
| 测试 | pytest（asyncio auto）+ 本地 SQLite 沙箱 `nb run` | 沿用旧服模式 |
| 部署 | 同服务器新 systemd unit（如 `guixiuxian3-bot`） | git push → pull → restart，与旧服同流程 |

### 15.2 仓库与目录结构

全新独立仓库（名称暂定 D://QQbot/GuiXiuXian3），旧服进维护模式互不干扰。单插件、内部按领域分层：

```
GuiXiuXian3/
├── bot.py / pyproject.toml / .env*
├── plugins/guixiuxian/
│   ├── infrastructure/   # IRepository + UoW（搬运）
│   ├── models/           # 按领域分文件：player.py item.py quest.py zone.py contract.py …
│   ├── repositories/
│   ├── services/         # 业务逻辑；金币账本/属性修改的单一入口在这层
│   ├── handlers/         # 指令层：player/ world/ battle/ economy/ social/ …
│   ├── battle/           # 战斗引擎（纯函数无 IO，见 15.3）
│   └── utils_markdown.py
├── data/
│   ├── config/           # 玩法 YAML：items/ enemies/ quests/ zones/ contracts/ ghosts/ …
│   ├── knowledge/        # 帮助文档 yaml（单一来源，沿用旧服机制）
│   └── narrative/        # 主线/偶遇文案
├── scripts/              # §4.4 数值模拟脚本、经济报表
└── tests/
```

### 15.3 架构红线（旧服学费换来的）

1. **战斗引擎纯函数化**：输入配装快照 + 怪物配置，输出战报，全程不碰数据库——§4.4 的数值模拟脚本与线上跑**同一段代码**，"先模拟后上线"才成立（旧 enhanced_engine 与 IO 耦合正是它只有 B+ 的主因，搬运时顺手解耦）
2. **属性现算单一入口**（宪法 9）：面板 = 基础值 + Σ装备/鬼物/诡契现算；永久基础值修改只有一个函数入口
3. **金币账本**（§12.0）：金币变动只走一个入口、带来源标签，Phase 0 即建
4. **models 按领域分文件**：不再一个包塞几十个模型
5. **编码规矩全部沿用**：禁 `except Exception`、事务走 `safe_session`、迁移走 auto_migrate、帮助文档走 data/knowledge yaml
