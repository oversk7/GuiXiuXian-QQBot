# 公会 Boss（镇诡）系统设计

> 2026-07-08 拍板：有限血量镇压制 + 会长资金召唤 + 现有货币奖励。
> 2026-07-08 修订：主题从"劫兽（修仙妖兽）"改为诡异风（邪神眷属/西式+中式鬼怪），对齐游戏整体怪谈世界观。
> 定位：给每个公会一个"自己的集体活动"，补齐归属感；同时为公会资金库（treasury）新增消耗出口。
> 原则：纯加法，不动世界BOSS/公会任务/签到；奖励零通胀（不新增货币、不掉材料）。

## 1. 核心循环

```
会长【开坛引诡】扣公会资金 → 大诡入阵（48小时倒计时）
→ 全员【镇诡】各自出力（每人每场3次，单人战斗引擎结算）
→ 血量归零：镇压结算，全员发奖，诡异凶戾度+1
→ 超时未镇压：保底结算（按削减血量比例折算），凶戾度不变
```

**世界观**：诡异杀不死——这是全游戏的公理（世界BOSS打不死只能比伤害、天灾玩法的诡异只能导流）。公会能做的是"镇"：开坛设饵，把一只在附近作祟的大诡引入公会结界，全员合力将它**镇回去**。但每次被镇压，它都记住了你们的手段——下次爬回来时更凶（凶戾度递增）。"你们镇住的不是它，是这周的太平。"

**Boss 池**（中西混合，命名与专属文案实现期定稿）：
- 中式：纸新娘、井底娘娘、吊颈鬼、夜哭童、白衣送葬人
- 西式：血腥玛丽、无面修女、提灯人、镜中先生
- 邪神眷属（高凶戾度解锁）：与世界BOSS的克苏鲁谱系呼应但不重名
每次开坛随机选一只，同一只诡异的凶戾度独立记录（可后续做"公会宿敌"叙事），P1 简化为公会统一凶戾度。

## 2. 与世界BOSS的差异定位

| | 世界BOSS | 公会Boss |
|---|---|---|
| 目标 | 无限血量，个人伤害排名 | 有限血量，全会合力镇压 |
| 开启 | 定时（懒加载） | 会长资金召唤，自主决定时间 |
| 竞争维度 | 玩家 vs 玩家（区服内） | 公会全员 vs Boss（会内协作） |
| 奖励 | 宝箱（宝珠/材料） | 公会经验 + 积分 + 少量金币 |

## 3. 数值设计

### 3.1 Boss 血量（关键公式）

目标体验：**全员 60% 参与、人均打满 3 次才能镇压**。血量锚定召唤时刻的全会真实战力：

```
HP = Σ(成员有效攻击力) × R × T × D(凶戾度)
```

- `Σ(成员有效攻击力)`：召唤瞬间快照成员 attack 总和（快照防"召唤后拉人/踢人"操纵）。2026-07-09 修订：只统计近 7 天活跃成员（`last_active_at`），躺尸号不撑血量但仍可参战
- `R`：预估单次战斗有效回合数（初值 15，上线后按实际战斗日志校准）
- `T`：目标出力系数 = 3次 × 60% 参与率 ≈ 1.8
- `D(lv)`：凶戾度倍率 = `1 + 0.08 × (lv - 1)`，攻防同步用世界BOSS的段位倍率思路按等级放大

未镇压不降级——血量涨速（8%/级）低于玩家成长速度，卡住等级的公会会随成员变强自然突破，无需失败惩罚。

### 3.2 召唤消耗与频次

- 消耗：`5000 + 凶戾度 × 2000` 公会资金（treasury 默认上限 10 万，中型公会每周可支撑 2 场）
- 权限：会长 / 副会长
- 频次：每周至多 **2 次**（周一 0 点重置），同一时间至多 1 只存活
- 存续：48 小时，超时自动保底结算（懒结算，同世界BOSS模式）

### 3.3 参战规则

- 指令冷却/次数：每人每场 **3 次**，攻击间隔 1 秒（对齐世界BOSS习惯）
- 战斗结算：复用世界BOSS的 `EnhancedBattleEngine` 单人结算路径（含词缀/套装/临时buff/宠物，30回合上限）
- 消耗：同世界BOSS的理智反击机制（闪避可全避、防御15%效益）；hp≤0 / 理智归零不能参战
- 召唤后新入会成员**可以参战**（拉新人一起打是归属感的一部分），但血量不重算

### 3.4 奖励（零通胀核算）

镇压成功：

| 对象 | 内容 | 量级锚点 |
|---|---|---|
| 公会 | 公会经验 +2000×D(lv)（走 add_guild_experience 吃神龛倍率） | ≈ 全员签到一天的总量 |
| 全体参战者 | 积分 gold2 +100，出满 3 次 +50 | 满勤一场 = 1.5 天签到 |
| 伤害前三 | 额外积分 +50 / +30 / +20 | 小幅头部激励 |
| 里程碑 | 凶戾度达 5 / 10 / 20 级时全体参战者获称号（镇诡人→伏诡者→缚神者），纯荣誉 | 无数值 |

超时保底：按 `已削减血量 / 总血量` 比例折算上述积分（向下取整），公会经验减半，无里程碑。

**价值出口核对**（稀缺性原则）：
- 积分唯一出口是丹房兑换，而"丹药被公会丹房包办"是已知经济问题——所以积分量级压在"满勤两场/周 ≈ 3天签到"，不放大丹房供给格局
- 金币不发（世界BOSS宝箱已是金币产出口），第一版**不掉任何材料/宝珠**；材料体系改造落地后，可在此挂"专属兑换"作为消耗端

## 4. 数据模型

```
GuildBossInstance（公会Boss场次）
  id, guild_id(FK, 索引), boss_level, boss_name
  hp_max, hp_left(BigInteger)
  atk_snapshot(召唤时全会攻击力总和，审计用)
  summoned_by, summoned_at, expires_at
  status: active / killed / expired
  settled(bool，懒结算标记)

GuildBossDamage（个人出力）
  id, instance_id(FK, 索引), player_id(索引)
  total_damage(BigInteger), attacks_used, last_attack_ts
  唯一约束 (instance_id, player_id)

Guild 表新增字段（走 auto_migrate REQUIRED_FIELDS）
  boss_level(默认1), boss_week_summons(默认0), boss_week_reset_at
```

分区无需额外处理：公会本身按 server_id 隔离，Boss 挂在 guild_id 下天然隔离。

## 5. 指令与卡片

| 指令 | 权限 | 内容 |
|---|---|---|
| 【开坛引诡】 | 会长/副会长 | 确认消耗 → 召唤，输出降临卡 |
| 【公会Boss】/【公会诡异】 | 成员 | 状态卡：血条进度、剩余时间、参战人数/成员数、我的剩余次数 |
| 【镇诡】 | 成员 | 战斗卡（代码块日志 + 本次伤害 + 全会进度条） |
| 【镇诡战报】 | 成员 | 会内伤害榜 + 未出手名单（社交拉动） |

排版遵循原生 Markdown 卡片范式（`# 标题 + *** + 数值加粗 + 蓝字按钮`）。状态卡的核心是**全会血条进度 + "还有 N 人未出手"**——归属感来自看见彼此出力。

结算展示：懒结算（镇压瞬间当场结算；超时的在下次任何人访问时结算并展示战报卡）。不做主动群推送（QQ被动消息限制）。

## 6. 边界情形

- 公会解散 → 存活实例作废不结算（cascade 或结算前校验 guild 存在）
- 成员退会/被踢 → 已记录伤害保留，结算时仍按参战者发奖（发放前校验玩家存在）
- 会长转让 → 召唤权随职位走，无需特殊处理
- 血量击穿（最后一击溢出）→ hp_left 钳制为 0，最后一击者记录在案（战报卡"封棺一击"）
- 并发攻击同帧镇压 → 以 UoW 事务内 `hp_left > 0` 校验为准，后到者提示"它已被镇入阵底"

## 7. 实现分期

- **P1（MVP）**：模型 + 四个指令 + 镇压/超时结算 + 会内伤害榜。约 1 个模块目录（仿 world_boss/ 结构：commands / service / config）
- **P2**：里程碑称号、封棺一击彩蛋文案、帮助 yaml（guild_boss_help.yaml + guild_system_help.yaml 入口）
- **P3（挂接焕活主线）**：区服级"凶戾度榜"（赛季荣誉候选）、材料体系落地后的专属兑换消耗端

## 8. 遗留决策（实现前确认）

- Boss 池最终定稿：每只诡异的登场文案与专属特性（如镜中先生反击强、夜哭童削理智狠），文风遵循怪谈叙事规范
- R 系数初值需用真实战斗日志校准一轮
- 丹房兑换是否有每日限额——若无限额，积分量级再下调 20%
