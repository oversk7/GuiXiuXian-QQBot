#### 2. 战斗属性计算机制

**切磋战斗的调用链**:

#### 3. 临时buff处理 - 核心问题

**问题根源**: 切磋战斗使用了**同步版本**的属性计算方法

- **同步方法**: `BattleAttributeCalculator.calculate_effective_attributes()` (battle_attributes.py:39-85)
  - ❌ **不查询数据库**
  - ❌ **不包含临时buff**
  - ✅ 仅使用player对象的字段值

- **异步方法**: `BattleAttributeCalculator.calculate_effective_attributes_async()` (battle_attributes.py:88-152)
  - ✅ **查询TemporaryBuff表**
  - ✅ **合并临时buff属性**
  - 调用: `await player.get_effective_attributes(session)` (player.py:101)

**对比副本战斗**:
副本战斗 (dungeon_battle.py:843) 调用的是相同的战斗系统,但副本战斗是PVE,对怪物的战斗不影响问题本质。**切磋PVP战斗和副本PVE战斗都使用相同的同步属性计算**。

#### 4. 临时buff查询逻辑

**正确的查询方式** (player.py:241-254):
```python
# 查询临时buff
buff_bonuses = await TemporaryBuff.get_total_attribute_bonuses(session, player.id)

# 合并到结果
for attr, value in buff_bonuses.items():
    result[attr] = result.get(attr, 0) + value
```

**切磋战斗缺失**:
- enhanced_engine.py的_execute_enhanced_attack()方法调用calculate_effective_attributes()时
- ❌ **没有传入session参数**
- ❌ **没有调用异步版本**
- ❌ **临时buff被忽略**

---

### conclusions

1. **临时buff在切磋战斗中完全无效**
   - 切磋战斗调用同步版本的属性计算
   - 同步版本不查询TemporaryBuff表
   - 临时buff属性加成被完全忽略

2. **影响范围**
   - ✅ 切磋PVP战斗 (compact_player_vs_player_battle)
   - ✅ 模拟战斗 (compact_player_vs_player_battle)
   - ❌ 副本PVE战斗也受影响 (使用相同方法)
   - ❌ 所有调用execute_player_turn()的战斗场景

3. **根本原因**
   - enhanced_engine.py设计时未考虑临时buff
   - calculate_effective_attributes()同步版本是简化实现
   - 缺少session参数传递链路

4. **属性来源优先级** (从attribute-system.md)
   ```
   最终属性 = 基础属性 + 装备_persist_bonus + 临时buff
   ```
   切磋战斗仅获取: 基础属性 + 装备_persist_bonus

## 修复建议

### 方案1: 修改为异步属性计算 (推荐)

**修改点**: enhanced_engine.py:674-679

```python
# 修改前
attacker_base_attrs = BattleAttributeCalculator.calculate_effective_attributes(attacker)
defender_base_attrs = BattleAttributeCalculator.calculate_effective_attributes(defender)

# 修改后
attacker_base_attrs = await BattleAttributeCalculator.calculate_effective_attributes_async(attacker, session)
defender_base_attrs = await BattleAttributeCalculator.calculate_effective_attributes_async(defender, session)
```

**影响范围**:
- execute_player_turn()需要改为async
- 所有调用点需要await
- session参数需要从pvp_commands传递到engine

### 方案2: 在战斗初始化时预加载临时buff

**修改点**: enhanced_engine.py:start_battle()

```python
# 在start_battle时预加载临时buff
async def start_battle(self, player, enemy, session, player_equipped_items=None):
    # 预加载临时buff
    player.temp_buff_attrs = await player.get_effective_attributes(session)
```

**优点**: 减少战斗中的数据库查询
**缺点**: 需要修改Player对象结构
