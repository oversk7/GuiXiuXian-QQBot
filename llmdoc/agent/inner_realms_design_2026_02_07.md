## 🎲 2D6骰子判定系统

### 核心公式

```
最终结果 = 2D6 + 属性修正 + 时间修正
```

### 判定结果表

| 结果 | 判定 | 效果 |
|------|------|------|
| 2-3 | 💀 大失败 | 严重后果（惊动全区敌人/触发陷阱/目标变异） |
| 4-6 | ❌ 失败 | 小惩罚（掉血/错过奖励/被发现） |
| 7-9 | ⚖️ 普通成功 | 基础奖励 |
| 10-11 | ✅ 成功 | 额外奖励 |
| 12+ | 🌟 大成功 | 双倍奖励 + 触发隐藏剧情 |

### 属性修正来源

| 属性 | 适用场景 |
|------|----------|
| 敏捷 | 潜行、逃跑、处决、先手 |
| 智力 | 线索解读、机关破解 |
| 攻击 | 威吓、强行破门 |
| 幸运 | 搜刮、随机事件 |

### 掷骰显示格式

```
🎲 威吓检定
━━━━━━━━━━━━━
骰子: [4] + [5] = 9
攻击修正: +3
━━━━━━━━━━━━━
最终: 12 ✅ 成功！
━━━━━━━━━━━━━
「村长瑟瑟发抖，交出了地窖钥匙和186金币」
```

## 🏆 多结局系统

每个里界根据玩家行为触发不同结局，【返回】时结算：

| 路线 | 触发条件 | 结局描述 | 奖励倾向 |
|------|----------|----------|----------|
| 🔪 **屠夫** | 击杀>80%居民 | 里界崩塌，化为虚无 | 大量材料+金币 |
| 🔍 **真相** | 收集全部线索碎片 | 揭示完整故事，核心诡异显现 | 稀有装备+剧情成就 |
| 🛡️ **救世** | 救出>50%幸存者 | 幸存者离开，里界净化 | 声望+特殊称号 |
| ⚔️ **猎人** | 击败核心BOSS | 强制结束，里界封印 | BOSS专属掉落 |
| 💀 **毁灭** | 杀光一切+击败BOSS | 完全毁灭结局 | 全类型最高奖励 |

## 🎮 指令设计

```
【里界】           - 查看可进入的里界列表及等级要求
【传送 第三病栋】   - 进入指定里界（需满足等级要求）
【搜刮】           - 搜索当前位置（触发2D6+幸运判定）
【威吓】           - 威吓当前NPC（触发2D6+攻击判定）
【处决】           - 静默击杀目标（触发2D6+敏捷判定）
【交谈 XXX】       - 与指定NPC对话
【查看线索】        - 查看已收集的线索碎片
【里界信息】        - 查看当前里界统计（击杀数/线索数/幸存者数）
【返回】           - 离开里界，触发结局结算
```

## 🛠️ 技术实现要点

### 数据模型

**新增表：`inner_realm_session`**
```python
class InnerRealmSession(Base):
    id: int
    player_id: str
    realm_name: str           # 里界名称
    entered_at: datetime      # 进入时间
    killed_count: int         # 击杀数
    saved_count: int          # 救出数
    clue_collected: List[str] # 收集的线索ID列表
    x: int                    # 当前坐标
    y: int                    # 当前坐标
    state: dict               # 探索状态（JSON）
```

**新增表：`inner_realm_tile`**
```python
class InnerRealmTile(Base):
    id: int
    session_id: int           # 关联session
    x: int
    y: int
    event_type: str           # NPC / LOOT / CLUE / EMPTY / BOSS
    state: dict               # 格子状态（JSON）
    refreshed_at: datetime
```

### 核心服务

**`plugins/xiuxian_game/inner_realm/inner_realm_service.py`**
- `enter_realm(player_id, realm_name)` - 进入里界
- `move_in_realm(session_id, dx, dy)` - 移动
- `perform_action(session_id, action, target)` - 执行判定动作
- `roll_dice(base_modifier)` - 掷骰子
- `exit_realm(session_id)` - 退出并结算

## 💡 设计理念

1. **第四天灾定位**: 玩家不受道德约束，可以自由选择掠夺或拯救，但通过细节反思
2. **细思极恐**: 通过碎片化叙事，让玩家在事后意识到真相的恐怖
3. **骰子判定**: 增加不确定性，让每次探索都有不同体验
4. **多结局**: 根据玩家行为给予不同反馈，增加重玩价值
5. **独立系统**: 不干扰现有诡域系统，作为额外玩法内容

2. **帮助信息**: 必须更新 `plugins/xiuxian_game/player/help.py`

4. **性能优化**: 625格地图需要考虑查询优化，使用索引
5. **测试**: 骰子判定的随机性需要充分测试各种概率分布
