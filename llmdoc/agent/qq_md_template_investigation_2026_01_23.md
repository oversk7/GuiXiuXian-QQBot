## 一、QQ官方Markdown模版技术规范总结

### 1.1 核心限制

根据已有文档和测试代码分析，QQ官方Markdown模版存在以下技术限制：

| 限制项 | 规范 | 来源 |
|--------|------|------|
| **参数数量** | 最多10个动态参数 | `md模版方案.md` 明确标注 |
| **按钮组件** | 使用`<qqbot-cmd-input text="指令" />`组件 | 测试代码中广泛使用 |
| **参数命名** | 建议使用p1-p10或t1-t10 | `markdown_template_test.py:33-46` |
| **文本长度** | 未明确限制，但建议控制在合理范围 | 实践经验 |
| **show参数** | 可省略，直接使用text值作为按钮显示 | `md模版方案.md:373-398` |

### 1.2 支持的Markdown语法

根据模版方案文档分析：

```markdown
# 一级标题 {{.title}}
**加粗文本** {{.section}}
***分隔线***
> 引用块
• 列表项
<qqbot-cmd-input text="{{.cmd}}" />  # 按钮组件
```

### 1.3 qqbot-cmd-input组件使用规范

**基础用法**:
```markdown
<qqbot-cmd-input text="修炼" />
```

**参数化用法**:
```markdown
<qqbot-cmd-input text="{{.btn1}}" />
```

**注意事项**:
- text参数为必填，指定按钮显示文字和执行指令
- 省略show参数可节省参数数量
- 按钮点击后会自动发送text中的指令

### 5.3 技术实现建议

#### URL编码处理

```python
from urllib.parse import quote
from nonebot.adapters.qq.models.common import MessageMarkdown, MessageMarkdownParams

def create_markdown_params(params_dict: dict) -> List[MessageMarkdownParams]:
    """创建URL编码的模版参数"""
    return [
        MessageMarkdownParams(
            key=key,
            values=[quote(str(value))]
        )
        for key, value in params_dict.items()
    ]
```

#### 多行文本处理

```python
def format_multiline_text(lines: List[str]) -> str:
    """格式化多行文本，使用\\n\\n分隔"""
    return "\\n\\n".join(lines)
```

#### 按钮文本优化

```python
def optimize_button_text(command: str, max_length: int = 10) -> str:
    """优化按钮文本长度"""
    if len(command) <= max_length:
        return command
    return command[:max_length-2] + ".."
```

### 6.1 核心发现

4. **已有方案**: 文档中的4个模版设计基本合理，但需要优化

**最终推荐**: 方案A（最小化方案）

**申请模版**:
1. ✅ **模版1: 通用反馈**（10参数）- 覆盖90%场景
