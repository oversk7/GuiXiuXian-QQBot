# 游戏金币经济流动系统完整调查报告

**调查日期**: 2025-12-03
**调查者**: scout代理
**文档类型**: 代理调研报告
**调查范围**: 金币获取渠道(Sources)与消耗渠道(Sinks)完整映射

---

## 执行概要

本次调查完整梳理了诡修仙游戏中的金币经济流动系统，覆盖13个金币获取渠道和9个主要消耗渠道。核心发现：

**平衡状态诊断**:
- **通货膨胀严重**: 最高金币34.4亿（已知数据2025-12-01）
- **Source > Sink**: 获取渠道数量多、效率高，消耗渠道缺乏吸引力
- **主要问题**: 银行利息无风险高收益（年化876%）、打工收益过低、装备升阶成本指数增长但收益不匹配

**关键数值**:
- **每日金币流入预估**: 主动玩家3,000-10,000金币/天（签到+打工+副本）
- **每日金币流出预估**: 装备维护500-2,000金币/天，装备升阶10,000+金币（非日常）
- **银行利息创造**: 10万以内存款每小时100金币，相当于自然增长（无资源消耗）

### 1.5 银行利息系统（⚠️ 严重通胀源头）

**文件位置**: `plugins/xiuxian_game/economy/bank.py` (第12-51行)

**阶梯利率配置**:
```python
_TIERS = [
    (100_000, 0.001),   # 10万以内：0.1%/小时
    (500_000, 0.0005),  # 10-50万：0.05%/小时
    (1_000_000, 0.0001),# 50-100万：0.01%/小时
    (float("inf"), 0.0) # 100万以上：无利息
]
```

**利息计算** (`_apply_interest`函数, 第37-51行):
```python
delta_hours = (now - acc.last_interest).total_seconds() / 3600
gain = int(acc.balance * _tier_rate(acc.balance) * delta_hours)
cap = 10_000  # 单次结息上限
if gain > cap:
    gain = cap
```

**每日预估收益**:
- 10万存款：24小时利息 = 10万 × 0.001 × 24 = **2,400金币/天**
- 50万存款：24小时利息 ≈ 10万×0.001×24 + 40万×0.0005×24 = **7,200金币/天**
- 100万存款：24小时利息 ≈ 10万×2.4 + 40万×1.2 + 50万×0.24 = **10,000金币/天**（触发单次上限）

**年化收益率**:
- 10万以内: 0.1%/小时 × 24小时 × 365天 = **876%年化**
- 10-50万: 0.05%/小时 = **438%年化**
- 50-100万: 0.01%/小时 = **87.6%年化**

**⚠️ 平衡性问题**:
1. **无风险超高收益**: 876%年化收益远超任何现实金融产品
2. **货币创造失控**: 利息是纯货币创造（无对应资源消耗），加剧通胀
3. **与股票系统矛盾**: 银行无风险876%收益 vs 股票0%期望收益+手续费
4. **参考文档**: `/llmdoc/design/bank_system_redesign_2025_12_03.md` 提出了重设计方案

### 1.6 交易市场收入

```python
def calculate_transaction_tax(amount: int) -> int:
    if amount <= 5000:
        return 0  # 5000以下免税
    elif amount <= 20000:
        return int(amount * 0.05)  # 5%
    elif amount <= 50000:
        return int(amount * 0.10)  # 10%
    elif amount <= 100000:
        return int(amount * 0.15)  # 15%
    else:
        return int(amount * 0.20)  # 20%
```

### 3.3 货币流动平衡分析

**主动玩家净流入**:
```
流入: 6,700金币/天
流出: 1,200-3,500金币/天
净流入: +3,200 ~ +5,500金币/天
```

**高频玩家净流入**:
```
流入: 19,200金币/天
流出: 7,000-18,000金币/天
净流入: +1,200 ~ +12,200金币/天
```

**躺赚玩家净流入**:
```
流入: 10,800金币/天（几乎全部来自银行利息）
流出: 0金币/天（无游戏行为）
净流入: +10,800金币/天
```

**⚠️ 平衡性结论**:
1. **Source > Sink**: 所有玩家类型均为净流入，货币持续增长
2. **银行利息失控**: 躺赚玩家每日10,800金币全部来自银行利息（无资源消耗的货币创造）
3. **装备升阶无效Sink**: 6阶以上升阶成本（121万+）远超日常流入，玩家需积累数月才能升阶一次
4. **日常Sink不足**: 装备修理（500-5,000金币/天）和药品购买（200-5,000金币/天）无法消化银行利息产出

## 5. 关键问题与建议

### 5.1 严重失衡问题

**问题1: 银行利息货币创造失控**
- **现象**: 10万存款年化876%收益，躺赚玩家每日10,800金币
- **影响**: 通货膨胀严重（最高金币34.4亿）
- **参考方案**: `/llmdoc/design/bank_system_redesign_2025_12_03.md`
- **建议**:
  1. 降低利率至0.01%/小时（年化87.6%）
  2. 取消利息机制，改为理财产品（有期限、有风险）
  3. 引入通货紧缩机制（如装备耐久度强制报废、税收增加）

**问题2: 药品刷经验漏洞**
- **现象**: 回春散/凝神草仅100金币，可无限续航副本
- **影响**: 经验获取效率8.25倍于正常修炼
- **参考**: `/llmdoc/agent/game_balance_analysis_2025_12_01.md`
- **建议**:
  1. 提高药品价格5倍（回春散500金币）
  2. 添加每日使用上限50次
  3. 提高副本MP消耗至3-5 MP/格

**问题3: 装备升阶成本指数爆炸**
- **现象**: 6阶→7阶需364.5万金币，9阶→10阶需9871.5万金币
- **影响**: 高阶装备升级成为天文数字，玩家放弃升级
- **建议**:
  1. 调整升阶公式，避免指数爆炸
  2. 引入材料替代部分金币成本
  3. 提供升阶活动/折扣机制

---

### 5.2 货币Sink优化建议

**建议1: 增加日常刚性消费**
- 装备耐久度自然衰减（每日-5点，即使不战斗）
- 引入装备"保养费"机制
- 增加公会维护费用（公会建筑需定期维护）

**建议2: 增加非必须但吸引力高的消费**
- 时装/外观系统（纯装饰，高价格）
- VIP专属服务（如更多背包空间、装备栏位）
- 限时活动商店（高价稀有物品）

**建议3: 调整税收机制**
- 提高交易市场税率至10%-30%
- 引入财富税（每周/月对高额存款征税）
- 增加银行转账手续费至5%-10%

### 7.2 Conclusions (关键结论)

1. **Source > Sink**: 金币获取渠道多、效率高，消耗渠道缺乏吸引力，导致持续通货膨胀
2. **银行利息失控**: 年化876%收益是最大的货币创造源头，躺赚玩家每日10,800金币无资源消耗
3. **药品价格失衡**: 回春散/凝神草仅100金币，可无限续航副本，刷经验效率8.25倍
4. **装备升阶成本过高**: 6阶以上升阶成本呈指数爆炸（121万→9871万），玩家放弃升级
5. **日常Sink不足**: 装备修理（500-5,000金币/天）和药品购买（200-5,000金币/天）无法消化银行利息产出
6. **高价值Sink失效**: 装备升阶（6阶以上）成本过高，玩家需积累数月才能升阶，无法作为日常货币Sink
