# 诡修仙材料和道具系统稀缺性深度调查报告

**调查日期**: 2025-12-03
**调查者**: scout代理
**文档类型**: 系统稀缺性分析报告
**调查范围**: 材料来源、消耗、定价、平衡性问题分析

---

## 执行概要

本次调查完整梳理了诡修仙材料和道具系统的稀缺性问题，覆盖**252个物品配置、13个材料获取渠道、8个主要消耗场景、5个稀有度等级**。

### 核心发现

**三大稀缺性问题**:
1. **白色材料供过于求**: 掉落概率30%-40%，基础价格仅50-100金币，市场价可跌至20-40金币（参考市集天堂贝=20元定价）
2. **升阶石严重缺乏**: 初级升阶石20,000金币、中级100,000金币，与日均金币流入不匹配，成为升阶瓶颈
3. **稀有材料获取困难**: 橙色材料掉落概率仅1%-3%，需大量副本刷取（200层诡异才有3%概率），玩家耗时巨大

**量化数据**:
- **材料等级分布**: 白色(45%)、绿色(35%)、蓝色(12%)、紫色(7%)、橙色(1%)
- **价格悬殊比例**: 白色材料均价80金币 vs 橙色材料均价7,667金币（**96倍差距**）
- **消耗不对等**: 白色材料每日产出>5,000个 vs 消耗<1,000个（**5倍产过于消**）

## 1. 材料获取机制完整分析

### 1.1 战斗掉落系统（主要来源）

**文件位置**: `plugins/xiuxian_game/world/dungeon_battle.py` (283-373行)

#### 掉落概率配置

```
低级诡异(≤20级):    白色30%, 绿色10%
中级诡异(21-60级):  白色40%, 绿色20%, 蓝色5%
高级诡异(61-100级): 白色30%, 绿色25%, 蓝色15%, 紫色3%
顶级诡异(101-200级): 白色20%, 绿色20%, 蓝色20%, 紫色8%, 橙色1%
超级诡异(200+级):   白色15%, 绿色15%, 蓝色25%, 紫色12%, 橙色3%
```

**问题诊断**:
- 白色材料掉落率过高（15%-40%），数量过剩
- 橙色材料掉落率过低（1%-3%），需200层诡异才能合理获取
- 精英怪掉落率翻倍，但仅为基础2-3倍，难以快速获得稀有材料
- 幸运值可增加掉落概率，但幸运值获取困难（装备、临时buff、商店高价）

#### 每日掉落预估

**主动玩家（20次战斗）**:
```
中级诡异(30级):
- 白色: 20次 × 40% = 8次掉落 × 1.5个 = 12个/天
- 绿色: 20次 × 20% = 4次掉落 × 1.5个 = 6个/天
- 估计总产出: 白色12个, 绿色6个
```

**高频战斗玩家（50次战斗）**:
```
高级诡异(80级):
- 白色: 50 × 30% × 1.5 = 22.5 ≈ 23个
- 绿色: 50 × 25% × 1.5 = 18.75 ≈ 19个
- 蓝色: 50 × 15% × 1.5 = 11.25 ≈ 11个
```

**爬塔玩家（200层诡异，10次战斗）**:
```
超级诡异(200+级):
- 橙色: 10 × 3% × 1.5 = 0.45 ≈ 0-1个/天
- 需要333天才能获得1个橙色材料（无幸运值加成）
```

### 1.2 商人系统（高价值材料来源）

**文件位置**: `plugins/xiuxian_game/world/dungeon_battle.py` (240-281行)

**机制**:
- 每个诡域格子有3-5个商人NPC
- 商人出售高价值材料（绿色、蓝色、紫色为主）
- 商人材料价格比正常价格高30-60%
- 区域材料池优先级：商人专属材料 > 稀有材料 > 其他材料

**访问成本**:
- 每格消耗1-3 MP（10级玩家max_mp≈50-60）
- 需探索多个格子才能遇到商人（概率系统）
- 商人材料需付费购买（通常>1,000金币）

**问题诊断**:
- 商人系统增加了"消耗途径"（金币→材料），而非真正的"获取"
- 对低等级玩家（金币<10,000）几乎无法使用
- 高价材料（紫色5,000金币、橙色8,000-10,000金币）价格为战斗掉落的3-5倍

### 2.1 装备升阶（最大消耗场景）

**文件位置**: `plugins/xiuxian_game/item/equipment_upgrade_service_new.py` (122-210行)

#### 升阶石需求配置

```
普通装备升阶需求:

2阶→3阶: 初级升阶石×2 (40,000金币)

4阶→5阶: 中级升阶石×1 (100,000金币)
5阶→6阶: 中级升阶石×2 (200,000金币)
6阶→7阶: 中级升阶石×3 (300,000金币)
7阶→8阶: 高级升阶石×1 (300,000金币)
8阶→9阶: 高级升阶石×2 (600,000金币)
9阶→10阶: 至尊升阶石×1 (300,000金币)
```

#### 稀有装备升阶需求（更高）

```
橙色/传说装备:
- 1-3阶: 初级升阶石 + 虚无精华/恶魔之心
- 4-6阶: 中级升阶石 + 虚无精华/时光尘埃/恶魔之心
- 7-9阶: 高级升阶石 + 世界碎片/时光尘埃
- 10阶: 至尊升阶石 + 世界碎片

材料稀缺性:
- 虚无精华(purple): 2,200金币 × 1-2个 = 2,200-4,400金币/阶
- 时光尘埃(orange): 10,000金币 × 1-2个 = 10,000-20,000金币/阶
- 世界碎片(orange): 8,000金币 × 1-2个 = 8,000-16,000金币/阶
```

#### 消耗频率与成本

```
主动玩家升阶计划:
- 首件装备升至5阶: 20+40+60+100+200 = 420,000金币 (3个月积累)
- 首件装备升至10阶: 420,000 + 300,000 + 600,000 + 600,000 + 300,000 = 2.22百万金币 (12+个月)

高频战斗玩家:
- 需要10件装备，每件升至5阶: 需要420万金币
- 这与"多装备策略"（不同场景换装备）冲突
```

**问题诊断**:
- **升阶石价格过高**: 初级石20,000金币，而日常获取金币仅6,700-19,200金币/天
- **供应不足**: 升阶石仅通过商店购买或BOSS宝箱获得，无战斗掉落
- **成本阶级分化**: 普通装备vs稀有装备升阶成本相差5-10倍
- **玩家选择困难**: 无法同时升多件装备和购买其他消耗品

| 4 | 鬼泪 | 18-25个 | 4-10个 | +8-21个 | 初级丹药，升级后无用 |
| 5 | 诅咒丝线 | 15-22个 | 2-5个 | +10-20个 | 低级装备配方，等级升了就不用 |

**泛滥表现**:
- 玩家背包堆积到满（无法获取其他材料）
- 市集底价跌至配置价的20%-60%
- 玩家倾向"丢弃"而非"出售"（存储成本>金币收益）
- 无"材料兑换"系统将泛滥材料转化为稀缺材料

### 3.4 "稀缺材料"识别 (TOP 5)

根据掉落概率 × 日常产量 × 高级需求:

| 排名 | 材料 | 日均产量 | 日均需求 | 缺口 | 问题 |
|------|------|---------|---------|------|------|
| 1 | 时光尘埃 | 0.05-0.1个 | 2-5个/周 | **严重不足** | 橙色材料，200+层诡异3%掉落，升阶必需 |
| 2 | 世界碎片 | 0.1-0.2个 | 3-5个/周 | **严重不足** | 橙色材料，同上 |
| 3 | 至尊升阶石 | 0个(仅商店) | 10个/月 | **完全缺乏** | 仅商店300,000金币购买，BOSS宝箱稀有 |
| 4 | 虚无精华 | 0.5-1个/周 | 5-10个/月 | **严重不足** | 紫色材料，稀有装备升阶必需 |
| 5 | 灵石 | 0.5-1个/周 | 3-8个/月 | **严重不足** | 紫色材料，公会建筑专用材料 |

**稀缺表现**:
- 玩家需刷200+层诡异才能快速获取
- 玩家倾向"囤积"而非"使用"（怕不够用）
- 高级内容（10阶装备、高级建筑）事实上无法完成
- 造成"经济等级分化"：有材料玩家VS没材料玩家实力差2倍+

**设计意图 vs 实际体验**:

稀有升阶石 (配置价格300,000金币):
- 设计意图: 传说级装备的最终升阶，极其稀有

- 问题: 破坏了稀缺性，变成"谁金币多谁赢"
```

## 4. 与其他系统的耦合分析

### 4.1 与经济系统的关联（金币流通）

**参考**: `/llmdoc/agent/economy_gold_flow_investigation_2025_12_03.md`

```
金币来源(日均):
- 签到: 800金币
- 打工: 1,500金币
- 副本战斗: 2,000金币(材料出售)
- 银行利息: 2,400-10,000金币(躺赚)
- 总计: 6,700-19,200金币/天

材料相关消耗:
- 药品购买: 200-5,000金币/天
- 升阶石购买: 5,000-50,000金币/周
- 装备锻造: 5,000-10,000金币/周
- 丹药炼制: 10,000-25,000金币/天
- 总计: 20,000-80,000金币/天
```

**问题诊断**:
- **应急压力**: 上限玩家日常消耗(80,000)超过中等玩家日均流入(19,200)的4倍
- **层级分化**: 躺赚玩家(10,800金币/天)vs主动玩家(19,200)收入只差2倍，但消耗可相差10倍
- **材料交易缺失**: 白色材料市价20金币，而配置100金币，套利空间大但交易量低

### 4.2 与装备系统的耦合

**装备升阶链条**:
```
1. 装备锻造 → 消耗白色/绿色材料
2. 装备升阶 → 消耗升阶石(无法掉落)
3. 宝石镶嵌 → 消耗宝石(战斗掉落)
4. 装备修理 → 消耗金币(不消耗材料)

供应不对等:
- 白色材料每日产>15个 但锻造需求<5个
- 升阶石零掉落 必须商店购买(金币压力)
- 宝石相对充足(战斗产出可行)
```

**优化方向**:
- 白色材料应改为"手工业"消耗（增加使用场景）
- 升阶石应部分来自高难副本（而非100%商店）
- 装备修理应支持"材料维修"（将泛滥材料转化为消耗）

### 4.3 与炼丹系统的耦合

**炼丹材料分级**:
```
初级丹药(升灵丹): 消耗8-10个白色材料 (价值1,000金币)
中级丹药(血心丹): 消耗14-20个白色+绿色材料 (价值6,000金币)
高级丹药(夜魂丹): 消耗5-10个绿色+蓝色材料 (价值14,000金币)

问题:
- 初级丹药消耗白色材料，但白色过剩
- 高级丹药消耗蓝色，而蓝色稀缺(掉落15%)
- 配方设计未考虑"玩家等级进度"的材料可用性
```

**过时机制**:
- 玩家10级时常用初级丹，但25级后完全弃用
- 初级材料(白色)供应持续，但无消耗(dumpster)
- 无"材料降级"或"材料合成"系统回收

### 4.4 与公会系统的耦合

**建筑升级与材料**:
- 缺乏详细的"材料消耗表"
- 假设建筑升级需材料，但玩家无法查看具体需求
- 公会成员无"采集任务"获取材料
- 建筑升级是"管理员特权"，普通成员无参与感

## 5. 改进方向识别

### 5.1 短期改进（配置调整，1-2周）

#### 1. 调整材料掉落概率（缓解泛滥）

**当前问题**: 白色材料40%掉落率，导致背包爆炸

**改进方案**:
```
低级诡异(≤20级): 白色25%→20%, 绿色10%→15%
中级诡异(21-60级): 白色40%→30%, 绿色20%→25%, 蓝色5%→10%
高级诡异(61-100级): 白色30%→20%, 绿色25%→30%, 蓝色15%→20%, 紫色3%→5%
顶级诡异(101-200级): 白色20%→15%, 绿色20%→25%, 蓝色20%→25%, 紫色8%→10%, 橙色1%→2%
超级诡异(200+): 白色15%→10%, 绿色15%→20%, 蓝色25%→30%, 紫色12%→15%, 橙色3%→5%
```

**影响**: 减少白色产出30%, 增加稀有产出20%, 平衡回收

#### 2. 增加升阶石产出来源

**当前问题**: 升阶石仅商店售卖，无战斗掉落，金币压力大

**改进方案**:
- 高难副本(100+级): 5%概率掉落初级升阶石
- 顶级副本(150+级): 3%概率掉落中级升阶石
- 200+层诡异: 1%概率掉落高级升阶石
- 世界BOSS: 保证掉落2-3个升阶石(各等级混合)

**影响**: 减轻金币消耗20%, 增加副本吸引力

#### 3. 调整药品价格（修复刷经验漏洞）

**当前配置**: 回春散100金币、凝神草100金币(参考`game_balance_analysis_2025_12_01.md`)

**改进方案**:
- 回春散: 100→500金币 (配置中已有此建议)
- 凝神草: 100→500金币
- 血契丹: 1,000→2,000金币
- 阴冥草: 500→1,000金币

**影响**: 提高副本续航成本5倍, 削弱药品刷经验漏洞

### 5.2 中期改进（功能新增，2-4周）

#### 1. "材料兑换"系统（将泛滥转化为稀缺）

**设计**:
```
诡域材料兑换商人(NPC):
- 白色材料×10 → 绿色材料×1 (汇率1:10)
- 绿色材料×10 → 蓝色材料×1 (汇率1:10)
- 蓝色材料×10 → 紫色材料×1 (汇率1:10)
- 紫色材料×5 → 橙色材料×1 (汇率1:5)

每日兑换上限: 5次(防止无限套利)
交易费用: 1,000-10,000金币/次(取决于等级)
```

**实现位置**: `plugins/xiuxian_game/world/npc_service.py` 或新增NPC命令

**影响**:
- 白色材料获得消耗途径
- 玩家可自助转化等级
- 降低升级"等待时间"

#### 2. "装备修理模式"增强（支持材料修理）

**当前**: 装备修理仅消耗金币

**改进方案**:
```
修理选项:
1. 金币修理(快速): 100金币/点耐久 (现有)
2. 材料修理(便宜): 白色材料×1 = 2点耐久, 绿色×1 = 5点耐久 (新)
3. 混合修理: 50%材料 + 50%金币 (新)

优势:
- 消耗白色材料
- 玩家选择灵活(金币多的用金币, 材料多的用材料)
```

**实现位置**: `plugins/xiuxian_game/item/equipment_craft.py:375-436行`

#### 3. "材料图鉴"系统（增加收集成就感）

**设计**:
```
材料图鉴功能:
- 收集所有材料完整信息(掉落源、用途、价格)
- 进度跟踪(已收集:100/252材料)
- 成就奖励: 完成图鉴 → 额外奖励(金币、扫荡令等)
- 稀有材料集卡: 首次获得橙色材料 → +10,000金币奖励

实现收集价值:
- 激励玩家探索不同副本(为了获取特定材料)

```

**实现位置**: 新增模块 `plugins/xiuxian_game/item/material_collection_service.py`

### 5.3 长期优化（系统重构，1个月+）

#### 1. "材料分级系统"（重新设计稀缺度）

**当前问题**: 材料等级与玩家等级无关，导致泛滥与稀缺并存

**改进方案**:
```
分级系统(基于玩家等级):
1级材料(1-20级玩家用): 白色材料, 掉落30%, 供过于求
2级材料(21-50级): 绿色材料, 掉落25%, 供需平衡
3级材料(51-80级): 蓝色材料, 掉落20%, 轻微缺乏
4级材料(81-120级): 紫色材料, 掉落8%, 严重缺乏
5级材料(121+级): 橙色材料, 掉落3%, 极度稀缺

关键: 同一材料不再跨越多个等级使用(避免长期垃圾囤积)
```

#### 2. "动态掉落调整"（根据玩家等级优化）

**设计**:
```
副本掉落权重根据玩家等级调整:
- 玩家等级 > 副本等级 + 20: 白色掉落-50%, 稀有掉落+30% (激励向上挑战)
- 玩家等级 = 副本等级: 标准掉落 (推荐难度)
- 玩家等级 < 副本等级 - 20: 白色掉落+30%, 稀有掉落-50% (惩罚屠杀弱怪)
```

#### 3. "交易市场管制"（防止泛滥材料价格崩塌）

**当前问题**: 白色材料市价跌至20金币，造成玩家不愿出售(交易成本>收益)

**改进方案**:
```
底价保护机制:
- 底价 = 配置价 × 0.5 (最低保护)
- 例: 白色材料配置100金币 → 底价50金币
- 超低价挂单(如10金币)自动调整至底价

溢价上限:
- 上限 = 配置价 × 5 (防止炒作)
- 例: 白色材料上限500金币
- 超高价挂单自动调整至上限

交易税减免:
- 底价交易(50-100金币): 免交易税
- 普通价交易(100-300金币): 5%税率
- 高价交易(300+金币): 10%税率
```

**实现位置**: `plugins/xiuxian_game/economy/market.py:57-76行` (修改税率逻辑)

## 7. Report (调查结论)

### 7.1 Result (核心发现)

#### 材料稀缺性现状

**泛滥问题 (严重)**:
1. **白色材料过剩**: 日均产出15-25个, 日均消耗<5个, 净流入+10-20个/天
   - 配置价格100金币 vs 市价20-40金币（40%-60%贬值）
   - 导致玩家背包满载、市集底价崩塌
   - 无"材料回收"或"降级兑换"系统

2. **初级丹药材料无用**: 玩家10级后永久弃用初级丹药，但白色材料持续产出
   - 初级丹药消耗白色×8-10个，但仅用于Lv1-10阶段
   - 导致Lv20+玩家白色材料持续堆积

3. **低级装备锻造材料冗余**: 白骨护甲、鬼泪吊坠等初级装备配方消耗白色材料
   - 玩家升到中级装备后，这些配方永不再用
   - 造成白色材料"一次性消耗品"性质

**稀缺问题 (严重)**:
1. **橙色材料无法自然获取**:
   - 掉落概率1%-3%（顶级诡异1%, 超级诡异3%）
   - 需升级到200+层诡异才能合理刷取
   - 装备10阶升级需时光尘埃×1-2，需500天+才能自然获得
   - 结论：10阶装备事实上仅商店可买（RMB玩家特权）

2. **升阶石供应不足**:
   - 配置仅商店售卖(初级20,000金币、中级100,000金币)
   - 日均金币流入6,700-19,200，升阶石购买成本5,000-50,000/周
   - 高频升阶玩家需积累1-2周金币才能升一次
   - 缺乏"掉落来源"，无法通过副本努力获取

3. **蓝色材料略缺**:
   - 掉落概率15%-25%
   - 高级丹药(Lv71+)大量消耗
   - 日均需求>产出20%，玩家需"精选"使用

#### 材料与金币经济的矛盾

1. **单向流动**: 金币→材料(商店购买升阶石), 但材料无→金币途径(泛滥材料贬值)
2. **阶级分化**:
   - 躺赚玩家(10,800金币/天) 可无限购升阶石
   - 主动玩家(19,200金币/天) 难以同时升装备+炼丹+修理
3. **消耗不对等**: 白色材料日产>日消20倍, 而橙色材料日产/日需<0.05倍

#### 道具系统分析

**稀有道具** (扫荡令、棺材钉、重启符):
- 价格100,000-500,000金币
- 获取仅商店购买或新手任务(一次性)
- 缺乏"成就感"，变成"谁RMB多谁赢"

**消耗品道具** (回春散、凝神草):
- 价格100金币(严重低估)
- 导致药品刷经验漏洞(8.25倍效率)
- 需提价至500金币(参考`game_balance_analysis_2025_12_01.md`)

### 7.2 Conclusions (关键结论)

1. **材料稀缺性设计失衡**: 白色与橙色之间缺乏中间层级的有效衔接
   - 白色材料设计为"基础", 但掉落概率过高
   - 橙色材料设计为"极稀", 但掉落概率不是市场问题(而是刷副本成本)
   - 中间层级(绿、蓝、紫)供需相对平衡

2. **缺乏材料消耗设计**:
   - 系统内部无"材料回收"(降级、兑换)机制
   - 部分材料仅用于特定等级，升级后无用
   - 商人系统是"消耗金币→获材料"，非"消耗材料→获价值"

3. **经济学困境**:
   - 白色材料价格自由落体(100→20金币)，但存储成本不变
   - 玩家宁愿丢弃(0金币损失)也不愿出售(负利率)
   - 市集完全失效(底价吸附无法解决根本问题)

4. **升阶成本与金币不匹配**:
   - 初级升阶石20,000金币 = 3天金币收入(中等玩家)
   - 高级升阶石300,000金币 = 2-3周金币收入
   - 玩家倾向"囤积金币"而非"主动升装备"

5. **道具价格体系混乱**:
   - 消耗品(药品100金币) vs 道具(扫荡令100,000金币): 1,000倍差距无逻辑
   - 升阶石价格(20,000-300,000)与装备升阶效果不匹配(仅+5%-10%属性)
   - 玩家无法直观理解"什么物品应该值多少金币"

### 7.3 Relations (系统关联)

**材料流动链条**:
```
战斗产出 -(白色泛滥)→ 背包满载 -(丢弃)→ 损失/浪费
         -(绿蓝有用)→ 炼丹消耗 -(成功率70-90%)→ 部分失败损失
         -(橙色稀有)→ 积累困难 -(长期等待)→ 装备停滞

金币流动链条`:
```
签到/打工 -(6,700-19,200/天)→ 金币积累
银行利息 -(2,400-10,000/天)→ 躺赚金币(无消耗)
                 ↓
商店购买升阶石 -(100,000-300,000/周)→ 金币支出
装备修理/丹药 -(10,000-25,000/天)→ 持续消耗
                 ↓
净结果: 金币持续增长(最高34.4亿), 经济膨胀严重
```

**关键矛盾**:
1. **白色材料**: 供给过剩 vs 降级转化系统缺失 → 垃圾化
2. **升阶石**: 价格高(100,000金币) vs 供给足够(商店+BOSS) → 金币压力而非材料压力
3. **橙色材料**: 获取困难(200层诡异) vs 市场需求低(仅10阶升级) → 严重不对等
