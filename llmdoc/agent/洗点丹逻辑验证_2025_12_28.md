## 1. 用户担忧场景

玩家可能利用洗点丹"以少换多"的假设漏洞:

**假设漏洞流程**:
1. 穿上高级装备(攻击+500)
2. 使用洗点丹(洗掉这500点装备加成)
3. 卸下装备
4. 重新穿上装备
5. **净赚500点属性点**

如果此漏洞存在,玩家可以无限刷取属性点,破坏游戏平衡。

## 2. 代码分析

### 核心函数位置

`plugins/xiuxian_game/item/item_effects.py:494-630` (`_reforge_attr`)

### 关键逻辑流程

#### 2.1 获取当前属性值(第517-520行)

```python
# 获取当前属性值
current_value = getattr(player, source_attr)  # 包含: 基础 + 装备 + 丹药
```

此时 `player.attack = 基础100 + 装备500 + 丹药0 = 600`

#### 2.2 计算去除装备加成后的基础属性值(第522-545行)

```python
# 计算去除装备加成后的基础属性值
base_value = Decimal(str(current_value))  # 先复制总属性值

# 查询所有已装备物品
equipped_items = (await session.execute(stmt)).scalars().all()

# 遍历装备,减去装备加成
for eq in equipped_items:
    delta = (eq.extra_attrs or {}).get("_persist_bonus", {})
    bonus = delta.get(source_attr)
    if isinstance(bonus, (int, float, Decimal)):
        base_value -= Decimal(str(bonus))  # 关键: 减去装备加成
```

**防护机制**:
- 遍历 `equipped=True` 的装备
- 从 `extra_attrs["_persist_bonus"]` 读取装备持久化加成
- **从 `base_value` 中减去装备加成**

此时 `base_value = 600 - 500 = 100` (纯净基础值)

#### 2.3 计算转换量(第553-556行)

```python
# 计算转换量(每次使用转换一次,仅针对基础属性值)
percent_ratio = Decimal(str(percent)) / Decimal("100")  # 3% -> 0.03
convert_amount_decimal = Decimal(base_value_int) * percent_ratio * Decimal(qty)
convert_amount = int(convert_amount_decimal.to_integral_value(rounding=ROUND_DOWN))
```

**关键**: 转换量基于 `base_value_int` (纯净基础值),而非包含装备的 `current_value`

计算: `convert_amount = 100 * 3% = 3`

#### 2.4 扣除源属性(第602行)

```python
# 扣除源属性
setattr(player, source_attr, current_value - convert_amount)
```

此时 `player.attack = 600 - 3 = 597` (临时状态)

**潜在误解**: 这里是从包含装备的总属性中扣除,而不是从基础值扣除

#### 2.5 重新计算装备加成(第616行)

```python
# 重新计算装备加成
await _recalculate_equipment_bonus(session, player)
```

调用链:
```
_reforge_attr:616
  → _recalculate_equipment_bonus:item_effects.py:671
    → EquipmentService.recalc_equipment_attributes:equipment_service_new.py:41
```

**装备重计算逻辑** (`equipment_service_new.py:69-133`):

```python
# 1. 先移除所有已记录的装备加成
for eq in equipped_items:
    delta = (eq.extra_attrs or {}).get("_persist_bonus", {})
    for k, v in delta.items():
        current_value = getattr(player, k, 0)
        setattr(player, k, max(0, current_value - int(v or 0)))  # 移除装备加成

# 2. 基于当前基础属性重新应用装备加成
base_attrs = {
    "attack": player.attack,  # 此时已是扣除后的基础值
    ...
}

# 3. 重新应用装备加成
for eq in equipped_items:
    eq.apply_attr_bonus(attrs_temp, base_attrs)
    new_delta = {...}  # 计算新加成
    for k, v in new_delta.items():
        setattr(player, k, getattr(player, k) + v)  # 重新应用装备
```

**关键步骤**:
1. 移除装备: `player.attack = 597 - 500 = 97`
2. 读取基础: `base_attrs["attack"] = 97`
3. 重新应用: `player.attack = 97 + 500 = 597`

## 4. 防护机制验证

### 4.1 基础属性计算(第522-545行)

✅ **正确排除装备加成**
- 遍历所有 `equipped=True` 的装备
- 从 `extra_attrs["_persist_bonus"]` 读取持久化加成
- 从 `base_value` 中减去装备加成
- **确保 `base_value` 是纯净的基础属性**

### 4.2 转换量计算(第553-556行)

✅ **仅对基础属性生效**
- `convert_amount = base_value_int * percent_ratio`
- **基于 `base_value_int`,而非 `current_value`**
- 避免将装备加成计入转换量

### 4.3 装备重计算(第616行)

✅ **基于新基础值重新应用装备**
- 调用 `recalc_equipment_attributes`
- 先移除所有装备加成,暴露纯净基础值
- 基于扣除后的基础值重新计算装备加成
- **确保装备加成始终基于最新的基础属性**

### 4.4 无法利用装备的证明

**假设玩家尝试漏洞操作**:

1. **穿上高级装备**: `player.attack = 100 + 500 = 600`
2. **使用洗点丹**:
   - 基础值: `600 - 500 = 100` ✅ 已正确排除装备
   - 转换量: `100 * 3% = 3` ✅ 仅对基础100生效
   - 扣除后: `player.attack = 600 - 3 = 597`
   - 重算装备: `597 - 500(移除) + 500(重新应用) = 597` ✅
3. **卸下装备**: `player.attack = 597 - 500 = 97` ✅ 基础已减少3
4. **重新穿上**: `player.attack = 97 + 500 = 597` ✅ 无法获得额外属性

**结论**: 玩家获得3点属性点,基础攻击从100降至97,总攻击从600降至597,符合预期。

## 5. 结论

### 5.1 验证结果

✅ **洗点丹逻辑完全正确**

- ✅ 已正确排除装备加成
- ✅ 仅对基础属性+丹药属性生效
- ✅ 无法利用装备"以少换多"
- ✅ 装备重计算机制确保数据一致性

### 5.2 核心防护机制

1. **第522-545行**: 遍历已装备物品,计算真实基础属性
   - 从 `extra_attrs["_persist_bonus"]` 读取装备加成
   - 从总属性中减去装备加成,得到纯净基础值

2. **第554-556行**: 转换量仅针对基础属性
   - `convert_amount = base_value_int * percent_ratio`
   - **基于纯净基础值,而非包含装备的总值**

3. **第616行**: 调用 `_recalculate_equipment_bonus` 重新计算装备加成
   - `EquipmentService.recalc_equipment_attributes` 确保基于新基础值重算
   - 先移除装备 → 读取基础 → 重新应用装备

### 5.3 设计优势

**_persist_bonus机制的价值**:
- 持久化每件装备的实际加成值
- 避免每次战斗重新计算装备加成
- 卸下装备时属性准确回退
- 使用丹药后自动重算装备百分比加成

**双重防护**:
1. 洗点时显式减去装备加成(第542行)
2. 重算时基于纯净基础值重新应用(第616行)
