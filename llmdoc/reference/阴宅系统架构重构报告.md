# 阴宅系统架构重构报告

**重构日期**: 2025-12-28
**重构目标**: 统一阴宅系统架构,移除双版本并存问题,全面采用DI架构

---

## 重构背景

### 问题分析

**原文见**: `/llmdoc/reference/阴宅系统现状调研.md` 第6.2节

阴宅系统存在双版本Service并存问题:
- `mansion.py` (旧版,806行) - 使用静态方法模式
- `mansion_service_new.py` (新版,804行) - 使用DI架构

**具体问题**:
1. **代码重复**: 两个文件几乎完全相同,维护成本高
2. **架构不一致**: 命令处理器已切换到新版DI架构,但核心逻辑(修炼/闭关/出关)仍在调用旧版静态方法
3. **TODO标记未完成**: `mansion_service_new.py`中存在TODO,需要扩展PlayerRepository
4. **直接访问私有成员**: 新版Service中存在`self._player_repo._session`,破坏封装

### 影响范围

**受影响的文件**:
- `plugins/xiuxian_game/cultivate/core.py` - 修炼/闭关/出关核心逻辑
- `plugins/xiuxian_game/cultivate/mansion_commands.py` - 阴宅命令处理器
- `plugins/xiuxian_game/world/attack_command.py` - 攻击命令(阴宅安全区判定)
- `plugins/xiuxian_game/world/real_world_explore.py` - 探索命令(附近阴宅查询)
- `plugins/xiuxian_game/cultivate/__init__.py` - 模块导入

---

## 重构方案

### 设计原则

1. **统一DI架构**: 全面采用依赖注入模式,与项目其他模块(公会、任务等)保持一致
2. **Repository模式**: 所有数据访问通过Repository,不直接访问Session
3. **向后兼容**: 保持所有公开API的签名和行为不变
4. **渐进式迁移**: 先完成Repository扩展,再迁移调用方,最后删除旧版

### 架构对比

**旧版 (静态方法)**:
```python
from .mansion import MansionService

# 直接调用静态方法
mansion_bonus = MansionService.get_efficiency_bonus(level)
mansion_owner = await MansionService.find_mansion_owner_at_location(session, x, y)
```

**新版 (DI架构)**:
```python
from .mansion_service_new import MansionService
from ..infrastructure.repositories.player_repository import PlayerRepository

# 注入Repository依赖
service = MansionService(player_repo=PlayerRepository(session))
mansion_bonus = MansionService.get_efficiency_bonus(level)  # 静态工具方法保持不变
mansion_owner = await service.find_mansion_owner_at_location(x, y)  # 实例方法
```

**文件**: `plugins/xiuxian_game/infrastructure/respositories/player_repository.py`

**新增方法**:
```python
async def find_mansion_owner_at_location(self, x: int, y: int) -> Optional[Player]:
    """
    查找指定坐标的阴宅主人

    Args:
        x: X坐标
        y: Y坐标

    Returns:
        阴宅主人对象,如果该位置没有阴宅则返回 None
    """
    stmt = select(Player).where(
        and_(
            Player.mansion_x == x,
            Player.mansion_y == y,
            Player.mansion_level > 0
        )
    )
    result = await self._session.execute(stmt)
    return result.scalar_one_or_none()
```
