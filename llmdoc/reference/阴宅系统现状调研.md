```python
mansion_level: Mapped[int] = mapped_column(Integer, default=0, server_default='0', comment="阴宅等级(0表示未拥有)")
```

**唯一约束** (防止多个阴宅建在同一位置):
```python
Index('idx_mansion_location_unique', 'mansion_x', 'mansion_y',
      unique=True,
      postgresql_where=text('mansion_level > 0 AND mansion_x IS NOT NULL AND mansion_y IS NOT NULL'),
      sqlite_where=text('mansion_level > 0 AND mansion_x IS NOT NULL AND mansion_y IS NOT NULL'))
```

### 1.2 字段设计说明

| 字段 | 类型 | 默认值 | 用途 |
|------|------|--------|------|
| `mansion_level` | int | 0 | 阴宅等级，0=未拥有，1-30为已拥有等级 |
| `mansion_x`, `mansion_y` | int\|null | NULL | 阴宅在世界地图的坐标位置 |
| `mansion_usage_fee` | int | 0 | 其他玩家使用此阴宅需支付的费用（金币） |
| `mansion_allow_others` | bool | true | 阴宅主人是否允许他人使用 |
| `mansion_willing_to_pay` | bool | true | 玩家是否愿意付费使用他人阴宅 |

### 1.3 数据模型特点

**优点**:
- 使用Player表扩展，无需额外表关联，查询效率高
- 唯一约束保证地图上每个坐标最多一个阴宅
- 使用NULL表示未拥有状态，`mansion_level=0`作为辅助判断

**潜在问题**:
- Coordinate存储方式与Player当前坐标(region, x, y)不同，阴宅只存储x,y不存储region
- `mansion_level=0`和NULL坐标都表示未拥有，存在语义重复

## 2. 阴宅等级与修炼效率机制

### 2.1 等级配置

**位置**: `plugins/xiuxian_game/cultivate/mansion_service_new.py:15-25`

```python
MAX_LEVEL = 30  # 最大等级
BASE_UPGRADE_COST = 10_000_000  # 基础升级费用（1千万）
COST_MULTIPLIER = 1.5  # 费用递增倍数
BASE_EFFICIENCY = 0.2  # 基础效率加成（20%）
EFFICIENCY_INCREMENT = 0.09  # 每级效率递增（9%）
```

### 2.2 效率加成计算

**位置**: `plugins/xiuxian_game/cultivate/mansion_service_new.py:74-90`

```python
efficiency = BASE_EFFICIENCY + ((mansion_level - 1) * EFFICIENCY_INCREMENT)
# 公式：0.2 + ((等级-1) * 0.09)
# 1级=20%, 2级=29%, 3级=38%, ..., 10级=101%
```

**效率加成示例**:
| 等级 | 效率加成 | 计算公式 |
|------|---------|---------|
| 1级 | 20% | 0.2 + (0 * 0.09) = 0.20 |
| 5级 | 56% | 0.2 + (4 * 0.09) = 0.56 |
| 10级 | 101% | 0.2 + (9 * 0.09) = 1.01 |
| 20级 | 191% | 0.2 + (19 * 0.09) = 1.91 |
| 30级 | 281% | 0.2 + (29 * 0.09) = 2.81 |

### 2.3 修炼中的实际应用

**位置**: `plugins/xiuxian_game/cultivate/core.py:126-169`

**修炼指令加成计算流程**:
```python
# 1. 获取基础经验
base_exp_gain = cfg["base_exp"] * (1 + player.level / k) * random.uniform(0.8, 1.2)

# 2. 检查当前位置阴宅
mansion_owner = await service.find_mansion_owner_at_location(current_x, current_y)

# 3. 验证使用权并扣费
can_use, use_msg = await service.can_use_mansion(player, mansion_owner)
if can_use:
    payment_success, payment_msg = await service.pay_mansion_usage_fee(player, mansion_owner)
    if payment_success:
        mansion_cultivation_bonus = MansionService.get_efficiency_bonus(mansion_owner.mansion_level)

# 4. 计算阴宅加成（基于基础经验）
mansion_bonus = int(base_exp_gain * mansion_cultivation_bonus)

# 5. 总经验 = 基础 + 月卡 + 冥返 + 公会 + 阴宅
exp_gain = base_exp_gain + card_bonus + reincarnation_bonus + guild_bonus + mansion_bonus
```

**闭关指令特殊处理** (`core.py:284-308`):
- 闭关时**不支付使用费用**，只需检查权限
- 仅当是自己的阴宅，或者主人允许且玩家愿意付费时，享受加成
- 避免了闭关期间重复扣费的问题

**出关指令结算** (`core.py:410-438`):
- 出关时**一次性支付使用费用**（对应闭关期间的加成）
- 如果闭关时使用了他人阴宅，出关时扣费并应用加成

## 3. 阴宅升级逻辑和消耗

### 3.1 升级费用计算

**位置**: `plugins/xiuxian_game/cultivate/mansion_service_new.py:56-71`

```python
def get_upgrade_cost(current_level: int) -> int:
    if current_level >= MAX_LEVEL:
        return 0
    # 公式：基础费用 * (倍数 ^ 当前等级)
    cost = int(BASE_UPGRADE_COST * (COST_MULTIPLIER ** current_level))
    return cost
```

**升级费用示例**:
| 等级 | 升级费用 | 计算公式 |
|------|---------|---------|
| 0→1级 | 1000万 | 1000万 * (1.5^0) = 1000万 |
| 1→2级 | 1500万 | 1000万 * (1.5^1) = 1500万 |
| 2→3级 | 2250万 | 1000万 * (1.5^2) = 2250万 |
| 5→6级 | 7594万 | 1000万 * (1.5^5) = 7594万 |
| 10→11级 | 5.77亿 | 1000万 * (1.5^10) = 5.77亿 |
| 20→21级 | 3325亿 | 1000万 * (1.5^20) = 3325亿 |
| 29→30级 | 19万亿 | 1000万 * (1.5^29) = 19万亿 |

**费用曲线特征**:
- 指数增长，后期升级成本极高
- 10级前相对友好（5.77亿）
- 20级后进入极高门槛（3325亿）
- 30级满级需要天文数字（19万亿）

### 3.2 购买阴宅（0→1级）

**位置**: `plugins/xiuxian_game/cultivate/mansion_service_new.py:570-636`

**购买条件检查**:
1. 玩家未拥有阴宅（`mansion_level=0`）
2. 金币≥1000万（购买费用）
3. 当前位置不是原点(0,0)（保护新手区）
4. 距离城镇市集≥20格（防止建在市集旁）
5. 当前位置无其他玩家阴宅（唯一约束）

**购买成功后状态**:
```python
player.mansion_level = 1
player.mansion_x = current_x
player.mansion_y = current_y
player.mansion_usage_fee = 1000  # 1级最低费用
```

### 3.3 升级阴宅（n→n+1级）

**位置**: `plugins/xiuxian_game/cultivate/mansion_service_new.py:360-425`

**升级条件检查**:
1. 未达到最大等级（30级）
2. 金币≥升级费用
3. 玩家在阴宅位置（防止远程升级）

**升级后自动调整**:
- `mansion_level += 1`
- 如果`mansion_usage_fee < 新等级最低要求`，自动调整到最低要求
- 例如：1级→2级，费用从1000自动调整到1500

## 5. 阴宅在玩家整体系统中的定位

### 5.1 修炼加成体系

**阴宅与其他加成系统的对比**:

| 加成来源 | 最高加成 | 适用场景 | 获取成本 |
|---------|---------|---------|---------|
| **阴宅** | 281% (30级) | 修炼/闭关 | 1000万购买 + 19万亿升级 |
| **月卡** | 50% | 修炼/闭关 | 30元/月 |
| **冥返** | 400% (20转) | 修炼/闭关 | 转生系统 |
| **公会** | 50% (炼丹房10级) | 修炼/闭关 | 公会建设 |
| **棺材钉** | 50% (100根) | 闭关 | 装备制作/购买 |

**阴宅的独特性**:
- **位置限制**：必须在阴宅坐标才能享受加成
- **社交属性**：可以出租给其他玩家，赚取金币
- **永久资产**：购买后永久拥有，可迁移位置

### 5.2 经济系统角色

**阴宅作为经济工具**:

1. **金币汇接收割**：
   - 其他玩家使用阴宅需要支付费用
   - 费用直接从使用者金币转移给主人（无手续费）
   - 高等级阴宅可以成为稳定收入来源

2. **使用费用市场**：
   - 1级最低费用：1000金币
   - 30级最低费用：1.55万金币
   - 主人可自由设置价格（1000-500万）
   - 形成阴宅租赁市场

3. **升级费用**：
   - 指数级消耗大量金币
   - 后期升级成本极高，是重要的金币汇

### 5.3 社交互动载体

**阴宅促进玩家互动**:

1. **位置竞争**：
   - 一个坐标只能有一个阴宅
   - 优质位置（靠近市集、交通枢纽）具有稀缺性

2. **租赁关系**：
   - 玩家可以付费使用他人阴宅
   - 形成阴宅主人和租户的社交关系

3. **地图探索**：
   - 玩家通过【附近地点】、【观察】发现阴宅
   - 促进玩家移动到阴宅位置修炼
