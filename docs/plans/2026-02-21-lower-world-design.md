## 一、世界观与叙事基调

### 核心隐喻

大都会（诡修赛博世界）发现了一套"诡异导流术"：
将原本会侵蚀大都会的诡异，借助被选定的"天灾节点"，引流到下位世界。

玩家不是自愿的征服者，是被选中的**导管**。
大都会得救了。下位世界不知道发生了什么。
两个世界都没有错——都只是想活着。

### 叙事原则

- 文案**白话易懂**，避免生僻词
- 诡异入侵的**视觉细节必须到位**（地面龟裂、鬼域张开、叩门声从影子传出）
- 给玩家制造**惭愧感和内心挣扎**，而不是征服感
- 下位世界的英雄是**有血有肉的人**，不是障碍

## 三、数据模型

通过 `auto_migrate.py` 的 `REQUIRED_FIELDS` 自动迁移，无需手动执行 Alembic。

| 字段 | 类型 | 说明 |
|------|------|------|
| `player_id` | VARCHAR(64) PK | 关联玩家 |

## 五、波次机制

### 节奏

- 每 **2小时** 系统自动推送一波英雄
- 英雄到达后**等待4小时**，超时自动撤退（算平局，不得不失天灾点）
- 玩家收到提醒：`⚔️ 第X波英雄已抵达你的山寨！使用【迎战】应战`

### 英雄强度缩放

```
英雄等级 = 玩家等级 × (0.6 + 波次 × 0.04)

示例（玩家100级）：
  第1波  → 60级（轻松热身）
  第5波  → 80级（有点压力）
  第10波 → 100级（势均力敌）
  第20波 → 130级（开始艰难）
```

### 奖励与波次对照

| 波次段 | 英雄类型 | 天灾点奖励 |
|--------|---------|-----------|
| 1-5波 | 普通骑士/圣女 | 5点/波 |
| 6-10波 | 骑士团长/大魔导士 | 10点/波 |
| 11-20波 | 各系勇者 | 20点/波 |
| 21+波 | 勇者+随机词缀强化 | 30点/波 |

### 失败惩罚

被击败后**封印24小时**，无法进入该玩法。

## 七、核心文案

### 【降临】

```
📋 大都会第七分部紧急会议记录

敲门诡在第十七区扩散，鬼域裂缝停不下来了。
再不处理，七十二小时内整个分部都会被吞掉。

会长看了一眼数据，说：
「导流。补偿打账户里。」

就这一句话。会议结束了。

你收到一条消息——
「你已被选为第四天灾导流节点，请配合传送。」

你还没看完，那些诡异的气息就扑过来了。
不是来打你的——它们要钻进你身体里。
它们把你当成了一扇门。

然后你就掉下去了。

睁开眼，天是另一种颜色。
有个小孩看见你，大叫一声"天灾来了"，
撒腿就跑，摔了一跤，爬起来继续跑。

你低头看自己落脚的地方——
地面正在龟裂，裂缝里渗出灰色的雾。
你身后，鬼域已经张开了。
叩门声从你的影子里传出来，一下一下，
敲进这片土地。

这里的人还不知道，
大都会把什么东西送过来了。

⚠️ 你已降临下位世界，成为「第四天灾」
   大都会的诡异正通过你持续涌入这个世界
   2小时后，这里的英雄会来找你
   ——大都会那边已经收到你的报酬了
```

### 【镇守】正常状态

```
📡 山寨状态
天灾点：{calamity_points}  |  当前波次：第{wave_number}波

鬼域裂缝已在山寨周围蔓延。
叩门声在石墙里流动——你带来的东西正在这里生根。

「下位世界的人把这里叫做'灾地'。
 村子里已经有人说：墙壁会动。」

⏳ 下一波英雄将在 {time_left} 后抵达
```

### 【镇守】封印状态

```
⛓️ 你被封印了（剩余：{sealed_left}）

圣光骑士把封印刻在你额头时说：
「你不是坏人，对吧。」
「但我们也没有别的选择。」

你们都沉默着。
```

### 【迎战】前

```
⚔️ {hero_name} 踏入了山寨

{hero_flavour}

他/她举起武器，眼里是害怕，但没有退缩。

【确认迎战请再次发送：迎战】
```

### 【迎战】胜利

```
……{hero_name} 倒下了。

他/她望着你，没有仇恨，只是问：
「你们那边……也会有人哭吗？」

你没有回答。
你身后，诡异继续往外涌。

+{points}天灾点（当前：{total}点）
「大都会那边有人因此平安了。
 他们不知道你的名字。」
```

### 【迎战】失败

```
你倒下了。

{hero_name} 没有趁机补刀，只是站在原地，
把武器插回剑鞘。

「走吧，天灾。
 今天先到这里。」

⛓️ 你被封印24小时
```

## 八、技术实现要点

### 文件结构

```
plugins/xiuxian_game/lower_world/
├── __init__.py
├── commands.py          # 所有命令处理器
├── service.py           # 业务逻辑（英雄生成、战斗结算）
├── hero_generator.py    # 英雄名字/属性生成
├── scheduler.py         # 定时任务（每2小时推送波次）
└── shop.py              # 天灾商店
```

### 与现有系统的集成

- **战斗**：复用 `BattleIntegrationHelper.enhanced_player_vs_monster_battle_v2`
- **数据库**：通过 `auto_migrate.py` 的 `REQUIRED_FIELDS` 添加 `lower_world_stronghold` 表
- **定时任务**：使用现有 APScheduler（参考 `inner_realm/scheduler.py`）
- **架构**：遵循 DI 架构（UnitOfWork + Repository 模式）

### NoneBot2 异常处理规范

严格遵守项目规范：
- **不使用** `except Exception` 捕获所有异常
- `finish()`、`send()` 调用放在 try-except 块**外部**
- 只捕获具体异常（`ValueError`、`json.JSONDecodeError` 等）

### 帮助信息

实现后需更新 `plugins/xiuxian_game/player/help.py`，添加：
- 【降临】、【镇守】、【迎战】、【天灾商店】、【兑换】的用法说明
