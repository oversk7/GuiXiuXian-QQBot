## 1. 游戏愿景

### 1.1 一句话定位

**在末日废土中，从孤身求生到结伴建城，用每一颗子弹和每一口罐头书写人类的重建史诗。**

### 1.2 核心设计理念

| 理念 | 说明 | 对比诡修仙 |
|------|------|-----------|
| **每一份资源都有重量** | 子弹、食物、药品全部有限，花掉就没了 | 修仙法力近乎无限 |
| **战斗是选择，不是惯例** | 打不打比怎么打更重要 | 战斗是主要玩法 |
| **合作不是锦上添花而是生存必须** | 独狼能活，但据点需要群体 | 公会是可选社交 |
| **废墟中有故事** | 每个地点、每个 NPC 都有末日前后的叙事 | 修仙世界观较抽象 |
| **死亡有代价但不绝望** | 死亡掉落部分物资，但角色不消失 | 转生重置等级 |
| **普通枪械不是万能的** | 属性变异体有异源护盾，必须用聚元手段破盾 | 攻击力碾压一切 |

### 1.3 玩家情感旅程

```
第一阶段【孤身求生】
  "我快饿死了，得找点吃的"
  → 紧张、不安、小心翼翼

第二阶段【站稳脚跟】
  "终于有把枪了，能打猎，能防身"
  → 安全感、小有成就

第三阶段【结伴同行】
  "有人了，可以轮班守夜，一起搜刮"
  → 归属感、信任建立

第四阶段【据点初建】
  "我们有家了，有围墙，有水源"
  → 自豪感、保护欲

第五阶段【抵御尸潮】
  "它们来了——守住据点！"
  → 热血、紧张、团队荣誉

第六阶段【废土重建】
  "据点之间开始通商，文明在重生"
  → 史诗感、成就感
```

## 2. 核心体验循环

### 2.1 日循环（单次登录 5-15 分钟）

```
搜刮低危区 → 获得食物/水/基础材料（消耗少量补给）
    ↓
整理补给 → 存入据点仓库 / 吃喝补充
    ↓
探索高危区 → 带足补给出门，获得稀有物资/遭遇事件（消耗更多补给+弹药）
    ↓
据点贡献 → 存入物资/建设设施/制造装备
```

> **节奏特点**: 每次行动消耗 1 份食物 + 1 份水，但搜刮本身也产出食物和水。活跃玩家每天约 10-15 次行动，佛系玩家每天 3-5 次也能自给自足。不登录时角色安全在据点，什么都不消耗。

### 2.2 周循环（中期目标）

```
周一~周五  日常搜刮积累物资 + 据点建设
周六      商队抵达（限时交易机会）
周日      尸潮来袭（据点防御战）
```

> **设计意图**: 周日尸潮是一周物资积累的"考试"，强化物资收集的意义感。如果据点被打穿，下周需要花时间修复，形成紧张的循环节奏。

### 2.3 长期循环（月度/赛季）

```
探索新区域 → 发现新资源/新威胁
    ↓
升级科技 → 解锁新武器/新建筑/新配方
    ↓
扩张据点 → 更大范围/更多人口/更强防御
    ↓
据点联盟 → 据点间贸易/联合防御/争夺资源区
    ↓
废土重建 → 赛季目标（修复发电站/净水厂/通信塔等）
```

## 3. 生存系统

### 3.1 核心设计原则：行动消耗制

> **关键决策**: 本游戏**不采用实时状态衰减**。玩家不在线时，角色安全待在据点，什么都不会掉。生存压力只在玩家主动行动时产生。
>
> **设计理由**: 目标用户是未成年人，登录频率不固定。实时衰减会变成负担（"不上线就饿死"），行动消耗制让玩家按自己的节奏玩——上线做事消耗资源，下线安全无忧。

### 3.2 行动消耗模型

每次玩家执行行动，消耗对应的**补给**。补给不足时行动会受到惩罚但不会被完全锁死：

| 行动 | 食物消耗 | 饮水消耗 | 说明 |
|------|---------|---------|------|
| **搜刮**（1 次） | 1 | 1 | 基础资源循环——搜刮本身就消耗补给 |
| **探索新区域** | 2 | 2 | 长途跋涉消耗更多 |
| **战斗**（1 场） | 1 | 1 | 战斗是体力活 |
| **制造**（1 次） | 0 | 0 | 在据点内，不消耗补给 |
| **据点建设** | 1 | 1 | 体力劳动 |
| **休整**（离线恢复） | 0 | 0 | 据点自动照顾，免费 |

**补给不足的惩罚**（不是阻止行动，而是降低效率）：

| 状态 | 条件 | 效果 |
|------|------|------|
| **正常** | 食物 ≥ 1 且 饮水 ≥ 1 | 无惩罚 |
| **饥饿** | 食物 = 0 | 攻击力 -25%，搜刮品质降一档 |
| **干渴** | 饮水 = 0 | 命中率 -25%，闪避率 -15% |
| **虚弱** | 食物和饮水均 = 0 | 以上叠加，且每次行动损失 5 点健康值 |

> **设计意图**: 没有补给也能行动（不会"饿到动不了"），但效率大打折扣。这鼓励玩家优先搜集食物和水，但不强迫按时登录。

### 3.3 健康值（唯一的核心状态条）

健康值是角色唯一需要关注的生命状态：

| 属性 | 说明 |
|------|------|
| **范围** | 0-100（随体能属性提升上限，公式：100 + 体能 × 5） |
| **不会自然衰减** | 只有战斗受伤、虚弱状态行动、环境伤害才会降低 |
| **恢复方式** | 绷带（+20）、医疗包（+50）、据点医疗站（休整时自动回满） |
| **归零 = 倒下** | 触发死亡流程（见 4.5 节） |

### 3.4 精神值（轻量级增益系统）

精神值不实时衰减，而是作为**行动Buff/Debuff**存在：

| 精神状态 | 范围 | 效果 | 触发/恢复方式 |
|---------|------|------|-------------|
| **恐慌** | 0-19 | 遭遇战有 30% 概率自动逃跑，NPC 好感获取 -50% | 连续死亡/遭遇恐怖事件时降低 |
| **低落** | 20-39 | 搜刮品质 -10% | 独自行动太久时缓慢降低 |
| **正常** | 40-69 | 无加成无惩罚 | 默认状态 |
| **振奋** | 70-89 | 暴击率 +5%，搜刮发现稀有品概率 +10% | 与队友一起行动/完成任务/使用娱乐品 |
| **高昂** | 90-100 | 暴击率 +10%，稀有品概率 +15%，NPC 好感 +20% | 成功击退尸潮/完成故事任务 |

**精神值变化规则**:
- **下降**: 死亡 -20、遭遇恐怖事件 -10、独自行动每次 -1（鼓励社交）
- **恢复**: 与队友共同搜刮 +2/次、使用娱乐品（烟酒书籍）+15、据点休整回到 60、击退尸潮 +30

### 3.6 食物 Buff 系统（烹饪）

> **参考**: 阿瑞斯病毒中饱食度 160+ 触发"体力充沛"buff。食物不仅是消耗品，更是主动增益来源。

食物分为**生食**和**烹饪料理**两类。生食只能恢复补给数量，烹饪料理额外提供**限时 buff**：

**生食**（直接食用，仅补充补给）:

| 食物 | 补给恢复 | 获取方式 |
|------|---------|---------|
| 罐头 | 食物 +2 | 搜刮（常见） |
| 矿泉水 | 饮水 +2 | 搜刮（常见） |
| 野果 | 食物 +1 | 搜刮郊区/森林 |
| 生肉 | 食物 +1（10% 概率生病：-10 健康） | 击杀野兽 |

**烹饪料理**（需要据点厨房，提供 buff 持续 N 次行动）:

| 料理 | 所需材料 | Buff 效果 | 持续 | 厨房等级 |
|------|---------|-----------|------|---------|
| **烤肉** | 生肉×2 + 木材×1 | 攻击力 +10% | 3 次行动 | Lv1 |
| **炖汤** | 罐头×1 + 草药×1 + 净水×1 | 搜刮品质 +15% | 3 次行动 | Lv1 |
| **干粮包** | 面粉×2 + 盐×1 | 行动食物消耗减半 | 5 次行动 | Lv1 |
| **草药茶** | 草药×2 + 净水×1 | 精神值 +20 | 即时 | Lv1 |
| **猎手烤串** | 变异肉×2 + 香料×1 | 暴击率 +8%，命中率 +5% | 3 次行动 | Lv2 |
| **铁壁炖菜** | 厚皮×1 + 蔬菜×2 + 盐×1 | 护甲 +15%，健康上限 +10 | 3 次行动 | Lv2 |
| **鹰眼浆果** | 稀有浆果×3 + 蜂蜜×1 | 感知 +5（搜刮+侦查全面提升） | 5 次行动 | Lv3 |
| **末日盛宴** | 优质肉×3 + 香料×2 + 酒×1 | 全属性 +5%，精神值回满 | 5 次行动 | Lv3 |

**烹饪规则**:
- 烹饪需要在据点厨房进行，不消耗行动次数
- 料理做好后放入背包，出门前**吃一份**激活 buff
- 同时只能激活 **1 个**食物 buff（新的覆盖旧的）
- buff 持续 N 次"消耗补给的行动"（搜刮/战斗/探索），不计时间

> **设计意图**: 食物从"出门必须带的消耗品"升级为"出门前选择吃什么加成"的策略选择。去打 Boss 吃猎手烤串（暴击），去远征搜刮吃炖汤（品质），去高危区吃铁壁炖菜（抗揍）。这也给据点农场和厨房提供了建设动力。

> **设计意图**: 精神值是一个"奖励社交行为"的软系统，不是惩罚独狼。独自玩也完全可行，只是和朋友一起玩有额外加成。

### 3.5 环境威胁

环境威胁不是持续debuff，而是**特定区域/特定时间的修正**，只在玩家主动进入时生效：

| 环境 | 触发条件 | 效果 | 防护方式 |
|------|---------|------|---------|
| **辐射区** | 进入特定区域 | 每次行动 -5 健康，战斗中每回合 -3 健康 | 防辐射服/碘片（抵消伤害） |
| **沙暴** | 随机天气事件（持续数小时） | 命中率 -30%，搜刮效率 -50% | 不出门/防风面罩 |
| **酸雨** | 随机天气事件 | 行动时装备耐久额外 -5% | 不出门/防腐涂层 |
| **极寒夜** | 每天 22:00-06:00 | 行动食物消耗 ×2 | 保暖衣物/不出门 |

> **设计意图**: 天气和环境是"今天适不适合出门"的决策因素，不是被动扣血的焦虑来源。沙暴天可以选择待在据点搞制造和建设。

## 4. 角色与成长系统

### 4.1 设计哲学

**不设等级。** 废土没有"50 级勇者"的概念。角色强度由 **技能熟练度 + 装备质量 + 物资储备** 三者决定。这意味着一个老手即使丢光装备，凭技能依然比新人强，但不会出现"碾压一切"的数值差距。

### 4.2 核心属性（6 项）

| 属性 | 影响 | 初始值 | 成长方式 |
|------|------|--------|---------|
| **体能** | 生命上限、近战伤害、负重、耐力 | 10 | 近战战斗/体力劳动/训练场 |
| **射术** | 远程命中率、暴击率、换弹速度 | 5 | 使用枪械战斗/射击训练 |
| **敏捷** | 闪避率、先手权、移动力、逃跑成功率 | 8 | 被攻击时闪避/据点跑酷训练 |
| **感知** | 搜刮品质、侦查距离、伏击识破率、陷阱发现率 | 8 | 探索新区域/侦查行动 |
| **机械** | 制造品质、武器改装、车辆维修、陷阱制造 | 5 | 制造物品/修理装备/拆解装备 |
| **意志** | 精神上限、辐射抗性、恐惧抵抗、NPC 好感增益 | 8 | 经历危机事件/与 NPC 深度交流 |

### 4.3 技能使用即升级（Use-Based Skill System）

属性不通过分配点数提升，而是**用了就涨**：

```
[射术提升规则]
- 每次枪械战斗中命中敌人 → 射术经验 +3
- 每次枪械战斗中暴击 → 射术经验 +5
- 在射击训练场练习 → 射术经验 +2（每日上限 20）
- 达到经验阈值自动升级（阈值递增）

属性 1→2:  100 经验
属性 2→3:  250 经验
属性 3→5:  400 经验
...
属性上限:  50（对应的行为已完全精通）
```

### 4.4 专长系统（替代修仙境界）

属性达到特定阈值时，解锁专长（被动能力），为角色提供方向性特化：

| 条件 | 专长名 | 效果 |
|------|--------|------|
| 射术 ≥ 15 | 稳射手 | 首发子弹命中率 +20% |
| 射术 ≥ 30 | 神射手 | 远距离命中率惩罚减半 |
| 体能 ≥ 15 | 铁骨 | 近战伤害减免 15% |
| 体能 ≥ 30 | 人形坦克 | 生命值上限 +30% |
| 感知 ≥ 15 | 拾荒者 | 搜刮额外获得 1 个物品栏位 |
| 感知 ≥ 30 | 鹰眼 | 自动侦查一个区域的敌人数量 |
| 机械 ≥ 15 | 修理工 | 修理消耗材料减半 |
| 机械 ≥ 30 | 军械师 | 解锁高级改装配方 |
| 敏捷 ≥ 15 | 灵活身手 | 被包围时闪避率不降低 |
| 意志 ≥ 15 | 铁心 | 精神值衰减速率 -30% |
| 体能≥20 且 射术≥20 | 突击手 | 冲锋后首次攻击伤害 +25% |
| 感知≥20 且 机械≥20 | 陷阱大师 | 陷阱伤害 +50%，制作不消耗稀有材料 |

### 4.5 死亡与惩罚

> **核心原则**: 目标用户是未成年人，死亡会频繁发生。惩罚要让人"心疼"但不"心寒"——丢的东西能拿回来，长期积累绝不被抹掉。死亡甚至可以变成社交互动的契机。

**死亡流程**:

```
健康值归零
    ↓
【倒下】进入"濒死"状态（持续 15 分钟）
    ↓
  ┌─ 有队友？→ 队友使用医疗包救起（恢复 30% 健康，不掉落任何东西）
  └─ 无队友？→ 15 分钟后"死亡"
    ↓
【死亡】在据点重生，背包物资掉落在死亡地点
```

**掉落规则**:

| 项目 | 死亡时 | 说明 |
|------|--------|------|
| **背包物资** | 全部掉落在死亡地点，形成"遗物包" | 不是消失，是掉在地上 |
| **身上装备** | **不掉落**，耐久 -10% | 装备是长期投入，不能因一次死亡就没了 |
| **技能/属性经验** | **不丢失** | 永久积累，绝不回退 |
| **据点仓库物资** | **不受影响** | 已存入的物资 100% 安全 |
| **精神值** | -20 | 死亡打击精神 |

**遗物包回收机制**:

- 死亡后，物资掉落形成"遗物包"，**标记在地图上**
- **本人回收**: 复活后可以返回死亡地点执行【回收遗物】，**100% 取回**
- **队友代捡**: 同据点成员可以去死亡地点帮忙捡回，**100% 取回**
- **他人拾取**: 非同据点玩家也能看到遗物包，**可以拾取**（PvP 风险元素）
- **超时消失**: 24 小时后遗物包消失（足够长，不焦虑）
- **每人最多 1 个遗物包**: 再次死亡时旧遗物包立即消失（防止刷物资）

**设计意图**:
1. **"兄弟帮我捡包"** — 死亡变成了社交互动，而不是孤独的惩罚
2. **鼓励存仓库** — 搜刮完及时把好东西存入据点仓库，背包只带必需品出门
3. **鼓励组队** — 有队友可以当场救起，连包都不用掉
4. **不惩罚长期积累** — 技能、装备、据点物资全部安全，丢的只是"这一趟出门带的东西"

**连续死亡保护**:
- 30 分钟内连续死亡 2 次，第 3 次起获得"天使护佑"：背包只掉落 50%
- 防止新手玩家在高危区域反复被杀导致物资清空的恶性循环

## 5. 战斗系统

### 5.1 设计原则

> **核心理念**: 在废土，战斗不是刷怪升级的手段，而是有代价的生存选择。每一发子弹都有成本，每一次受伤都需要药品。最好的战斗是不战而胜。

### 5.2 战斗前置：遭遇阶段

战斗不是自动开始的。玩家在探索时遭遇敌人后，先进入**遭遇阶段**，可以选择应对方式：

```
【遭遇警报】
你在废弃超市二楼发现动静——
3 名拾荒匪，装备：木棒×2、手枪×1
距离：中距离  你的位置：走廊拐角(可隐蔽)

> 【伏击】消耗 1 弹药，先手攻击，获得 1 轮免费行动
> 【交涉】尝试对话（基于意志属性，可能交易/收买/吓退）
> 【潜行绕过】基于敏捷，成功则完全避战（失败被发现，失去先手）
> 【设陷阱】消耗 1 陷阱材料，引诱敌人进入（基于机械属性）
> 【撤退】直接脱离，消耗体力，安全但放弃搜刮
```

### 5.3 战斗回合结构

进入战斗后，每回合结构如下：

```
回合开始
  ├── 环境效果结算（沙暴/辐射/天气）
  ├── 持续效果结算（流血/中毒/燃烧）
  │
  ├── 攻击方行动（选择 1 项）
  │   ├── 【射击】 → 消耗弹药，命中率由属性+武器+距离决定
  │   ├── 【近战】 → 不消耗弹药，仅近距离可用
  │   ├── 【投掷】 → 消耗投掷物（手雷/燃烧瓶/闪光弹）
  │   ├── 【换弹】 → 本回合不攻击，装填弹药
  │   ├── 【切枪】 → 切换到副武器，本回合可攻击但命中率-15%
  │   ├── 【使用道具】 → 使用医疗包/兴奋剂等
  │   ├── 【移动】 → 改变距离档位（近→中→远）或寻找掩体
  │   └── 【逃跑】 → 基于敏捷判定，成功则脱战
  │
  ├── 防御方响应（被动自动）
  │   ├── 闪避判定（基于敏捷）
  │   ├── 掩体减伤（如果在掩体后）
  │   ├── 护甲减伤
  │   └── 反击判定（近战被攻击时，基于体能）
  │
  └── 回合结算
      ├── 武器耐久 -1
      ├── 检查卡壳（耐久低时触发）
      └── 检查战斗结束条件
```

### 5.4 距离系统

战斗中存在三档距离，不同武器在不同距离有截然不同的表现：

| 武器类型 | 近距离 | 中距离 | 远距离 | 弹容量 | 换弹回合 | 特殊机制 |
|---------|--------|--------|--------|--------|---------|---------|
| 拳头/木棒 | 75% / 70% | - | - | ∞ | - | 沉默，不引来敌人 |
| 匕首/砍刀 | 85% / 90% | - | - | ∞ | - | 可暴击切割（持续流血） |
| 手枪 | 70% | 55% | 20% | 12 | 1 回合 | 换弹快，可双持 |
| 霰弹枪 | 95% | 40% | 10% | 6 | 2 回合 | 近距离多目标，击退效果 |
| 步枪 | 50% | 75% | 60% | 30 | 2 回合 | 可连射（2连射，弹药×2，命中率-10%） |
| 狙击枪 | 15% | 60% | 90% | 5 | 2 回合 | 首发暴击率 ×2，被近身后几乎无用 |
| 冲锋枪 | 80% | 55% | 15% | 25 | 1 回合 | 可连射（3连射），弹药消耗大 |
| 弓/弩 | 40% | 65% | 50% | 1 | 1 回合 | 沉默，箭矢可回收 50% |

**距离变化规则**:
- 【冲锋】: 距离拉近一档（远→中→近），本回合可继续行动但命中率 -15%
- 【后撤】: 距离拉远一档（近→中→远），本回合无法攻击
- 敌人 AI 会根据武器类型自动调整距离（持霰弹枪的敌人会尝试接近）

### 5.5 弹药系统

弹药是消耗品，战斗的核心资源约束：

| 弹药类型 | 适用武器 | 搜刮稀有度 | 可制造 | 制造材料 |
|---------|---------|-----------|--------|---------|
| 9mm 弹 | 手枪/冲锋枪 | 常见 | 是 | 铜片×2 + 火药×1 |
| 12号霰弹 | 霰弹枪 | 较少 | 是 | 铜片×3 + 火药×2 |
| 5.56mm 弹 | 步枪 | 稀少 | 是 | 铜片×3 + 火药×2 + 弹壳×1 |
| .308 弹 | 狙击枪 | 稀有 | 是 | 铜片×4 + 火药×3 + 弹壳×1 |
| 箭矢 | 弓/弩 | 可制造 | 是 | 木材×2 + 铁片×1 |

> **设计意图**: 近战武器不消耗弹药，给予新手和物资匮乏的玩家保底战斗力。枪械强大但弹药珍贵，鼓励精准使用。

### 5.6 掩体系统

战场中存在掩体，为战斗增加位置维度：

| 掩体类型 | 效果 | 被摧毁条件 |
|---------|------|-----------|
| 无掩体 | 无加成 | - |
| 轻掩体（灌木/木箱） | 被命中率 -15% | 受到 50 点伤害后摧毁 |
| 重掩体（残墙/车辆） | 被命中率 -30%，免疫穿透 | 受到 150 点伤害后摧毁 |
| 全掩体（房间/堡垒） | 被命中率 -50%，但无法射击（需探头） | 不可摧毁 |

- **探头射击**: 在全掩体后使用，暴露 1 回合进行射击，该回合掩体加成降为 -15%
- **盲射**: 在掩体后不暴露射击，命中率 -40%，但保持掩体加成

### 5.7 武器状态与故障

武器有耐久度，低耐久时触发故障：

| 耐久度范围 | 状态 | 效果 |
|-----------|------|------|
| 100%-61% | 完好 | 无 |
| 60%-31% | 磨损 | 命中率 -5% |
| 30%-11% | 破损 | 命中率 -15%，每回合 10% 卡壳 |
| 10%-1% | 严重损坏 | 命中率 -30%，每回合 30% 卡壳 |
| 0% | 报废 | 不可使用，需要高级修复 |

- **卡壳**: 浪费当前回合，下回合自动清除
- **维修**: 据点工坊或使用维修工具包，消耗材料恢复耐久
- **战场修复**: 使用简易维修工具（消耗 1 回合 + 材料），恢复 20% 耐久

### 5.8 护甲系统

护甲提供伤害减免，但不使用传统的"防御力"概念，而是分为**部位防护**：

| 护甲部位 | 被攻击概率 | 减伤类型 |
|---------|-----------|---------|
| 头部 | 15% | 高减伤（头盔），被命中伤害 ×1.5（爆头） |
| 躯干 | 50% | 主要减伤来源（防弹衣/护甲） |
| 四肢 | 35% | 低减伤，被命中降低移动力/射击精度 |

护甲减伤公式（复用诡修仙防御公式，换皮）:
```
实际伤害 = max(1, 基础伤害 - min(护甲值, 基础伤害 × 护甲值 / (护甲值 + 100)))
```

### 5.9 敌人类型与行为模式

> **借鉴思路**: 阿瑞斯病毒中每种怪有标志性行为（龟缩壳/牛冲撞/蛛产卵），核心乐趣是"认出敌人→选对打法"。文字游戏无法还原走位操作，但可以把这个思路转化为**回合选择题**：系统描述敌人当前状态 → 玩家从选项中选择最优应对 → 选对了事半功倍，选错了多挨打。

**核心机制——敌人"蓄势提示"**:

每种敌人在特定回合会进入"蓄势"状态，系统会给出**文字提示**。玩家根据提示选择正确行动，就能化解威胁甚至反打；忽视提示则受到额外伤害。这就是文字游戏版的"看招拆招"。

```
【战斗 回合3】
冲撞兽低下头，蹄子猛刨地面——它在蓄力冲撞！

> 【闪避】准备躲开（推荐：冲撞后它会有 1 回合硬直）
> 【射击】趁它蓄力开枪（可以打伤它但无法阻止冲撞，你会被撞）
> 【掩体】躲到掩体后面（掩体挡住冲撞，但掩体会被撞碎）
```

**敌人一览**:

| 类型 | 行为特征 | 蓄势提示 | 最优应对 | 错误应对的代价 | 掉落 |
|------|---------|---------|---------|-------------|------|
| **游荡者(丧尸)** | 无特殊，缓慢靠近 | 无 | 随便打 | 无 | 腐肉 |
| **拾荒匪** | 血量 <50% 试图逃跑 | "匪徒转身想跑！" | 放走省弹药，或追击防叫援兵 | 放走后下次该区域匪徒+1 | 杂物/食物 |
| **武装团伙** | 会使用掩体，交替射击 | "一名敌人在装弹，另一名探出掩体！" | 趁装弹时射击暴露的那个 | 攻击掩体后的等于浪费弹药 | 武器/弹药 |
| **冲撞兽** | 每 3 回合蓄力冲撞 | "它低头蹄子刨地——要冲了！" | 选【闪避】→ 它撞空 1 回合硬直可白打 | 不闪避被撞：大量伤害+倒地 1 回合 | 厚皮/肉 |
| **爆炸体** | 靠近后 2 回合倒计时自爆 | "它的身体膨胀发光，倒计时开始！" | 远程击杀 / 选【后撤】拉开距离 | 自爆范围伤害+辐射 debuff | 化学品 |
| **缩壳兽** | 受攻击缩壳(减伤90%)，3回合后露出破绽 | "它缩进硬壳——你的攻击被弹开！" | 停止攻击等 3 回合，出现"露出破绽"时集火 | 对着壳猛打 = 纯浪费弹药 | 硬壳/骨片 |
| **召唤者** | 每 3 回合嚎叫召唤 2 只游荡者 | "它仰头发出刺耳嚎叫！" | 优先集火召唤者，忽略小怪 | 先清小怪 = 无限循环消耗弹药 | 变异组织 |
| **腐蚀者** | 远程吐酸(降护甲+减速) | "它的喉囊鼓起——准备喷射酸液！" | 选【冲锋近战】（酸液近距离无法使用） | 保持远距离被持续腐蚀护甲 | 酸液/腐蚀腺体 |
| **机械哨兵** | 正面装甲极厚 | "你的子弹打在装甲板上弹开了。" | 穿甲弹 / EMP / 两人配合攻击背面 | 用普通弹药正面打 = 几乎无伤 | 电子元件 |

> **设计意图**: 每种敌人本质上是一道"选择题"，答案藏在蓄势提示里。新手第一次遇到可能选错（被冲撞兽撞飞），但下次就知道了。这种"认识敌人→学会应对"的成长感，是文字游戏能做到的"操作感"替代品。

**Boss**（区域 Boss，击败后掉落★★★以上图纸）:

| Boss | 所在区域 | 核心机制（选择题） | 推荐准备 |
|------|---------|------------------|---------|
| **屠夫** | 工业区 | 3 回合蓄力一次重击 → 选【闪避】化解；普通回合只能近战 → 保持远距离射击 | ★★武器+绷带×5 |
| **蛛母** | 医院 | 每 4 回合产卵 → 选【投掷 燃烧瓶】一次烧光卵和网；会结网减速 → 被网住选【挣脱】而非攻击 | 燃烧瓶×3+★★★武器 |
| **钢骨将军** | 军事基地 | 正面免疫物理 → 必须先用 EMP 瘫痪 2 回合再输出；周期电磁冲击 → 选【掩体】躲避 | EMP×2+2-3 人团队 |
| **辐射之心** | 辐射荒原 | 持续辐射光环 → 必须穿防辐射装备；血量 <30% 分裂 → 需要高爆发一轮带走 | 防辐射服+★★★★武器+全队集火 |

### 5.10 异源生物与元气护盾

> **参考**: 《黑暗血时代》中虫族拥有天地元气防护，普通武器无法伤害，必须用符文聚元后的武器才能破甲。同时虫族从蠕虫到赤甲虫到紫焰魔虫有严格的等级和属性分化。

#### 敌人阶段划分

**前期（Tier 1-2）以人类和普通丧尸为主**，普通枪械完全够用。**异源生物是中后期高级敌人**，出现在 Tier 3+ 区域，代表着完全不同量级的威胁：

| 阶段 | 主要敌人 | 护盾 | 武器需求 | 对应区域 |
|------|---------|------|---------|---------|
| **前期** | 游荡者、拾荒匪、武装团伙、野兽 | 无 | 普通枪械/近战 | Tier 1-2 |
| **中期** | 低阶异源体（焰尸、寒尸等） | 薄 | 兵符武器或大量普通弹硬磨 | Tier 3 边缘 |
| **中后期** | 中阶异源体（焰甲兽、寒甲兽等） | 厚 | 必须兵符武器 | Tier 3 核心 |
| **后期** | 高阶异源体（焰魔、寒魔等） | 极厚 | 兵符武器 + 属性克制 | Tier 4 / Boss |

> **设计意图**: 前期打人、打丧尸，体验纯粹的废土生存枪战。当玩家在 Tier 3 第一次遇到"子弹打不动"的异源生物时，游戏进入第二阶段——你需要符隶了。

#### 元气护盾——为什么普通枪打不动

异源生物体内的异源物质产生了一层**天地元气构成的护盾**。子弹打上去像打在果冻上，物理动能被吸收殆尽。这不是物理装甲，是能量场。

**唯一的破盾方式：用元气打元气。** 把兵符融入武器后，武器攻击时自动裹上元气——以气破气，护盾就挡不住了。

| 武器状态 | 对异源生物伤害 | 说明 |
|---------|-------------|------|
| **无符·普通武器** | ×0.1（几乎无效） | 子弹被护盾弹开，约等于挠痒 |
| **有符·兵符武器** | ×1.0（正常伤害） | 元气穿透护盾，和打普通敌人一样 |
| **有符·属性克制** | ×1.3（额外增伤） | 克制属性的元气对护盾有破坏性共振 |
| **有符·属性被克** | ×0.7（略微减伤） | 被克制的元气被护盾部分吸收 |
| **有符·同属性** | ×0.5（大幅减伤） | 同源元气被护盾直接同化 |

公式很简单：
```
对异源生物伤害 = 基础伤害 × 破盾倍率 × 属性修正
无符 = 基础伤害 × 0.1
有符 = 基础伤害 × 1.0（× 克制修正）
```

**文字表现**:

```
【战斗 回合1】
你对焰甲兽射击！ 步枪 [普通弹]
> 子弹命中——撞上一层赤红色的气浪，弹头融化弹开。
> 伤害: 4  焰甲兽毫发无伤。
> ⚠️ 普通弹无法穿透元气护盾！

【战斗 回合2】
你拔出手枪——枪身上的蚀兵符纹路微微发光。
你对焰甲兽射击！ 手枪 [蚀兵符·已融入]
> 弹头裹着一层腐蚀性元气射出——穿透护盾！酸蚀在伤口蔓延！
> 伤害: 49（38 × 1.3 属性克制）
> 焰甲兽发出嘶吼。
```

#### 五种变异属性

| 属性 | 外观特征（文字线索） | 攻击特点 | 出没区域 |
|------|-------------------|---------|---------|
| **焰** | "体表浮动着暗红色热浪" | 灼烧（3回合持续伤害） | 工业区深处 |
| **寒** | "周围空气凝结出白霜" | 减速（下回合行动-1） | 医院/地下设施 |
| **蚀** | "皮肤溃烂渗出绿色黏液" | 降甲（-15%持续3回合） | 化工厂/辐射区 |
| **雷** | "体表偶尔闪过蓝白电弧" | 麻痹（20%概率跳过1回合） | 军事基地 |
| **暗** | "身影模糊，光线在它周围扭曲" | 高闪避+首回合偷袭 | 辐射荒原/地下设施 |

#### 属性克制

```
焰 → 克制 → 寒（火融冰）
寒 → 克制 → 雷（冰冻导体）
雷 → 克制 → 蚀（电击凝固酸液）
蚀 → 克制 → 焰（酸液浇灭火焰）
暗 → 独立（被"照明"道具削弱）
```

克制属性的兵符武器攻击：伤害 ×1.3，并**压制敌人的属性特效**（灼烧/减速等不触发）。

#### 异源体等级

| 层次 | 命名规则 | 护盾 | 特征 | 掉落 |
|------|---------|------|------|------|
| **低阶** | 属性+尸（如"焰尸"） | 薄（普通弹×0.1，能磨但巨亏） | 基础属性效果，50%触发 | 异源碎片 |
| **中阶** | 属性+甲兽（如"焰甲兽"） | 厚（普通弹无意义） | 100%属性触发+蓄势技能 | 精炼异源碎片 |
| **高阶** | 属性+魔（如"焰魔"） | 极厚（普通弹无意义） | 极强+范围属性光环 | 纯净异源核心 |

> **设计意图**: 异源生物的出现是游戏叙事和玩法的分水岭。前期你觉得"有枪就无敌"，第一次被焰甲兽弹开子弹时才意识到——**废土上还有比人类更可怕的东西**。这个冲击感既是叙事高潮（异源物质到底是什么？），也是玩法升级（必须学会符隶了）。

### 5.11 战斗产出与消耗对比

**这是战斗系统最关键的平衡点**——玩家需要感觉到"打赢了确实赚了"，但同时要为战斗付出明确代价：

```
[示例：与 3 名武装匪徒战斗]

消耗:
  - 食物 ×1, 饮水 ×1（战斗行动消耗）
  - 5.56mm 弹药 ×8（步枪射击 8 次）
  - 健康值 -25（被命中 1 次）
  - 绷带 ×1（战后治疗）
  - 步枪耐久 -8%
  消耗折算: 约 120 物资价值

获得:
  - 手枪 ×1（耐久 45%）
  - 9mm 弹 ×6
  - 罐头 ×3
  - 废铁 ×5
  获得折算: 约 180 物资价值

净收益: +60 物资价值（约 50% 利润率）
```

> **设计原则**: 有准备的战斗应该有正收益（30%-80%利润率），无准备的遭遇战可能亏损。对战弱敌利润低不值得浪费弹药，对战强敌利润高但风险大。

## 6. 探索系统

### 6.1 区域制地图（非坐标制）

> **关键决策**: 废土世界不使用坐标系统，而是使用**命名区域 + 路线连接**的模式。玩家通过【前往 区域名】在区域间移动，同一区域内的所有玩家自动可见、可交互。
>
> **设计理由**: 坐标制让玩家分散在大地图上，组队需要先"走到一起"，不适合社交协作为核心的废土生存。区域制让据点成员天然聚集，到达同一区域就能一起行动。

### 6.2 世界地图结构

世界由**据点**为中心，向外辐射出多层区域。区域之间有**路线连接**，远处的区域需要途经近处区域（消耗更多补给）：

```
                    ┌──────────┐
                    │ 辐射荒原 │ Tier 4
                    └────┬─────┘
                         │
┌──────────┐       ┌─────┴────┐       ┌──────────┐
│ 军事基地 │───────│  工业区  │───────│  医  院  │ Tier 3
└──────────┘       └─────┬────┘       └────┬─────┘
                         │                  │
┌──────────┐       ┌─────┴────┐       ┌────┴─────┐
│ 商业街   │───────│废弃城镇  │───────│郊区住宅  │ Tier 2
└──────────┘       └─────┬────┘       └──────────┘
                         │
                    ┌────┴─────┐
                    │  据  点  │ 家
                    └──────────┘

                    ┌──────────┐
                    │ 地下设施 │ ???（故事解锁，从军事基地进入）
                    └──────────┘
```

### 6.3 区域详情与移动消耗

从据点出发，越远的区域消耗越多补给：

| 区域 | 层级 | 距据点路程 | 移动消耗(食物/水) | 危险等级 | 主要资源 | 解锁条件 |
|------|------|-----------|------------------|---------|---------|---------|
| **据点** | 家 | 0 | 0 | 安全 | 据点产出 | 初始 |
| **废弃城镇** | Tier 1 | 1 步 | 1/1 | ★☆☆☆☆ | 食物/水/日用品 | 初始 |
| **郊区住宅** | Tier 1 | 1 步(经城镇) | 1/1 | ★★☆☆☆ | 衣物/药品/家具材料 | 初始 |
| **商业街** | Tier 2 | 2 步 | 2/2 | ★★★☆☆ | 电子元件/奢侈品/弹药 | 感知 ≥ 10 |
| **工业区** | Tier 2 | 2 步 | 2/2 | ★★★☆☆ | 金属/机械零件/燃料 | 感知 ≥ 10 |
| **医院** | Tier 3 | 3 步 | 3/3 | ★★★★☆ | 药品/手术器械/化学品 | 据点等级 ≥ 3 |
| **军事基地** | Tier 3 | 3 步(经工业区) | 3/3 | ★★★★★ | 军用武器/护甲/高级弹药 | 据点等级 ≥ 5 |
| **辐射荒原** | Tier 4 | 4 步 | 4/4 | ★★★★★ | 能量核心/变异材料 | 防辐射装备 |
| **地下设施** | ??? | 经军事基地 | 3/3 | ??? | 科技图纸/实验数据 | 故事线解锁 |

**移动规则**:
- **【前往 区域名】**: 即刻到达，扣除对应补给。无需等待、无需走路
- **补给不足时**: 仍然可以前往，但进入"虚弱"状态（参见 3.2 节惩罚）
- **返回据点**: 免费，任何时候可以【回据点】，不消耗补给（设定：据点有信标可以循迹回家）
- **逐层推进**: 不要求严格逐层，但远处区域一次性扣除路程总补给

> **设计意图**: 去城镇搜刮只花 1 食物 1 水（低成本日常），去军事基地要 3 食物 3 水（需要提前囤补给的远征）。回家永远免费，避免"出远门回不来"的窘境。

### 6.4 区域内的地点

每个区域内有多个**具体地点**，是实际搜刮的目标：

```
【废弃城镇】包含:
  - 废弃超市    资源: 食物★★★ 日用品★★ 遭遇率: 10%
  - 加油站      资源: 燃料★★★ 工具★★ 遭遇率: 15%
  - 便利店      资源: 食物★★ 水★★★ 遭遇率: 5%
  - 民宅区      资源: 衣物★★ 杂物★★ 遭遇率: 20%
  - 药店(隐藏)  资源: 药品★★★ 遭遇率: 25% [需感知≥12发现]

【工业区】包含:
  - 废弃工厂    资源: 铁片★★★ 机械零件★★ 遭遇率: 30%
  - 仓库群      资源: 杂物★★★ 燃料★★ 遭遇率: 25%
  - 修车场      资源: 工具★★★ 零件★★ 遭遇率: 20%
  - 化工厂(隐藏) 资源: 化学品★★★ 火药★★★ 遭遇率: 40% [需感知≥18]
```

- 到达区域后，用【搜刮 地点名】搜刮具体地点（消耗 1 食物 + 1 水 / 次）
- 也可以直接【搜刮】，系统随机选择当前区域的一个地点
- **隐藏地点**需要感知达标才能发现（首次搜刮时自动判定，解锁后永久可见）

### 6.5 区域内玩家可见性

**同一区域的所有玩家互相可见**，这是区域制的核心社交优势：

```
【前往 工业区】

到达工业区。消耗: 食物-2, 饮水-2
当前同区域玩家: @老王(小队中), @小李, @废土行者
可搜刮地点: 废弃工厂, 仓库群, 修车场

> 【搜刮 废弃工厂】  消耗1食物+1水
> 【组队 @小李】     邀请小李组队
> 【侦查 废弃工厂】  先侦查再决定
> 【回据点】         免费返回
```

> **对比坐标制**: 坐标系统里你在 (23,47)，小李在 (25,51)，你甚至不知道他在附近。区域制里，到了同一个区域就自动看到彼此，组队只需一条指令。

### 6.6 搜刮机制

```
【搜刮 废弃超市】

搜刮中...（3 分钟冷却）
消耗: 食物-1, 饮水-1

[搜刮结果]
  发现: 罐头×2, 矿泉水×1, 创可贴×1
  隐藏发现（感知≥15）: 超市储物间钥匙 → 额外获得罐头×3
  遭遇: 无（本次安全）

补给剩余: 食物×5, 饮水×4
```

**搜刮规则**:
- 每个地点有独立的**资源池**，每日 06:00 刷新
- 同一地点每日搜刮次数上限 5 次（收益递减：100%→70%→40%→20%→10%）
- 感知属性影响：搜刮品质（稀有物品发现率）、隐藏地点/隐藏物品发现
- 每次搜刮有概率触发**随机事件**
- **小队搜刮**: 小队成员在同一地点一起搜刮，每人分别获得搜刮结果（独立掉落表），但遭遇事件共享（一起打或一起跑）

### 6.7 随机事件

探索时触发的事件，用故事引擎驱动：

| 事件类型 | 概率 | 示例 |
|---------|------|------|
| **安全事件** | 40% | 发现幸存者笔记/地图标注/隐藏储物间 |
| **选择事件** | 25% | 听到求救声（可能是陷阱/可能是真的幸存者） |
| **遭遇事件** | 20% | 遇到敌人（进入遭遇阶段） |
| **环境事件** | 10% | 建筑坍塌/毒气泄漏（需要快速反应） |
| **稀有事件** | 5% | 发现完好的车辆/未开封的军用箱/NPC 商人 |

### 6.8 侦查系统

玩家可以先侦查再决定是否搜刮（不消耗补给，但有冷却）：

```
【侦查 废弃工厂】

侦查结果（基于感知 18）:
  - 区域内敌人: 约 2-3 个拾荒匪
  - 资源丰富度: ★★★☆☆（今日已被搜刮过 1 次）
  - 环境威胁: 无特殊
  建议: 单人可行，匪徒装备简陋
```

## 7. 据点系统

### 7.1 设计定位

**据点是玩家群体的"家"，是所有系统的汇聚点。** 据点提供安全存储、生产制造、防御工事、休息恢复。从空地开始，逐步建设成能抵御尸潮的堡垒。

### 7.2 据点创建

- 任何玩家均可创建据点（消耗：木材×100 + 铁片×50 + 工具包×1）
- 据点创建时选择**相邻区域**，决定了附近可搜刮的资源特点（如靠近工业区的据点更容易获取金属材料）
- 每个 QQ 群最多 3 个据点（鼓励竞争和联盟）
- 创建者成为据点首领

### 7.3 建筑系统

据点通过建造建筑获得功能。建筑需要**材料 + 人力（在线成员数）+ 时间**：

| 建筑 | 等级上限 | 功能 | 建造材料(1级) | 升级方向 |
|------|---------|------|-------------|---------|
| **围墙** | 5 | 据点基础防御力 | 木材×200 | 木墙→铁墙→混凝土墙→电网围墙→堡垒墙 |
| **了望塔** | 3 | 提前预警尸潮/入侵，侦查加成 | 木材×100+铁片×50 | 提升预警轮数 |
| **水井** | 3 | 休整时自动补充饮水，据点产出饮水 | 铁片×80+管道×5 | 提升产水量+水质 |
| **农场** | 3 | 休整时自动补充食物，据点产出食物 | 种子×10+木材×50 | 提升产出种类+数量（解锁烹饪原料） |
| **武器工作台** | 5 | 制造/修理武器 | 铁片×80+工具×2 | 每级解锁更高星级武器配方 |
| **防具缝纫台** | 5 | 制造/修理护甲和衣物 | 木材×60+布料×20 | 每级解锁更高星级防具配方 |
| **化学实验台** | 5 | 制造药品、弹药、化学品 | 铁片×60+玻璃瓶×10 | 解锁高级药品和特殊弹头 |
| **锻造熔炉** | 5 | 冶炼矿石、加工金属、制造陷阱 | 石材×100+铁片×50 | 解锁加工链 |
| **厨房** | 3 | 烹饪食物获得战斗/探索buff | 石材×50+铁片×30 | 解锁高级食谱（更强buff） |
| **医疗站** | 3 | 休整时自动恢复健康值 | 药品×20+器械×5 | 提升恢复速率 |
| **仓库** | 5 | 据点公共存储空间 | 木材×150 | 增加存储格数 |
| **发电机** | 3 | 为其他建筑提供电力加成 | 电子元件×30+燃料×20 | 解锁电力建筑（电网围墙/广播塔等） |
| **广播塔** | 1 | 吸引 NPC 幸存者和同伴前来投奔 | 电子元件×50+电力 | 唯一建筑 |
| **训练场** | 3 | 提供安全的属性训练环境 | 木材×100+铁片×80 | 提升训练效率 |
| **贸易站** | 3 | 解锁据点间贸易，吸引商队 | 木材×200+奢侈品×10 | 降低交易税+增加商队频率 |

## 8. 尸潮系统

### 8.1 设计定位

**尸潮是废土世界的"最终检验"。** 所有平时的搜刮、建设、储备，都是为了在尸潮来袭时守住据点。这是据点成员的集体挑战，也是游戏最紧张刺激的时刻。

### 8.2 尸潮触发

- **固定尸潮**: 每周日 20:00 来袭（给玩家明确的准备时间）
- **随机尸潮**: 低概率在其他时间触发小规模尸潮（了望塔可提前预警）
- **剧情尸潮**: 故事线推进到特定节点触发（规模更大，有剧情奖励）

### 8.3 波次机制

每次尸潮分为 **3-5 波**，难度递增：

```
【尸潮警报——第 3 周】

预警: 了望塔发现大规模尸群正在接近！
预计抵达: 30 分钟后
预估规模: ★★★☆☆ (中等)

> 【备战】检查据点防御状态
> 【部署陷阱】在据点外围设置陷阱（消耗材料）
> 【分配岗位】指定成员负责不同防线
> 【疏散】放弃据点逃跑（据点将被破坏）
```

**波次设计**:

| 波次 | 敌人组成 | 数量系数 | 特殊机制 |
|------|---------|---------|---------|
| 第 1 波 | 普通游荡者 | ×1 | 试探性进攻，消耗外围陷阱 |
| 第 2 波 | 游荡者 + 奔跑者 | ×1.5 | 奔跑者速度快，会冲过陷阱 |
| 第 3 波 | 混合 + 重型变异体 | ×2 | 重型单位血厚，能破坏围墙 |
| 第 4 波（高等级） | 精英变异体 + 辐射体 | ×2.5 | 辐射体爆炸造成 AOE |
| 最终波（Boss） | BOSS 级变异体 | 1 只 | 超高血量，需要全据点集火 |

**数量系数基于据点等级和周数调整**:
```
实际敌人数 = 基础数量 × 波次系数 × (1 + 周数 × 0.05) × (1 + 据点等级 × 0.2)
```

### 8.4 据点防御战流程

尸潮到来后，进入特殊的**防御战模式**：

1. **陷阱阶段**: 据点外围陷阱自动触发，削减第一波敌人
2. **围墙阶段**: 敌人攻击围墙，围墙有独立血量，成员在墙后射击
3. **突破阶段**: 围墙被破则进入近战混战（如果围墙没倒，则敌人消耗完毕此波结束）
4. **波间休整**: 30 秒间隔，可修理围墙/补给弹药/治疗
5. **结算**: 所有波次结束后统计战果

**成员参与方式（每波选择行动）**:
```
【尸潮 第2波——38只奔跑者正在冲锋！】
围墙血量: 680/1000  弹药储备: 步枪弹 45 发, 霰弹 12 发

你的位置: 围墙射击位  武器: 步枪 [28/30]

> 【射击】消耗弹药攻击冲锋的敌人
> 【投掷】使用手雷/燃烧瓶（AOE 伤害）
> 【修墙】本回合不攻击，修复围墙 50 点
> 【支援】使用医疗包治疗受伤的队友
```

### 8.5 尸潮结果

| 结果 | 条件 | 后果 |
|------|------|------|
| **完美防御** | 围墙未被突破 | 全额奖励 + 额外稀有材料 + 据点声望 |
| **惨胜** | 围墙被破但击退敌人 | 基础奖励，围墙需修复 |
| **据点沦陷** | 成员全灭或撤退 | 据点建筑随机损坏 1-2 级，仓库物资丢失 30% |

**奖励内容**: 变异材料（用于高级制造）、科技碎片（用于解锁研究）、据点声望（吸引更多 NPC 居民）

## 9. 制造与改装系统

> **参考**: 阿瑞斯病毒的 4 工作台 + 图纸制。制造不是"有材料就能造"，而是"先找到图纸，再建好对应工作台，最后用材料制造"。图纸本身成为一种稀缺资源，驱动探索和 NPC 交易。

### 9.1 四大工作台

据点的**工坊**建筑拆分为 4 个专业工作台，各自独立建造和升级：

| 工作台 | 功能 | 建造材料 | 等级上限 | 升级解锁 |
|--------|------|---------|---------|---------|
| **武器工作台** | 制造/修理近战武器和枪械 | 铁片×80+工具×2 | 5 | 每级解锁更高星级武器配方 |
| **防具缝纫台** | 制造/修理护甲和衣物 | 木材×60+布料×20 | 5 | 每级解锁更高星级防具配方 |
| **化学实验台** | 制造药品、弹药、化学品 | 铁片×60+玻璃瓶×10 | 5 | 解锁高级药品和特殊弹头（毒弹/燃烧弹） |
| **锻造熔炉** | 冶炼矿石、加工金属、制造陷阱和建筑材料 | 石材×100+铁片×50 | 5 | 解锁高级合金/加工链 |

**建造优先级建议**（对标阿瑞斯病毒的前期开荒）:
1. 先造武器工作台（有武器才能安全搜刮）
2. 再造化学实验台（有药品才能续航战斗）
3. 然后防具缝纫台（有护甲才能扛高危区）
4. 最后锻造熔炉（提供加工链的深度升级）

### 9.2 图纸系统

制造任何非基础物品都需要先获得**图纸**。图纸是一次性学习物品，学会后永久解锁该配方：

**图纸获取途径**:

| 途径 | 获得图纸类型 | 说明 |
|------|------------|------|
| **NPC 商人购买** | 基础~中级武器/防具图纸 | 用弹药/物资从流浪商人处购买 |
| **搜刮发现** | 随机图纸 | 高危区域搜刮时低概率发现 |
| **Boss 掉落** | 高级/稀有图纸 | 击败区域 Boss 必定掉落特定图纸 |
| **故事任务奖励** | 特殊图纸 | 完成特定故事线解锁 |
| **据点研究** | 加工链/建筑图纸 | 据点等级达标后自动解锁 |

**图纸星级**（对标阿瑞斯病毒的装备星级）:

| 星级 | 品质 | 获取难度 | 对应区域 |
|------|------|---------|---------|
| ★ | 简陋 | 初始/NPC 购买 | 废弃城镇/郊区 |
| ★★ | 普通 | NPC 购买/搜刮 | 商业街/工业区 |
| ★★★ | 精良 | 搜刮/Boss 掉落 | 医院/军事基地 |
| ★★★★ | 大师 | Boss 掉落/故事奖励 | 辐射荒原/地下设施 |
| ★★★★★ | 传说 | 特殊条件 | 赛季目标/限定 |

> **设计意图**: 星级同时是装备强度和内容门槛。3 星装备才能扛住医院的辐射体，4 星装备才能去辐射荒原。这给了搜刮图纸一个明确的驱动力——"我得找到 3 星步枪图纸才能打更难的区域"。

### 9.3 加工链（多级制造）

原材料不能直接变成最终产品，需要经过**加工链**：

```
[武器制造加工链示例]

木材 ──→ 木棍（随身制造）──→ 木弓（武器工作台★）
                                  ↓
铁矿 ──→ 铁锭（锻造熔炉）──→ 铁枪头 ──→ 铁矛（武器工作台★★）
                  ↓
              钢材（熔炉Lv3）──→ 枪管 ──→ 手枪（武器工作台★★★）
                                    ↓
                              精密枪管 ──→ 步枪（武器工作台★★★★）

[弹药制造加工链]

铜矿 ──→ 铜片（锻造熔炉）─┐
硫磺 ──→ 火药（化学实验台）─┤──→ 9mm弹（化学实验台）
                            │
                            └──→ 毒弹头（化学实验台Lv3 + 毒囊）──→ 9mm毒弹

[药品制造加工链]

草药 + 酒精 ──→ 药剂（化学实验台★）
草药 + 化学品 ──→ 抗辐射药（化学实验台★★★）
```

> **设计意图**: 加工链让材料搜集有了方向感（"我需要铜矿和硫磺来造子弹"），也让锻造熔炉有了不可替代的价值。这比"有铁片就直接造枪"要有成就感。

### 9.4 随身制造 vs 工作台制造

### 9.7 符隶系统

> **参考**: 《黑暗血时代》的符文体系——火兵符融入武器发射火元气攻击，寒兵符让弓箭射出寒冰箭，六甲符封印在身体上增强防御，聚元符汲取天地元气存储，摄元符从怪物尸体上摄取元气。核心是**把符融入武器/身体，赋予元气能力**。
>
> **废土适配**: 异源物质渗透了废土世界。部分幸存者发现，用异源生物遗骸中提取的材料可以篆刻"符"，融入武器和装备——让武器攻击带上元气，穿透异源生物的护盾。符隶系统是对抗异源生物的**唯一途径**。

#### 9.7.1 兵符——融入武器，破盾杀敌

兵符是符隶系统的核心。把兵符**融入一件武器**后，该武器的所有攻击自动裹上对应属性的元气。手枪融了火兵符，每颗子弹都是火元气子弹；长剑融了寒兵符，每一刀都带寒冰之力。

| 兵符 | 属性 | 融入效果 | 示例 | 材料 |
|------|------|---------|------|------|
| **火兵符** | 焰 | 武器攻击附带火元气，破盾+灼烧（2回合×5伤害） | 手枪→射出火弹 | 焰属性异源碎片×5 |
| **寒兵符** | 寒 | 武器攻击附带寒元气，破盾+减速（1回合） | 弓箭→射出冰箭 | 寒属性异源碎片×5 |
| **蚀兵符** | 蚀 | 武器攻击附带蚀元气，破盾+降甲10%持续3回合 | 步枪→射出酸弹 | 蚀属性异源碎片×5 |
| **雷兵符** | 雷 | 武器攻击附带雷元气，破盾+15%麻痹 | 霰弹枪→散射电弧 | 雷属性异源碎片×5 |
| **暗兵符** | 暗 | 武器攻击附带暗元气，破盾+吸取3%生命 | 狙击枪→暗能射线 | 暗属性异源碎片×8 |
| **神兵符** | 无属性（纯元气） | 武器攻击附带纯净元气，破盾但无额外效果 | 长剑→元气斩 | 任意异源碎片×3 |

**融入规则**:
- 一件武器只能融入 **1 个兵符**（与改装配件互不冲突）
- 融入后**永久生效**，不可拆除，换新兵符会覆盖旧的
- 融入后武器名变化：步枪 → 焰·步枪，长剑 → 寒·长剑
- **神兵符**是入门级兵符——纯粹破盾不附带属性效果，材料要求低，不挑属性碎片

> **核心体验**: 把火兵符融入手枪的那一刻，手枪枪身浮现暗红色纹路。再射击焰甲兽——子弹裹着火元气穿透护盾，伤害从 4 跳到 38。**一把符隶武器顶得上十箱普通弹药。**

#### 9.7.2 高阶兵符

中阶异源体和Boss掉落精炼碎片/纯净核心，可以篆刻更强的兵符：

| 兵符 | 效果 | 材料 | 获取时机 |
|------|------|------|---------|
| **烈焰兵符** | 火兵符升级：灼烧 3回合×8伤害，10%引燃 | 焰属性精炼碎片×3 + 纯净核心×1 | 中后期 |
| **冰封兵符** | 寒兵符升级：20%概率冻结（跳过1回合） | 寒属性精炼碎片×3 + 纯净核心×1 | 中后期 |
| **溶蚀兵符** | 蚀兵符升级：降甲20% + 每回合额外酸蚀伤害 | 蚀属性精炼碎片×3 + 纯净核心×1 | 中后期 |
| **裂雷兵符** | 雷兵符升级：30%麻痹 + 链式弹射（波及相邻敌人） | 雷属性精炼碎片×3 + 纯净核心×1 | 中后期 |
| **噬暗兵符** | 暗兵符升级：吸取8%生命 + 击杀时恢复元气 | 暗属性纯净核心×3 | 后期 |

#### 9.7.3 元气与元气管理符

兵符武器攻击时会**消耗元气**。元气是角色身上的隐形资源——没有元气，兵符就休眠，武器退回普通状态。

**元气基础**:
- 角色默认元气上限：**50**（随意志属性提升：50 + 意志×2）
- 兵符武器每次攻击消耗：**2 点元气**
- 高阶兵符每次攻击消耗：**3 点元气**
- 元气归零后兵符进入休眠，武器退回普通状态（对异源生物又打不动了）

**元气回复——两种管理符**:

| 管理符 | 效果 | 使用方式 | 材料 |
|--------|------|---------|------|
| **聚元符** | 自动汲取天地元气，每次行动（搜刮/战斗/探索）恢复 **5 点元气** | 融入身体（永久生效，占1个护符槽） | 任意精炼碎片×5 |
| **摄元符** | 从异源生物尸体上摄取元气，每次击杀异源生物恢复 **10 点元气** | 融入身体（永久生效，占1个护符槽） | 任意精炼碎片×5 |

**无符时的元气回复**:
- 在据点休整：元气回满
- 使用"元气结晶"（消耗品，搜刮/Boss掉落）：恢复 20 点元气

> **设计意图**: 元气系统让兵符武器不是"永久无脑强"——你需要管理元气，决定什么时候该用兵符武器（对异源生物），什么时候该换回普通武器省元气（对人/丧尸）。聚元符和摄元符是"被动挂机回复"和"战斗中击杀回复"两种风格，鼓励不同的游玩方式。

#### 9.7.4 防护符——融入防具

| 防护符 | 效果 | 融入位置 | 材料 |
|--------|------|---------|------|
| **焰御符** | 受到焰属性攻击减伤40% | 防具 | 焰属性碎片×5 |
| **寒御符** | 受到寒属性攻击减伤40%，免疫冻结 | 防具 | 寒属性碎片×5 |
| **蚀御符** | 受到蚀属性攻击减伤40%，降甲减半 | 防具 | 蚀属性碎片×5 |
| **雷御符** | 受到雷属性攻击减伤40%，免疫麻痹 | 防具 | 雷属性碎片×5 |
| **六甲符** | 所有属性攻击减伤20% + 物理防御+10% | 防具 | 任意纯净核心×1 |

每件防具最多融入 **1 个防护符**。

#### 9.7.5 符隶获取与篆刻

**符隶制作**需要在**锻造熔炉 Lv3+** 进行。不需要单独的"符隶工作台"——篆刻本质上是在锻造熔炉中用异源材料塑形。

**"鸡生蛋"问题解决**（打异源生物需要碎片，碎片从异源生物身上掉）:

| 途径 | 说明 |
|------|------|
| **NPC商人出售低阶兵符** | 流浪商人偶尔出售神兵符（最基础的破盾符），价格不菲但够用 |
| **故事引导** | 中期主线任务"信号追踪"中，NPC赠送一个神兵符+教学 |
| **低阶异源体普通弹能磨** | ×0.1不是×0，多花弹药一样能杀低阶焰尸，掉碎片 |
| **据点成员共享** | 据点仓库可以存放碎片和兵符，先富带后富 |

#### 9.7.6 符隶系统总览

```
[玩家进度路径]

前期（Tier 1-2）
  打人/丧尸 → 普通枪械就够 → 不需要符隶

中期转折
  第一次遇到异源生物 → "打不动！" → 获得/购买神兵符
  → 神兵符融入武器 → 破盾！ → 开始收集异源碎片

中期（Tier 3）
  攒碎片 → 篆刻属性兵符（火/寒/蚀/雷）→ 针对不同属性敌人切换武器
  攒碎片 → 篆刻聚元符/摄元符 → 元气管理不再焦虑
  攒碎片 → 篆刻防护符 → 扛住异源生物的属性攻击

后期（Tier 4+）
  精炼碎片+纯净核心 → 篆刻高阶兵符 → 更强属性效果
  → 打更强的异源Boss → 掉更好的材料 → 循环
```

## 10. 经济与贸易系统

### 10.1 货币设计

**不设统一货币。** 废土没有银行和造币厂，经济基于**以物易物 + 通用硬通货**：

| 交易媒介 | 定位 | 说明 |
|---------|------|------|
| **以物易物** | 基础交易 | 直接用物品换物品（NPC 商人接受） |
| **弹药** | 通用硬通货 | 9mm 子弹作为最通用计价单位（1发 ≈ 1单位价值） |
| **净水** | 辅助硬通货 | 大宗交易用净水计价 |
| **科技碎片** | 高端货币 | 用于购买稀有图纸/高级材料，仅特殊 NPC 接受 |

> **设计意图**: 用弹药当货币是废土题材的经典设定，它天然有"用掉就没了"的消耗属性，自动控制通胀。你花了 20 发子弹买食物，就少了 20 发子弹用来战斗。

### 10.2 商队系统（复用跑商框架）

定期有 NPC 商队在据点之间流动：

- **商队到达**: 每周六随机抵达某个据点（广播塔/贸易站提升到访概率）
- **交易窗口**: 商队停留 24 小时
- **商品内容**: 每次随机生成（稀有弹药、药品、图纸、改装配件等）
- **动态定价**: 复用诡修仙的供需因子系统，某种物品被大量购买后涨价

### 10.3 据点间贸易

拥有贸易站的据点之间可以进行交易：

- **商队派遣**: 据点可派成员运货到另一个据点交易（途中有被劫风险）
- **贸易协定**: 两个据点可签订协定，降低交易税/提升安全性
- **资源差异**: 不同位置的据点附近资源不同，形成自然贸易需求

### 10.4 玩家间交易

```
【交易 @玩家 物品名 数量 换 物品名 数量】

示例:
  【交易 @老王 5.56mm弹×20 换 罐头×10】
  → 老王将收到交易请求，确认后完成交换
```

可复用诡修仙的市场订单系统，支持挂单交易。

## 11. 社交系统

### 11.1 小队系统

玩家可以组成 2-4 人小队一起行动：

- **小队探索**: 搜刮效率提升（人多搜得快），但每人分得的物资减少
- **小队战斗**: 遭遇战时所有成员参与，可以协同战术
- **小队分工**: 队长分配搜刮任务（你搜一楼/我搜二楼）
- **资源分配**: 战利品由队长分配或自动均分

### 11.2 据点社交

- **据点公告**: 首领发布据点任务/物资需求
- **据点日志**: 自动记录据点内发生的事件（谁搜刮了什么/谁升级了建筑）
- **轮班制度**: 首领可设置巡逻/值守排班

### 11.3 声望系统（替代好感度）

玩家在废土世界中积累声望：

| 声望等级 | 范围 | 效果 |
|---------|------|------|
| 恶名昭彰 | -100~-50 | NPC 商人拒绝交易，部分据点禁止进入 |
| 可疑之人 | -49~-1 | NPC 交易涨价 20% |
| 无名之辈 | 0~49 | 基础状态 |
| 值得信赖 | 50~149 | NPC 交易降价 10%，可接特殊任务 |
| 废土英雄 | 150~299 | NPC 降价 20%，吸引高级 NPC 幸存者投奔 |
| 传奇人物 | 300+ | 解锁传说级任务/商人/事件 |

**声望获取**: 帮助幸存者 NPC、击退尸潮、完成贸易、完成故事任务
**声望损失**: 攻击友好 NPC、偷窃据点仓库、背叛队友

## 12. AI 对话与 NPC 系统

### 12.1 NPC 类型

可直接复用诡修仙的 AI 对话系统，更换人设：

| NPC 类型 | 角色定位 | 交互方式 |
|---------|---------|---------|
| **流浪商人** | 交易+情报 | 对话砍价/套取区域情报 |
| **幸存者** | 求助/加入据点 | 帮助后可能成为据点 NPC 居民 |
| **匪帮头目** | 威胁/谈判 | 可以交涉避免战斗/缴纳保护费 |
| **神秘旅人** | 剧情推进 | 提供任务线索/世界观碎片 |
| **据点 NPC 居民** | 日常互动 | 分配工作/闲聊/提供任务 |
| **电台主播** | 全局信息 | 广播世界事件/据点排名/尸潮预警 |

### 12.2 AI 对话系统复用

直接移植以下组件，更换 prompt 和人设：

- `ai_dialogue_service.py` → 对话引擎核心
- `npc_personality.py` → 更换为废土人设模板
- `npc_favorability_service.py` → 复用好感度机制
- `dialogue_summarization_service.py` → 长期记忆机制

**人设模板示例**:
```yaml

  personality: 精明、世故、表面圆滑实则重义气
  speech_style: 带点油腔滑调，爱用末日前的老话
  background: 末日前是二手车商，末日后靠贩卖物资为生
  knowledge: 熟悉各据点情况、物价行情、危险区域
  trade_bias: 弹药出价偏低、药品出价偏高
  secrets: 知道军事基地的隐秘入口位置（好感度达到"亲密"后透露）
```

### 12.3 NPC 居民系统

通过广播塔吸引或在探索中救助的 NPC 可成为据点居民：

- **分配工作**: 农场劳作/仓库管理/巡逻守卫/工坊制造
- **NPC 技能**: 每个 NPC 有特长（如"前军医"→ 医疗站效率 +20%）
- **NPC 需求**: 需要食物和水（消耗据点资源），不满意会离开
- **NPC 事件**: 偶尔产生剧情（NPC 之间的矛盾/NPC 的个人任务）

### 12.4 NPC 同伴系统

> **设计思路**: 阿瑞斯病毒中可带同伴出门协助战斗/采集。文字游戏中同伴不需要"AI走位"，而是作为**出门时的被动增益 + 偶发互动**存在。同伴的核心体验是"不再独自上路"，以及"培养一个可靠的伙伴"。

**同伴定位**: 同伴是**据点NPC居民中的特殊个体**，经过玩家培养后可以带出据点协助探索。同伴不是玩家的附属品，而是有性格、有台词、会成长的角色。

**同伴获取**:

| 途径 | 说明 |
|------|------|
| **据点NPC好感度达到"信赖"** | 好感度≥60的据点NPC居民可被"邀请同行" |
| **野外救助** | 探索时随机事件救下的幸存者，有概率愿意跟随 |
| **广播塔招募** | 广播塔Lv2+，定期有"愿意当搭档的幸存者"前来 |

**同伴类型与效果**:

每个同伴有一个**专长方向**（由其背景决定），带出门时提供被动加成：

| 类型 | 被动效果 | 战斗表现 | 代表背景 |
|------|---------|---------|---------|
| **战斗型** | 战斗中自动补充 1 次额外攻击（伤害=同伴攻击力的50%） | 每回合有概率帮你挡一次伤害（20%） | 前警察/退伍军人/猎人 |
| **搜刮型** | 每次搜刮额外发现 1 个物品 | 战斗中不参战，但不会受伤 | 前快递员/拾荒老手/小偷 |
| **医疗型** | 战斗结束后自动恢复 15 点健康 | 战斗中每 3 回合为你恢复 10 点健康 | 前护士/兽医/药剂师 |
| **机械型** | 制造时品质提升一档的概率 +15% | 战斗中可花 1 回合让同伴修理武器（+10%耐久） | 前工程师/修理工/技工 |

**同伴限制**:
- 最多带 **1 名同伴**出门（后期专长"领袖气质"可解锁第 2 名）
- 同伴出门也消耗补给：每次行动额外消耗 **食物×1**（需要喂同伴）
- 同伴有独立的**健康值**（默认50，可通过培养提升），归零则"受伤"，需要回据点休养 3 次休整周期
- 同伴不会"死亡"，只会受伤退回据点

**同伴互动（文字游戏的特色部分）**:

同伴在探索过程中会**随机发表评论**，基于他们的性格和当前场景：

```
【前往 工业区】
到达工业区。消耗: 食物-2, 饮水-2, 同伴食物-2

同伴[老陈]: "这地方我以前来修过机床，没想到再来是翻垃圾。"

【搜刮 废弃工厂】
搜刮中...

同伴[老陈]帮你翻找，额外发现: 扳手×1
老陈: "嘿，这把扳手还能用，好东西别嫌弃。"
```

同伴的台词由**AI对话系统**生成（复用`ai_dialogue_service.py`），但以简短随机触发的形式出现，不需要玩家主动对话。触发概率约30%/次行动。

**同伴培养**:

同伴跟随出门次数越多，能力越强：

| 同行次数 | 同伴等级 | 效果 |
|---------|---------|------|
| 0-10 | 新手搭档 | 基础效果 |
| 11-30 | 默契搭档 | 被动效果 +50% |
| 31-60 | 老搭档 | 被动效果 +100%，解锁专属技能 |
| 61+ | 生死之交 | 被动效果 +100%，专属技能 +50%，遇险时有30%概率触发"舍命相护"（为你挡一次致命伤害，自己受伤退场） |

**专属技能**（老搭档解锁，每次出门可使用 1 次）:

| 同伴类型 | 专属技能 | 效果 |
|---------|---------|------|
| 战斗型 | 【火力压制】 | 下 2 回合敌人命中率 -30% |
| 搜刮型 | 【老手直觉】 | 本次搜刮保证获得该地点最高品质物品 |
| 医疗型 | 【急救术】 | 立刻恢复 40 点健康，清除所有负面状态 |
| 机械型 | 【现场改造】 | 临时给武器附加 1 个改装效果（持续本次外出） |

> **设计意图**: 同伴系统给"独自探索"增加了一个伙伴维度——你带着老陈去工业区，他会评论环境、帮你翻东西、关键时刻挡子弹。这种"陪伴感"是文字游戏能做好的事情，不需要3D模型也不需要AI走位，只需要几句恰当的台词和可靠的数值辅助。同伴的补给消耗（多吃一份食物）也平衡了收益，防止同伴成为"白嫖加成"。

## 13. 世界观与叙事框架

### 13.1 背景设定

**"灰烬纪元"** — 距离"大崩溃"已过去 3 年。

没人确切知道大崩溃的起因。有人说是生化武器泄漏，有人说是陨石带来的未知病原体，还有人说是某个实验室的实验失控。唯一确定的是：

- 全球 70% 人口在第一年内死亡或变异
- 政府和军队在第二年彻底瓦解
- 幸存者开始自发组织，废墟中冒出据点和商队
- 变异仍在继续——尸潮规模越来越大，变异体越来越强

**核心设定原则**:
- 不给出大崩溃的确切原因（保持神秘感，为故事线留空间）
- **异源物质**: 大崩溃后出现的神秘物质，渗透了生物和矿物。它是变异体拥有属性的根源，也是符隶系统的物质基础。没有人知道它从哪来——陨石？地心？还是某种维度裂隙？（主线第四章"地下设施"揭示部分真相）
- 文明遗物随处可见（超市、医院、军事基地）但都已荒废
- 没有"治愈病毒拯救世界"的宏大叙事，主题是**活下来，然后重建**
- 每个区域都有末日前后的小故事（通过搜刮到的笔记/录音/照片讲述）
- **属性变异体不是单纯的怪物**——它们有自己的生态链，焰系和寒系变异体会互相攻击，暗属性变异体像幽灵一样游走于各区域边缘。玩家可以利用这一点（引诱不同属性的变异体互斗）

### 13.2 故事线框架

主线通过探索逐步揭示，使用诡修仙的故事引擎实现：

```
主线（依次解锁）:
  第一章: 苏醒 — 玩家在避难所醒来，学习基本生存
  第二章: 信号 — 收到神秘电台信号，寻找信号源
  第三章: 真相碎片 — 在各个设施中发现大崩溃的线索
  第四章: 地下设施 — 进入关键地下实验室
  第五章: 选择 — 发现可能的"解药"或"进化"，做出选择

支线（并行）:
  - 各据点 NPC 的个人故事
  - 匪帮势力的兴衰
  - 神秘组织的踪迹
  - 变异体的起源调查
```

## 15. 数值框架

### 15.1 时间经济

| 行为 | 冷却时间 | 说明 |
|------|---------|------|
| 搜刮 | 3 分钟 | 核心循环频率 |
| 制造 | 即时~5 分钟 | 按复杂度不同 |
| 休整 | 8 小时 | 离线恢复（对标诡修仙闭关） |
| 小队探索 | 5 分钟 | 比单人搜刮略慢但收益高 |
| 尸潮（每波） | 实时参与 | 每波约 2-3 分钟决策时间 |

### 15.2 资源产出与消耗平衡

**行动消耗制下的每日平衡**（活跃玩家，约 10-15 次行动/天）:

| 资源 | 日搜刮产出(约) | 日行动消耗(约) | 盈余 |
|------|--------------|--------------|------|
| 食物 | 8-12 份 | 5-8 份（每次行动消耗 1） | +3~4（可积累存据点） |
| 饮用水 | 6-10 份 | 5-8 份（每次行动消耗 1） | +1~2（略紧，鼓励建水井） |
| 弹药(9mm等价) | 15-25 发 | 10-20 发（1-2 场战斗） | 微盈余 |
| 医疗品 | 2-4 个 | 1-3 个 | 微盈余 |
| 制造材料 | 10-20 个 | 按需 | 积累用于建设/制造 |

> **设计意图**: 食物和水的产出略大于消耗，活跃玩家每天能存下几份补给到据点。但如果不搜刮就出去探险，带出去的补给会很快用完。核心循环是"先搜刮低危区攒补给 → 再拿补给去高危区探险"。

**佛系玩家的体验**（每天 3-5 次行动）:
- 消耗食物 3-5 份、水 3-5 份
- 搜刮产出足以自给自足
- 缓慢积累物资，依然能参与周日尸潮（靠据点仓库的公共物资）

### 15.3 战斗数值基准

**基准单位: 1个刚创建的角色 vs 1个普通游荡者**

| 数值 | 玩家(初始) | 普通游荡者 |
|------|-----------|-----------|
| 生命值 | 100 | 60 |
| 攻击力(近战) | 12 | 8 |
| 攻击力(手枪) | 18 | - |
| 护甲 | 0 | 0 |
| 命中率(中距离手枪) | 55% | - |
| 闪避率 | 8% | 5% |

预期：新手玩家用手枪对付 1 个普通游荡者，消耗约 3-4 发弹药，受到 0-1 次攻击。
感觉：有优势但不轻松，需要尊重每一个敌人。

### 15.4 成长曲线

属性成长采用对数曲线，前期快后期慢：

```
经验需求 = 基础值 × (当前等级 ^ 1.5)

属性 1→10:  约 1 周活跃游玩
属性 10→20: 约 3 周
属性 20→30: 约 2 个月
属性 30→40: 约 4 个月
属性 40→50: 约 8 个月（对标诡修仙高级境界的长期目标）
```

## 16. 月卡与付费设计

### 16.1 设计原则

- **不卖数值，卖便利和外观**
- 月卡玩家不会比免费玩家"更强"，但会"更舒适"
- 所有付费内容都可以通过游戏内途径获取（只是更慢）

### 16.2 月卡方案

| 功能 | 免费玩家 | 基础月卡 | 高级月卡 |
|------|---------|---------|---------|
| 搜刮冷却 | 3 分钟 | 2 分钟 | 1.5 分钟 |
| 背包容量 | 30 格 | 40 格 | 50 格 |
| 离线休整恢复 | 基础速率 | +20% | +50% |
| 据点离线消耗减免 | 无 | 食物消耗 -20% | 食物消耗 -40% |
| 每日搜刮上限 | 每地点 5 次 | 每地点 7 次 | 每地点 10 次 |
| 专属外观 | 无 | 基础称号框 | 高级称号框+营地装饰 |
| 自动整理背包 | 无 | 无 | 有 |
| 死亡物资保护 | 掉落 30% | 掉落 20% | 掉落 10% |

### 16.3 付费道具（少量）

- **营地装饰**: 纯外观，不影响数值
- **额外角色栏**: 可以创建第二个角色
- **改名卡**: 更改角色/据点名称

### 17.3 数据模型概要

**核心表设计**:

```
survivor (玩家/幸存者)
  - id, qq_id, name
  - hp, max_hp                    # 健康值（唯一核心状态条）
  - sanity                        # 精神值（增益/减益系统）
  - food_count, water_count       # 随身携带的食物/水数量（行动消耗制）
  - strength, shooting, agility   # 体能/射术/敏捷
  - perception, mechanic, will    # 感知/机械/意志
  - str_exp, shoot_exp, ...       # 各属性经验值
  - reputation                    # 声望
  - yuan_qi                       # 当前元气值（默认50，上限50+意志×2）
  - yuan_qi_max                   # 元气上限（受聚元符/摄元符影响）
  - settlement_id                 # 所属据点
  - current_zone                  # 当前所在区域（枚举：据点/废弃城镇/工业区/...）
  - is_resting                   # 是否在休整
  - death_count                  # 死亡次数
  - death_zone                   # 最近死亡区域（遗物包位置）
  - death_pack_expires_at        # 遗物包过期时间
  - consecutive_deaths           # 连续死亡次数（天使护佑判定）
  - created_at, last_active_at

settlement (据点)
  - id, name, leader_id
  - level
  - wall_hp, max_wall_hp
  - population, max_population
  - adjacent_zones (JSON)         # 据点连接的区域列表（决定地理位置）
  - created_at

settlement_building (据点建筑)
  - id, settlement_id
  - building_type (ENUM)
  - level
  - condition                     # 建筑状态/耐久

settlement_member (据点成员)
  - id, settlement_id, survivor_id
  - role (ENUM: leader/deputy/veteran/newcomer)
  - joined_at

inventory (背包物品)
  - id, survivor_id
  - item_id, quantity
  - durability                    # 耐久度（武器/护甲）
  - quality (ENUM)                # 品质
  - modifications (JSON)          # 改装配件数据
  - fused_talisman_id              # 融入的兵符/防护符ID（NULL=无符隶）
  - element_type                  # 融入的属性类型（焰/寒/蚀/雷/暗/纯，NULL=普通武器）

settlement_storage (据点仓库)
  - id, settlement_id
  - item_id, quantity

exploration_zone (探索区域状态)
  - id, zone_id, date
  - remaining_resources (JSON)    # 当日剩余资源池

horde_record (尸潮记录)
  - id, settlement_id
  - week_number, wave_count
  - result (ENUM: perfect/victory/defeated)
  - rewards (JSON)
  - participants (JSON)

death_pack (遗物包)
  - id, survivor_id
  - zone                          # 掉落区域
  - location                      # 掉落地点（区域内的具体地点名）
  - items (JSON)                  # 掉落的物品列表
  - created_at
  - expires_at                   # 24小时后过期
  - recovered_by                 # 谁回收的（NULL=未回收）

npc_resident (据点NPC居民)
  - id, settlement_id
  - name, specialty
  - assignment (ENUM: farm/guard/workshop/medical/idle)
  - satisfaction                  # 满意度

companion (同伴数据)
  - id, npc_resident_id           # 关联据点NPC居民
  - owner_survivor_id             # 所属玩家
  - companion_type (ENUM: combat/scavenge/medical/mechanic)
  - hp, max_hp                    # 同伴健康值
  - trips_together                # 同行次数（决定同伴等级）
  - skill_used_today              # 今日是否已使用专属技能
  - is_injured                    # 是否受伤（需休养）
  - injury_rest_remaining         # 剩余休养次数
  - personality_prompt            # 同伴性格描述（用于AI生成台词）
```

## 18. 开发路线图

### Phase 1: 核心生存（MVP）

**目标**: 单人可以探索、搜刮、战斗、活下来

- [ ] 项目框架搭建（复用 DI/UoW/Repository 基础设施）
- [ ] 角色创建 + 属性系统
- [ ] 生存状态（饥饿/口渴/健康/精神）+ 衰减/恢复
- [ ] 背包系统 + 物品模型
- [ ] 基础搜刮系统（区域 + 资源池）
- [ ] 基础战斗系统（近战 + 远程 + 弹药 + 距离）
- [ ] 基础敌人（丧尸/流浪者/野兽——普通枪械即可对付）
- [ ] 新手引导流程
- [ ] 帮助系统

> **Phase 1 说明**: MVP 专注于"人 vs 丧尸"的纯生存体验。不引入异源生物和符隶系统——先让核心搜刮+战斗+生存循环跑通、打磨手感。属性变异体是中后期进度门槛，不是前期内容。

### Phase 2: 据点与社交

**目标**: 多人可以建立据点，一起生活

- [ ] 据点创建 + 成员管理
- [ ] 建筑系统（围墙/水井/农场/工坊/仓库/厨房）
- [ ] 据点公共仓库
- [ ] 小队系统
- [ ] NPC 居民系统
- [ ] NPC 同伴系统（邀请同行/同伴培养/随行加成）

### Phase 3: 尸潮与防御

**目标**: 周期性尸潮考验据点

- [ ] 尸潮引擎（波次生成/敌人 AI）
- [ ] 据点防御战模式
- [ ] 陷阱系统
- [ ] 尸潮奖励/惩罚结算
- [ ] **属性尸潮波次**（特定波次出现属性变异体，需要据点储备符隶武器和元气结晶）

### Phase 4: 符隶、异源生物与经济

**目标**: 异源生物登场 + 符隶系统完整上线 + 完整的资源循环

- [ ] 制造系统（四工作台/图纸/品质/加工链）
- [ ] **异源生物 + 异源护盾**（Tier 3 区域开始出现低阶焰尸/寒尸等，作为"护盾之墙"进度门槛）
- [ ] **符隶系统**（兵符融入武器破盾 + 防护符融入防具减伤 + 聚元符/摄元符元气管理）
- [ ] **中高阶属性变异体**（焰甲兽/焰魔等，Tier 3-4 区域的硬护盾敌人）
- [ ] 武器改装系统
- [ ] 属性克制关系完善（五属性循环克制）
- [ ] 玩家间交易
- [ ] 商队系统
- [ ] 声望系统

> **Phase 4 说明**: 符隶系统与制造系统同期上线。此时玩家已经在 Tier 1-2 区域打了几周丧尸和人类敌人，熟悉了核心生存循环。当他们首次踏入 Tier 3 遇到异源生物"打不动"，再获得神兵符融入武器、一枪破盾——这个反差体验才是真正的"进阶门槛"。

### Phase 5: 叙事与深度

**目标**: 长期留存内容

- [ ] AI NPC 对话系统（复用+换皮）
- [ ] 主线故事（故事引擎驱动，含异源物质起源揭示）
- [ ] 随机事件系统（丰富探索体验）
- [ ] 环境威胁系统（辐射/天气）
- [ ] 专长系统
- [ ] 高阶兵符 + 异源精华（顶阶符隶，对应最难内容）

### Phase 6: 运营与付费

**目标**: 可持续运营

- [ ] 月卡系统
- [ ] 赛季目标系统
- [ ] 据点排行榜
- [ ] 据点间联盟/贸易
