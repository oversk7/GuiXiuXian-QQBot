# 材料统计功能说明

## 功能概述

材料统计系统是一个管理员专用工具，用于统计全服材料的数量分布（包括玩家背包和公会仓库），便于及时调整爆率，监控材料稀缺度是否符合预期。

## 权限要求

- **仅限超级管理员使用**（需要在 `config.yaml` 中配置的 `admin_ids` 列表中）
- 使用 `SUPERUSER` 权限验证

## 使用场景

### 1. 监控材料稀缺度

定期使用 `材料统计` 查看各稀有度材料的分布情况，确保：
- 普通材料占比合理（建议 50-60%）
- 稀有材料不会过于泛滥
- 传说材料保持稀缺性（建议 < 2%）

### 2. 调整爆率

通过查看具体材料的统计数据，判断是否需要调整副本掉落率：
- 如果某个材料持有人数过少，可能需要提高爆率
- 如果某个材料总量过多，可能需要降低爆率
- 通过人均持有量判断材料是否过于集中

### 3. 发现异常

- 检查是否有玩家持有异常大量的某种材料
- 通过排行榜发现可能的刷材料行为
- 监控材料经济是否健康

### 4. 平衡游戏经济

- 根据材料分布调整装备合成配方
- 平衡不同稀有度材料的价值
- 确保游戏进度合理

## 技术实现

### 数据来源

- 从 `inventory` 表查询所有 `MATERIAL` 类型的物品实例（玩家背包）
- 从 `guild_warehouse_item` 表查询所有材料（公会仓库）
- 聚合统计每个材料的总数量、持有人数和持有公会数
- 关联 `items.yaml` 配置文件获取材料属性

### 性能优化

- 使用 SQL 聚合函数减少数据传输
- 按需查询，避免一次性加载所有数据
- 分页显示排行榜，限制 TOP10

### 权限控制

- 使用 `SUPERUSER` 权限确保只有超级管理员可用
- 防止普通玩家查看全服数据

---

## 注意事项

1. **数据实时性**：统计数据为实时查询，反映当前数据库状态
2. **性能影响**：大量玩家和公会时查询可能较慢，建议在低峰期使用
3. **数据准确性**：仅统计 `quantity > 0` 的物品实例
4. **装备排除**：统计仅包含材料类型，不包含装备
5. **公会仓库**：包含所有公会仓库中的材料统计，提供更全面的数据
