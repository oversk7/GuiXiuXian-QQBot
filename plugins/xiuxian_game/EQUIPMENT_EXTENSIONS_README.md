# 装备系统扩展功能文档

## 📋 功能概述

本次扩展为装备系统添加了三大核心功能：
1. **装备等级穿戴限制** - 装备有等级要求，增加游戏策略性
2. **装备升阶系统** - 装备可升级1-10阶，大幅提升属性
3. **宝石镶嵌系统** - 可镶嵌宝石、佛珠、符文，自定义装备属性

## 🎯 装备等级穿戴限制

### 功能特点
- 每个装备都有最低等级要求（`required_level`）
- 玩家等级不足时无法穿戴装备
- 在装备信息中显示等级要求

### 配置示例
```yaml
- item_id: "bone_armor"
  name: "白骨护甲"
  required_level: 1    # 1级可穿戴
  gem_slots: 1         # 1个宝石孔位
  rarity: "white"      # 白色品质
```

### 使用命令
- `装备栏` - 查看装备信息，显示等级要求
- `装备 装备名` - 穿戴装备，自动检查等级

## ⭐ 装备升阶系统

### 功能特点
- 装备可从0阶升级到10阶
- 每次升阶提升20%基础属性
- 升阶需要消耗材料、金币和升阶石
- 成功率随等阶递减，失败可能降级或损坏

### 升阶材料
- **初级升阶石** - 用于1-3阶升级
- **中级升阶石** - 用于4-6阶升级  
- **高级升阶石** - 用于7-9阶升级
- **至尊升阶石** - 用于10阶升级
- **稳定水晶** - 提升成功率，防止失败降级

### 成功率配置
| 等阶 | 成功率 | 失败后果 |
|------|--------|----------|
| 1-3阶 | 90%-80% | 仅消耗材料 |
| 4-6阶 | 70%-50% | 可能降1阶 |
| 7-9阶 | 40%-20% | 可能降2阶或损坏 |
| 10阶 | 10% | 可能降3阶或损坏 |

### 使用命令
- `升阶信息 装备名` - 查看升阶需求和成功率
- `升阶 装备名` - 执行升阶操作
- `升阶 装备名 稳定水晶` - 使用稳定水晶升阶
- `升阶列表` - 查看可升阶装备

## 💎 宝石镶嵌系统

### 功能特点
- 装备有1-3个宝石孔位（根据品质决定）
- 可镶嵌三类物品：宝石、佛珠、符文
- 镶嵌需要消耗镶嵌锤和金币
- 拆卸需要拆卸凿，有损坏风险

### 镶嵌物品类型

#### 🔸 宝石类（基础属性提升）
- **力量宝石** - 攻击力 +15
- **敏捷宝石** - 敏捷 +15
- **体质宝石** - 生命值 +100
- **防御宝石** - 防御力 +20

#### 📿 佛珠类（特殊属性提升）
- **暴击佛珠** - 暴击率 +8%
- **连击佛珠** - 连击率 +6%
- **闪避佛珠** - 闪避率 +8%
- **命中佛珠** - 命中率 +10%

#### 🔮 符文类（特殊效果）
- **吸血符文** - 15%概率吸血30%伤害
- **反伤符文** - 20%概率反伤50%伤害
- **免疫符文** - 25%概率免疫负面状态

### 孔位配置
- **白色装备** - 1个孔位
- **绿色装备** - 2个孔位
- **蓝色及以上** - 3个孔位

### 使用命令
- `孔位 装备名` - 查看装备孔位信息
- `镶嵌 装备名 孔位号 宝石名` - 镶嵌宝石
- `拆卸 装备名 孔位号` - 拆卸宝石（有风险）
- `镶嵌物品` - 查看可镶嵌物品列表

## 🛠️ 技术实现

### 数据库扩展
- 扩展 `ItemInstance` 模型，添加 `upgrade_level` 和 `gem_slots_data` 字段
- 扩展 `ItemConfig` 类，添加 `required_level`、`gem_slots` 等属性
- 创建数据库迁移文件 `add_equipment_extensions.py`

### 核心服务类
- `EquipmentUpgradeService` - 装备升阶核心逻辑
- `GemSocketService` - 宝石镶嵌核心逻辑

### 命令模块
- `equipment_upgrade_commands.py` - 升阶相关命令
- `gem_socket_commands.py` - 镶嵌相关命令

### 配置文件更新
- 在 `items.yaml` 中添加了156行新配置
- 包括升阶材料、镶嵌物品、装备属性扩展

## 📊 平衡性设计

### 升阶系统平衡
- 材料需求指数增长，防止快速升满
- 成功率递减机制增加挑战性
- 失败惩罚机制增加决策权重

### 镶嵌系统平衡
- 孔位数量限制防止属性过度膨胀
- 拆卸风险机制增加选择成本
- 不同类型镶嵌物提供多样化构建

### 经济平衡
- 升阶和镶嵌消耗大量金币和材料
- 为高级材料创造新的需求
- 增加装备的长期价值
