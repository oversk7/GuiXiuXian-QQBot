# 社交系统

## 概述

社交系统为游戏增加了婚姻和师徒功能，让玩家之间可以建立更深层的社交关系。系统包含以下主要功能：

- **婚姻系统**：玩家可以求婚、结婚、离婚
- **师徒系统**：玩家可以拜师、收徒、解除师徒关系
- **礼物系统**：夫妻和师徒之间可以互送礼物
- **排行榜系统**：恩爱榜和恩师榜

## 功能特点

### 婚姻系统
- 一方申请一方同意的机制
- 恩爱榜由双方互送礼物的价值累计决定
- 支持离婚功能
- 防止重复求婚和多重婚姻

### 师徒系统
- 一方申请一方同意的机制
- 恩师榜依据恩师点排名
- 恩师点由徒弟的等级增长获得
- 支持逐出徒弟和脱离师门

### 礼物系统
- 只能向配偶或师父/徒弟送礼
- 自动扣除发送者物品，增加接收者物品
- 记录礼物价值用于排行榜计算
- 支持查看送礼和收礼历史

### 排行榜系统
- 恩爱榜：按夫妻间礼物总价值排序
- 恩师榜：按师父获得的恩师点排序
- 使用emoji美化显示效果

## 数据持久化

所有数据都存储在数据库中，服务器重启不会丢失：

- `marriage` 表：存储婚姻关系
- `mentorship` 表：存储师徒关系
- `social_application` 表：存储申请记录
- `gift_record` 表：存储礼物记录

## 命令列表

### 婚姻相关
- `求婚 UID` - 向指定玩家求婚
- `求婚申请` - 查看收到的求婚申请
- `同意求婚 申请ID` - 同意求婚申请
- `拒绝求婚 申请ID` - 拒绝求婚申请
- `配偶` - 查看配偶信息
- `离婚` - 解除婚姻关系

### 师徒相关
- `拜师 UID` - 向指定玩家拜师
- `拜师申请` - 查看收到的拜师申请
- `收徒 申请ID` - 同意拜师申请
- `拒绝收徒 申请ID` - 拒绝拜师申请
- `师父` - 查看师父信息
- `徒弟` - 查看徒弟列表
- `逐出徒弟 UID` - 逐出指定徒弟
- `脱离师门` - 脱离师父

### 礼物相关
- `送礼 UID 物品名称 数量` - 向配偶/师父/徒弟送礼
- `送礼记录` - 查看送礼历史
- `收礼记录` - 查看收礼历史

### 排行榜相关
- `恩爱榜` - 查看夫妻恩爱值排行榜
- `恩师榜` - 查看师父恩师点排行榜
- `社交统计` - 查看社交系统统计信息

## 设计理念

- **小而美**：代码简洁优雅，功能完整但不冗余
- **时间差计算**：使用数据库时间戳而非实时定时器
- **数据持久化**：所有重要数据都存储在数据库中
- **用户友好**：使用emoji和粗线装饰美化界面显示

## 扩展性

系统设计具有良好的扩展性：
- 可以轻松添加新的社交关系类型
- 礼物系统可以扩展支持更多物品类型
- 排行榜系统可以添加更多排序维度
- 升级钩子系统可以支持更多游戏事件
